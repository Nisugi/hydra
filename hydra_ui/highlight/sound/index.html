hydra_ui::highlight

Module sound 

Source
Expand description

A highlight’s sound is a file name in Hydra’s sounds folder, and nothing else.

Why not a path: a highlights file or a Wrayth settings file is something players pass around, and on Windows a path like \\host\share\ding.wav is opened by reaching out to host over the network, which answers with the player’s Windows credentials (CVE-2023-23397’s mechanism). So a sound names a file, never a place, by one rule (refused) read on strings, asked when a highlight is built, when an import brings one, and by whatever plays it.
