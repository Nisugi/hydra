Hydra

Keybinds and hotbars

The faces of a macro: a key for the hands, a button for the eyes.

Keybinds

Open the Editors window and choose Keybinds; a play window’s Keys menu opens it too, working for that character. For at the top picks every character’s keys or one character’s own. Every key in effect is listed, with what it does and where that came from. A key is bound to one of:

BindingWhat it does
"commands"Text sent to the game as it is, all at once, with no logic.
{ fill = "text" }Text put in the command line for you to finish.
{ action = "name" }One of Hydra’s own actions: switch set, open a drawer, lock.
{ macro = "name" }Run the macro of that name.

Keys come in sets, 0 to 9, and a key switches which set is in use. A macro’s own key, set on the Macros page, is listed among the keybinds as macro: <name> in the set it names, or in every set when it names none, so a key two things claim is seen. A keybind in the keys file wins over a macro’s key on the same chord.

A send keybind is sent at once as it is written, with no logic. For a chain that waits or decides, make a macro and bind the key to it.

Hotbars

A hotbar is a grid of buttons. A button names a macro, or carries commands of its own, and the bar gives it a slot, a size, a label, an icon and the colours its states show in. A press runs the macro when its condition holds. While it does not, the button is drawn dim, and a press sends nothing.

Open the Editors window and choose Hotbars: Menu › Editors › Hotbars. Every bar is listed on the left, the character’s own and everyone’s; the bar chosen is drawn on the right as its widget draws it, with its buttons in a form below. Pictures for buttons are kept on the Icons page of the same window.

In the form, Macro picks the macro the button runs, or none. With none, Sends is the button’s own commands, in the chain language. Lift into a macro makes a macro of them, named by the button’s id, and has the button run it from then on: the commands live once, on the Macros page, and the button is only its face.

A bar need not be on the screen for its keys to work. A macro’s key is the macro’s, and a button’s own hotkey is read from the file whether the bar is placed or not. The Hotbar widget on a play window shows the bars you choose to see.

The controller

A controller’s binds are keybinds too, and may press a button or run a macro. The Controller page of the Editors window holds them.
