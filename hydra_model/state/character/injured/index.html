Can this character act? The four injury predicates.

The rules here encode game mechanics: which injuries at which ranks stop casting, sneaking, searching and ranged attacks, and which of those Sigil of Determination lets a character ignore.

§Arithmetic only

The predicates are arithmetic over values the injuries dialog already gave. Nothing here sends a command, caches, or toggles the game’s injury display mode: a model crate does not send commands (model_does_no_file_io makes the same point about the filesystem).

§How wounds and scars relate

The game’s documentation on wounds states the whole model:

1. A part carries a wound AND a scar at once, and both are readable.

“Scars are the remnants of old wounds that have been partially healed through herbs or empathic self-healing. … if there is both a scar and a fresh wound on the same location then the wound must be healed first.”

So healing a rank-2 wound runs: R2 wound, then R1 wound with an R2 scar, then an R2 scar alone, then an R1 scar, then healthy. character.rs retains a known scar when a new wound image arrives rather than writing scar: 0 over it.

2. Scars come only from healing, so one cannot appear mid-hunt:

“A character who is healed by an empath will not have a scar.”

3. effective = max(wound, scar unless rank 1):

“Rank 1 scars never have any mechanical penalties. More significant scars have penalties similar to wounds of the same level.”

There is no Unknown answer: a scar under a wound is observable, as two coexisting facts per part, so every predicate can answer.

§One rule, not two

Spellcasting merges each arm with its hand as max(arm, hand) and ignores rank-1 scars. Summing wound and scar separately across the pair, or counting rank-1 scars, would be a different rule, and not the game’s.
