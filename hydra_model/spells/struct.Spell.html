pub const fn circle(&self) -> u16

The spell circle this number belongs to.

A three-digit number’s circle is its first digit, anything else its first two. So 215 is circle 2 and 1215 is circle 12.

Total over every u16. The shipped table’s lowest number is 101, but number is a pub field, so Spell { number: 5, .. }.circle() must not panic. A number under 100 is its own first two digits, so it is its own answer; the digits are computed arithmetically rather than by slicing a string.

Source

pub fn roles(&self) -> BTreeSet<Role>

What this spell is for, as a set.

The type= tag parsed: spelling normalised, order discarded. Empty when the table states no type, which 12 spells do — and not the same as “this spell does nothing”.

A tag this cannot read is skipped rather than guessed at, and Self::unreadable_roles reports it, so a table update that adds a seventh category is visible instead of silently absent.

Source

pub fn is(&self, role: Role) -> bool

Whether this spell has a role.

A whole-tag test: a substring test for attack would also match a role named counterattack, and this does not.

Source

pub fn is_area(&self) -> bool

Whether the spell hits an area rather than one target.

A modifier, not a role. MEASURED: five spells carry area, and every one of them carries attack too — attack/area, attack/area/utility. It qualifies how an attack lands rather than naming what the spell is for, so it is a question of its own instead of a sixth peer in Role.

Source

pub fn unreadable_roles(&self) -> Vec<&str>

Tags in type= that neither Role nor area accounts for.

Empty across the whole shipped table. It exists so a future regeneration that introduces a tag reports it rather than dropping it.
