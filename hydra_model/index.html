Crate hydra_model 

Source
Expand description

What the game has told one character, folded from the parser’s frames.

GameState::apply takes each [hydra_protocol::Frame] in wire order. Nothing here sees raw wire text, and nothing here plays the game: hunting, loot, herbs, travel and Lich are not this crate’s vocabulary.

Each area is built against a real capture, and keeps everything the game states.
