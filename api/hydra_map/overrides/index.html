hydra_map

Module overrides 

Source
Expand description

The player’s corrections to the map: rooms put in the area they belong to, kept in a file of their own and laid over the built-in map before the atlas lays it out.

The map files rooms by area, and some are filed wrong: a shop in the town next door, a pocket of rooms beyond a gate left in the area the gate came from. The Explorer shows such an exit, into another area, and the player corrects it: one room, or the whole pocket reachable from it that is in that other area. The correction is kept here, map-overrides.json in the data folder, by the room’s number, and applied to a copy of the map each time Hydra loads it, so the sheets are laid out as corrected. Export writes the same corrections with each room’s game numbers, for the mapper to take into the curated map.
