Expand description

One mapped room.

title, description and paths are lists because rooms have variants – day and night, seasonal, before and after an event – and the text matcher must accept any of them. Keeping only the first is the bug Genie 5 records fixing (plan/21 §3e).

Fields§

§id: RoomId

The graph node.

§uid: Vec<Uid>

Every game room number known for this node. Empty when the room has never been seen since the game began sending them, or is virtual.

§title: Vec<String>

Titles, as the game prints them, brackets included.

§description: Vec<String>

Descriptions.

§paths: Vec<String>

The “Obvious exits: …” lines.

§location: Option<String>

What the game’s location verb answers here.

§location_unknowable: bool

The location verb fails here, and that failure is itself the signal: a twin of this room is told apart by the verb failing again (reference/lich-5/lib/common/map/map_gs.rb:135-157). Upstream spells this location: false.

§check_location: bool

An identical room exists elsewhere, so identifying this one means sending the location verb.

§unique_loot: Vec<String>

Objects that must all be present for the text matcher to accept this room.

§climate: Option<String>

Climate, as upstream names it.

§terrain: Option<String>

Terrain, as upstream names it.

§tags: Vec<String>

Plain tags: travel targets (bank, gemshop, town) and, for now, forage names. Splitting forage out is plan/21 §6.

§meta: Vec<String>

Upstream’s meta: tags with the prefix removed, forage sightings excluded. Kept as strings until each kind is typed by the step that first reads it.

§image: Option<Image>

The picture fallback.

§exits: Vec<Exit>

Exits, ordered by destination so the file is stable.

§map: Option<String>

The grid this room is drawn on, when that is not its area’s own sheet: a plate, or an <area>.interiors shelf.

A slug. What each slug is — its display name and the area it is a sheet of — lives in a map-level registry, which is not carried here yet: a slug with no entry is a validation error for whoever builds the file, not a load error for the client.

§area: Option<String>

The area this room belongs to.

A plate is a grid, not a place. A room drawn on landing.well is still a room of Wehnimer’s Landing, so Self::map cannot answer this and the two are separate fields rather than one.

§placement: Option<Placement>

Where a dragged room sits, relative to a room that did not move.

The locksmith pool’s worker here, as the map names it: upstream’s meta:boxpool:npc:<name>, which eloot finds the worker by (find_worker, eloot.lic:3204). Every pool carries one: 13 rooms, 12 names, two of which (a dead halfling pirate, a grimy halfling scoundrel) answer to none of eloot’s words for a worker.
