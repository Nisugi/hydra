Parsing data/crit_tables.tsv into CritEntry values.

§Why a data file and not a const array

Crit tables are static data, so they ship as a data file. The measurement that makes it more than a preference is rustfmt:

200 entries written one-per-line  ->  203 lines
the same file after `cargo fmt`   -> 4223 lines   (21x)

Extrapolated to 2,394 entries that is ~50,500 lines of generated Rust, unreviewable. One TSV of 2,395 lines is one line per entry, so a data fix is a one-line diff.

The file is embedded with include_str!, so the tables ship inside the binary and need no file at run time.
