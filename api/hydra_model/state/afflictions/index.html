The six statuses that arrive only as text, never as an indicator.

§Why this exists

StatusInfo holds the 11 status indicators plus poisoned/diseased. Six more statuses exist that no indicator carries:

bound  calmed  cutthroat  silenced  sleeping  thorned

So a client that reads only <indicator> cannot know a character is silenced, bound, asleep or bleeding out from a thorn. They are read from the lines that state them.

A single character’s logs are not a census of what the game can send: a character who earns ascension experience never sees its training points change, for one. The list here is every text-only status, not only those one character happened to meet.

§The anchors are load-bearing

The patterns are anchored to the start of a line, and that is not cosmetic: a player can type “A calm washes over you.” into a channel. One exception is mid-line by necessity: the wire sends <creature> slices deep into your vocal cords! with the attacker first.

§Thorn poison has five ways to say yes

The start line, five progression lines and four deprogression lines all mean still poisoned; only the end line clears it. They are grouped into one true arm, because the grouping is the fact: a deprogression line is the poison weakening, not gone, and treating it as an end would be a bug.
