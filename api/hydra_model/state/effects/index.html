Active effects: spells, buffs, debuffs and cooldowns, with when they end.

<dialogData id='Buffs' clear='t'></dialogData>
<dialogData id='Buffs'><progressBar id='506' value='100' text="Celerity" time='00:01:44'/>...

Four dialogs, each cleared then refilled on its own. One collection, the dialog kept as each effect’s category: “is 515 up?” should not depend on which dialog the game files it under. Ids are mostly spell numbers, but not all; they are kept verbatim.

§Live until its end, not while listed

The game re-sends an effect only when it changes, so one whose time has run out can still be in the dialog. An effect keeps its end on the server’s clock and is live until then. The time= remaining is counted from the prompt that follows the refill: counted from the one before, an effect refilled after three idle minutes would read as ending three minutes early.
