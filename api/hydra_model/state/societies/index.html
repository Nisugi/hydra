Society abilities: Voln symbols, Council signs, Sunfist sigils.

Two halves.

Which society and what rank is membership, a classifier over the wire lines that state it. The Society enum it reports lives in character/vocabulary.rs, with the max_rank a Master’s line leaves unstated.

What a member can then do is this module and its three tables: what each ability costs, and whether it is affordable right now.

§Three societies, three currencies

SocietyAbilityCostsRanks
Order of Volnsymbolfavor, scaled by character level26
Council of Lightsignspirit and/or mana20
Guardians of Sunfistsigilstamina and/or mana20

That is why Cost is an enum rather than one struct with three optional fields: a Voln symbol has no mana cost in the sense that a sign does, and a struct with two always-None fields invites a caller to ask a question the society cannot answer.

§The tables were checked against a second source

Every number below was diffed against the game’s wiki (https://gswiki.play.net/Favor#Symbol_Use_Favor_Cost, and the Sunfist and Council pages) before being written here, because a cost table transcribed from a single source has no oracle:

CheckedValuesDisagreements
Voln voln::BASE_FAVOR_COST_BY_LEVEL98 levels0
Voln cost modifiers22 factors1, see voln
Sunfist sigils20 x rank/stamina/mana0
Council signs20 x rank/spirit/mana/timing0

The wiki is the weaker source where it is silent – it omits the stamina column for nine sigils and calls Sigil of Intimidation’s mana “Variable” where the table commits to 5 – and the two disagree in exactly one place, recorded in the voln module.

§What is NOT here

One accessor per ability. The access is voln::symbol("holiness"); 66 named accessors would be 66 names to keep in sync with the tables for no gain.

Using an ability sends the command and waits on roundtime. Sending is a session concern and hydra-model sends nothing, so Ability::command builds the string and stops there.

Spirit still owed by active dissipates signs needs live effect state, so it belongs above the model beside the other stateful consumers. What the model owes it is the timing, which CostTiming carries.
