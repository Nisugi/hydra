What the wire says about society membership: joining, advancing, leaving.

A stateless classifier over one line, the shape skills.rs, psm.rs and bounty.rs already take. The abilities a member can then use are in super; this is only the membership itself.

§Two traps, avoided by construction

1. The Council’s join line does not say Council.

It is The Grand Poohbah smiles broadly. "Welcome to the Lodge," he cries. Matching all three welcomes with one pattern and then scanning the matched text for the society’s name would miss it, and a new Council member’s status and rank would never be written.

Here each society owns its own join pattern, so there is no scan to disagree with: matching the line is identifying the society.

2. Advancing a rank adds one to a possibly-absent rank.

Before anything has taught the model a character’s rank, there is no rank to add one to. MembershipLine::Advanced carries no number for that reason: it says a rank was gained, and a consumer that does not know the current rank cannot compute the new one and should ask rather than guess.

§Advancement does not name the society

Nine different NPCs across all three societies announce an advancement, and none of the phrasings says which society is advancing. That is sound – a character belongs to at most one – but it means MembershipLine::Advanced carries no society either, and a consumer applies it to whichever membership it already holds.
