Can this sign be paid for right now?

The comparisons are asymmetric – see the module docs, where the reason is recorded.

pending_spirit is the spirit already owed by active Dissipates signs; a caller with no effect state passes 0, which is what is owed when nothing is up.

use hydra_model::state::societies::col;
let healing = col::sign("healing").expect("rank 15 sign");
// 2 spirit, invoked: strictly more than 2 must be held.
assert!(!col::affordable(healing, 2, 0, 0));
assert!(col::affordable(healing, 3, 0, 0));
