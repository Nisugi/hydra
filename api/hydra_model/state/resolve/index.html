What does a name mean? Turning "kron" into an item the game will accept.

§Resolution only

Using an item splits in two:

What it does
Resolution“which item does this name mean?”
Manipulationget it, wear it, swap hands, retry

Manipulation sends commands and watches for the reply, which needs a connection and roundtime; it belongs above this crate, which has no socket. Resolution needs nothing but state, and is what everything above it will ask first. It is all this module does.

§The ordering is the real content

GameState::find_items sorts by two keys, in the order the game itself resolves a bare noun in:

  1. How specific the match is – the whole name beats part of it beats a loose hit (Specificity).
  2. Where the item is – hands, then the ready list, then worn, then inside a container (Location).

Both matter, and the second is why this cannot live below GameState: it reads the hands, the ready list and the inventory tree at once.

§No regex

Matching is over words, so a caller’s string is never compiled into a pattern: a profile naming a bag "pack (old)" cannot raise or mismatch on its metacharacters.
