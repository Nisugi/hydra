A creature seen to leave: read off the markup, not matched against prose.

§The room gives a link with the id

The bestiary’s 1,067 flee lines, 802 of them with {direction}/{pronoun} placeholders, are matchable (creature_message.rs) – but they are the wrong tool for this question. MEASURED on the wire:

<pushBold/>A <a exist="8365650" noun="ghast">cadaverous tatterdemalion ghast</a><popBold/>
leans back on <pushBold/><a exist="8365650" noun="ghast">his</a><popBold/> haunches
and bounds <d>southwest</d>.

Both facts a departure carries are in the markup:

factwherenot
which creaturethe <a exist=> id, twice – the pronoun is a link tooa name looked up in a table
which directiona bare <d> command linka word matched from a list

So this reads the frame. No bestiary lookup, no placeholder expansion, no ambiguity about which of two creatures with the same name left, and a creature whose flee line nobody has recorded is handled exactly as well as one whose line is in the table.

§The markup separates all three, and that is MEASURED

Leaving a room carries a direction in <d>; arriving does not, and hiding does not. Measured over eight large combat logs, counting lines that carry a creature link:

shapelinescarry a direction <d>
departure195195
arrival1420
hide380

So a direction link beside a bolded creature link is a departure, and no prose is needed to tell it from the other two.

§What this still requires, and why

A bare <d> also appears in room descriptions and <compass>, and carries go bridge and climb wall as well as directions. So classify requires a bolded creature link and a <d> whose text is one of the eleven directions. Bold is the wire’s own mark for a creature (state/room.rs); an unbolded <a exist> is an item or a player.
