Status lines: a condition beginning or ending.

Reads the status family: thirty statuses, each with add patterns and remove patterns, matched as one list – every add before every remove, first match wins.

§A status is a closed vocabulary

The thirty names are the game’s conditions, and the state machine branches on several by name – the floor positions are mutually exclusive, and a stand-up clears all three. A closed set gets typed variants, and a new name in the data goes red in tests/combat_defs.rs, which asserts every TSV name parses, rather than silently classifying to nothing.
