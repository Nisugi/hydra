pub fn pattern_addresses_self(&self, pattern: &str) -> bool

Does a def’s own pattern text address us?

\b(?:at|towards?|upon|around|near|on)\s+your?\b, case-insensitive, tested against the def’s source: some inbound defs name us in the literal rather than a capture (“springs from the shadows and strikes at you!”), and have an attacker capture and no target capture.

The weapon a 2p swing or fire line names in prose.

pub fn is_narration(&self, text: &str) -> bool

Is this narration that links a creature but states no combat fact?

A rider leaping clear of its toppling mount, bystanders growing wary, our own target-set echo. Fed to the target switcher, these would split the open attack into phantom per-creature events.
