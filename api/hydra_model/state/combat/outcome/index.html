Outcome lines: why a swing produced nothing, or that it landed.

Reads the outcome family, and whether an outcome is inbound. One outcome per line, first match wins, with the specific categories before the broad evade/block pools.

§An outcome can be the only record of an inbound swing

A fully-intercepted inbound swing prints no initiation line, so the outcome is the only record of it – the state machine opens it inbound, not as an attack ON X (otherwise barrier blocks file as an unknown attack against whatever creature is current). Outcome::names_attacker is that signal: the def carried an (?<attacker>) capture.
