pub fn parse_chunk(&mut self, chunk: &Chunk, at: Option<u32>) -> ChunkFacts

Parse one completed chunk into its facts, without publishing them.

at is the chunk’s prompt time – the server epoch second the prompt carried – which stamps every event. GameState::close_chunk applies the facts to the creature registry between this and Self::publish, in that order: parse, persist, then emit.

pub fn invalidate_for_reconnect(&mut self)

Forget everything a new connection has not re-taught.

A held cast or pre-flare belongs to a chunk the old connection never finished; an assault bracket cannot outlive the fight it was in. The model’s own reconnect invalidation, run on the session’s reconnect, calls this.
