Module bracket 

Source
Expand description

Brackets: the lines that open and close a multi-part action.

Two kinds, and the distinction is the state machine’s:

  • An assault is single-target, multi-round: flurry, barrage, pummel, guardant thrusts, thrash. The opener names the ONLY target the whole assault can strike; the rounds between usually name none; the attacker cannot act otherwise until the end line.
  • A sequence is multi-target: mstrike, volley, and the spawned AoE casts (natures fury, earthen fury). Per-target attack events unfold inside it; the bracket bounds them and attributes spawned casts.

Barrage’s opener names no target; the state machine backfills it from the first named line inside the bracket.
