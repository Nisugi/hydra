pub fn link_name(text: &str) -> String

A creature’s display name from its link text.

The game sometimes puts the possessive INSIDE the link (<a>grim gigas skald's</a> mastery of music), which would register a second creature named "grim gigas skald's". Same id, same creature: strip it. A hidden adjective leaves a doubled space (halfling cannibal), squeezed for the same reason.
