What a chunk of combat yields: attack events and the facts beside them.

An attack event and its per-fact companions (statuses, spell losses, UCS), typed. A recorder or a highlighter reads these; nothing here is a creature’s running state – that is the registry’s, applied from these.

§Lineage is by index into the chunk’s event list

A blob’s spawn tree is recorded as indices: an event’s AttackEvent::root and AttackEvent::parent are indices into the same ChunkFacts::events list. A reference to an event that was not emitted degrades to self-root / no parent.
