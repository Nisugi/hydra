Expand description

One attack, assembled from its lines.

Fields§

§name: String

The def name, or unknown for an orphan.

§target: EventTarget

Who was attacked.

§attacker: Option<Actor>

Who attacked, when the line says. None for our own.

§inbound: bool

Aimed at us.

§foreign_caster: bool

A nearby player’s attack.

§unowned: bool

An effect tick with no owning cast: the creature’s damage is real, but it is not our deal.

§orphan: bool

The orphan sink: facts whose initiation had no def.

§ambush: bool

Struck from hiding.

§attack_kind: Option<AmbushKind>

Which hiding maneuver, or a reaction.

§redirect: Option<Redirect>

A guardian redirect.

§aimed: bool

An aimed shot.

§weapon: Option<String>

The weapon, from the swing line or the def.

§via_cast: bool

Opened by a bare cast gesture the spell line superseded.

§parent_flare: Option<ParentFlare>

The flare that spawned it.

§root: Option<usize>

This chunk’s tree root: an index into the chunk’s events, self for a root. Resolved at emit.

§parent: Option<usize>

The immediate spawner, only when asserted.

§parent_confidence: Option<Confidence>

How the parent was established.

§hits: Vec<Hit>

Damage dealt.

§flares: Vec<FlareEvent>

Flares that rode it.

§outcomes: Vec<OutcomeKind>

How its swings resolved.

§resolutions: Vec<Resolution>

Its roll lines.

§at: Option<u32>

The chunk’s prompt time, server epoch seconds.
