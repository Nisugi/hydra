What appraise and measure say about the one thing they are aimed at: the two replies a hunt reads before a sacrifice and a briar raise.

Stateless readers over the reply’s text, for the behavior that sent the command and holds its reply lines. Nothing here is folded into GameState: the answer is about one command, and the behavior that asked is the one that acts on it.

§appraise #id, and which line is read

The reply runs from a line matching The <creature> is <size> in size to the prompt, and the verdict is read off the reply’s last line, which is the size line only when the reply is one line. A creature reads enticingly frail when it can be sacrificed; the other verdicts are susceptible to manipulation, and a soul stalwart and formidable, firmly bound or indomitable. No committed fixture carries an appraise reply: the shape is UNVERIFIED here.

Blank lines are skipped when finding the last line, so a reply that ended in a blank line still reads its verdict. Whether one ever does is UNVERIFIED.

§measure #id

Each reply line is tested for to be about N percent., any case, and the weapon is raised at 100. That is one line’s question, so measured_percent takes one line. No committed fixture carries this reply either.
