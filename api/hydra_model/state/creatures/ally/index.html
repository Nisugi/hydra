Someone’s familiar, companion or summon: a creature that is nobody’s target, whatever a hunt’s any says.

§The gap this closes

A hunt skips a creature the server calls unhostile (hostile() == Some(false)). One with no <crtrStatus> yet – registered off a combat line, creatures.rs’s choice 2 – reads None, and a target list holding any would attack it. The object-type table (data/gameobj-data.tsv) has no familiar or companion type, so these are their tables.

Spirit servants are Passive. Every spirit servant name, across 93 demeanors by 39 kinds, is already passive npc in the object-type table, MEASURED, so they need no table of their own.

§Three rules outrank the tables

  1. The server. A creature the wire calls hostile is a foe, and CreatureInstance::ally answers None for it: a creature that can be targeted is always treated as hostile.
  2. Named exceptions. A name ending abyran'ra or slush is hostile.
  3. The bestiary. A name with a template, a boon adjective stripped as the bestiary retries, is a creature of the world and nobody’s. A fixed list of excluded companion names would go stale: MEASURED, five templates carry a companion noun (mongrel wolfhound, storm hound, vapor hound, water hound, wharf rat), and two templates spell a familiar (large black cat, large ring-tailed lemur). So the bestiary is the exclusion.

§Igaesha

The Igaesha pattern matches a cloud of {color} {subtype}, the names the game gives it, with any color words between cloud of and the subtype.

§What stays UNVERIFIED

Whether the game’s own target list (dDBTarget, targeting.rs) already leaves these out. INFERRED that it does, not measured.
