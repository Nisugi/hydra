One creature the feed has shown: its statuses, wounds, damage and UCS state, and the questions a hunter asks of it.

§The clock is the server’s

The model has no wall clock – it has GameState::game_time_now, the server epoch extrapolated from the last prompt – so every timestamp is a server second and every method that must compare one takes now: Option<u32>. With no clock (None, before the first prompt) a timed status simply does not expire and an estimate is not active: an unknown clock reports unknown rather than a guess.
