Module state 

Source
Expand description

GameState: one character’s state, and the one place frames enter it.

Every area the game states is kept: all of the data, not a chosen subset. Not here, because they are automation rather than game state: guard words, the herb table and doses, triggers and their flags, the sorter, the loot ledger, room claiming. Not kept yet: the player’s own injuries.
