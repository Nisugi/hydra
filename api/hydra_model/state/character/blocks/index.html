Reading a command report out of a completed chunk.

A chunk consumer: the prompt is the report’s boundary (see state/chunks.rs), and the chunk holds parsed lines with exist, noun and bold already typed, so this file needs no pattern for markup at all.

§No block state machine

The chunk is already the report’s boundary, so “which block is open” is answered by looking at the chunk’s own lines rather than remembered across them. There is no buffer, no opener that sets an open block, no terminator that commits one.

What remains is a pure function of one chunk, which is a better shape for the same reason a classifier is: same chunk in, same answer out, and nothing left dirty when a connection drops mid-report.
