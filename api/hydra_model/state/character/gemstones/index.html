Module gemstones 

Source
Expand description

The character’s gemstones: the collection gem list all prints, which of them are equipped, and each one’s properties with their ranks.

The game says nothing of gemstones on its own: the listing comes when it is asked for, and an equip or unequip answers with one line naming the jewel. So the collection is read from the listing whenever one passes, and the two answers flip the jewel they name between listings. The properties’ mnemonics come from the listing’s own links: each property is a gem info <mnemonic> link, so the name a report shows and the word the game uses for it arrive together.

A set cannot change in combat: the game asks for thirty seconds with no hostile creature about before a gemstone is equipped or unequipped. A hunt therefore has one set, which is what the combat recorder keeps of it.
