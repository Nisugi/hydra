pub fn read_tables(chunk: &Chunk) -> Vec<(PsmCategory, Vec<PsmLine>)>
Expand description

Every PSM table one chunk holds: its header, then its rows, until the Subcategory: footer or the chunk’s end (the INFO form has no footer).

The sync sends every <category> list all all (snapshot.rs, Group::sync_commands); this is what folds the answers into the model via PsmSet::replace_category, so cost’s known test has ranks to read.
