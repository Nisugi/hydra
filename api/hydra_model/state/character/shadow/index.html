§Two rules

  • An unknown count stays unknown. A gain or a spend on a count never told leaves it unknown, rather than counting from 0; the report, or reaching the cap, says it.
  • The mana estimate divides as a real number. The mana per essence after the first grows with the character’s mana control ranks; integer division would make that share 0 for every character. essences_for divides as a real number.
