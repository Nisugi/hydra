Expand description

Society membership, citizenship, warcries and resources.

Everything society_line and its siblings teach, stored. Grouped in one struct rather than five fields on Character because they share a refresh: Group::Standing is one line of a sync and one entry in the dirty set.

Every field is Option or empty-by-default: a character the client has never synced has not “no society”, it has an unknown one, and the two must not read the same. A 'None' string sentinel for no society would blur them, which is why the society is an Option<Society>.

Fields§

§society: Option<Option<Society>>

The society, once stated. Some(None) is “stated: none”.

§society_rank: Option<u8>

The rank within it.

For a Master the wire sends no number and this holds Society::max_rank, applied by Self::apply_society – VERIFIED against a live character, whose society output says only “Master of the Guardians of Sunfist” while the store holds rank 20.

§citizenship: Option<Option<String>>

The citizenship town. Some(None) is “stated: none”.

§urchin_access: Option<bool>

Whether the urchin guides serve this character, once urchin status has said (urchin_line). Kept, so travel asks only while this is unknown.

§urchin_until: Option<u32>

When that access ends, by the game’s clock, when the game gave a date (urchin_until). Read through Self::urchins.

§warcries: BTreeSet<Warcry>

The warcries known, in Warcry::ALL order.

A set, not a count. Recording presence and absence under different keys would let a warcry, once learned, never be un-learned. A set cannot have that failure: Self::set_warcries replaces it wholesale.

§resource_type: Option<ResourceType>

Which resource this profession earns, from a Suffused line.

§resources: Option<ResourceAmounts>

Weekly and total earned.

§suffused: Option<u32>

The amount currently suffused.

§covert_arts_charges: Option<i32>

Covert Arts charges, out of 200. Signed: the wire can send a negative.

§shadow_essence: Option<u8>

Accumulated shadow essence, 0 to 5 (character/shadow.rs).

pub fn apply_society(&mut self, event: SocietyEvent) -> bool

Apply one society line’s meaning.

Returns whether anything changed, so a caller can mark a group dirty only when there is something to write.

§The arithmetic the line does not carry

A Master’s line has no rank, so Society::max_rank fills it. A step line says only that one happened, so the rank rises by one – and an unknown rank stays unknown, rather than becoming 1: adding one to an absent rank would turn “we never asked” into “rank 1”.

Source

pub fn set_warcries(&mut self, warcries: BTreeSet<Warcry>) -> bool

Replace the known warcries wholesale.

Wholesale because a warcry report states the complete set, and merging would keep a warcry the character no longer has.
