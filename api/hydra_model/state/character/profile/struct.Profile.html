Expand description

What profile says that nothing else does.

Every field is Option or empty-by-default: a profile nobody has run is not a character with no title.

Fields§

§title: Option<String>

Title: Hero – the title in use, which info does not state.

§age: Option<u32>

Age: a tender age (36) – the number in the brackets.

Also reaches Identity::age, which is where a caller should read it. Kept here too because this reader is where the bracketed form is understood.

§birthday: Option<String>

Date of Birth: 8/28/5090, verbatim. Elanthian, so not a date type.

§description: Vec<String>

The He is... / He has... lines, in wire order: height, eyes, skin, hair, scars, tattoos. Free prose, and the set varies per character, so these are kept as lines rather than parsed into fields.

§affiliations: Vec<String>

The AFFILIATIONS lines, in wire order.

Kept whole even though Standing reads most of them, because the section says things Standing has no field for: Follower of Zelia, Attuned to the Element of Earth, Member of House of Paupers. A caller wanting the society or citizenship reads Standing.

§achievements: Vec<(String, String)>

ACHIEVEMENTS, as (label, value): Strongest foe vanquished, Most difficult lock picked, Number of warcamps destroyed. Labels vary by profession, so this is a list rather than a struct.

§history: Vec<String>

HISTORY lines, e.g. Formerly known as Ibbo.

pub fn read_lines(&mut self, lines: &[String], name: Option<&str>) -> bool

Read one chunk’s lines, as the profile of the character named name.

Returns whether they were this character’s profile. Recognised by its PERSONAL INFORMATION header rather than assumed, because this runs on every chunk – the same rule blocks::InfoReport::read follows.

§Only the character’s own

profile Bob prints Bob’s profile in the same shape, and reading it would give this character Bob’s society, rank, citizenship and age. So the Name: line under PERSONAL INFORMATION must name name as one of its words. With no Name: line, or the character’s own name not yet known, nothing is read either: a profile nobody can prove is ours teaches nothing. A refused profile leaves what was read before untouched.
