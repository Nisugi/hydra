The room the character is in.

§The room is several independent feeds

<compDef> is the snapshot on arrival and <component> the live update, the same ids and the same body shape; the parser gives both as Frame::Component. Each id replaces only its own entry: creatures and players come and go one update at a time, and an empty body (“nobody here”) is a real update. So the room keeps each component’s body as it came, beside the typed lists read from it.

§Creatures are the bold entries of room objs

There is no separate creature feed: <pushBold/> is the only thing that tells a creature from an object in room objs.

§Where the character is, not what it saw

Only the window feed (<nav>, <streamWindow id='room'>, the room components) moves the room. The story window’s styled room text is what the character saw, and abilities that look into another room send it without the window feed; reading it here would move the character wherever it looked.
