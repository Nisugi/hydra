Module world

Expand description

What the game says of the world rather than the character: when the next pulse comes, the world events under way, and the Ebon Gate merchants at work (merchants).

A <pulse min= max=> bounds when the next pulse arrives, anchored on the server clock at arrival; a <worldEvent expires=> lapses that many minutes after it arrived, and lapsed events are pruned when a new one comes. Here they are kept whole and filtered when read, so nothing is lost between two events.
