The spells this character knows: the Spells stream.

Once per login, after <clearStream id="Spells"/>:

<stream id="Spells"><a exist="-10966483" coord="2524,1885" noun="">Minor Spiritual</a></stream>
<stream id="Spells">Minor Spiritual:</stream>
<stream id="Spells">  <a exist="-10966483" coord="2524,1865" noun="101">Spirit Warding I</a></stream>

A circle link (noun=""), a circle header (Name:), and a spell: a link whose noun is the spell’s number. This is the list the game shows, not one derived from circle ranks.
