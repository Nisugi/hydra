pub fn apply_snapshot( &mut self, room: &str, items: &[InventoryItem], continuations: &[Continuation], state: Option<&str>, )

Absorb one <inventoryManager> response.

A response carrying a state is the server reporting a failed or stale load. It replaces nothing – overwriting a good snapshot with a failure would lose the whole inventory on a transient error – but the marker is recorded so a caller can see it and re-request.

Source

pub fn apply_page( &mut self, items: &[InventoryItem], continuations: &[Continuation], (state, answering): (Option<&str>, (&str, &str)), )

Absorb one page of a big container: a response that answers the cursor answering, its root and the last item before it. Its items are added to the tree, not put in its place; its cursor is answered, and the cursors it brings wait their turn. A page carrying the server’s error marker is recorded and adds nothing.
