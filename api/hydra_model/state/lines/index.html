Text frames into lines, and lines into the prompt-bounded chunk.

§A frame is not a line

The parser gives one text frame per markup boundary, and marks the last frame of each wire line with ends_line. An enhanced info stat line is five frames, the bold value and bonus among them. A reader needs the whole line with its bold runs, so the frames are gathered per stream until one ends the line.

§The prompt closes a command’s output

Every main-window line until the next <prompt> is one chunk: a command’s report (info, skills), a combat exchange, a bank statement is read once it is whole, from the chunk the prompt closes. Lines are routed to the chunk, the stream buffers and the readers that must see them as they arrive in streams.rs.
