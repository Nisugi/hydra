The ways home: which are available, and whether one worked.

Reading only. Sending SPIRIT GUIDE and waiting out roundtime is a behavior; knowing what you could send is a question about the character. Policy stays with the caller: which method a profile picks, whether to fog at all, and any custom command list.

§Five ways out of the field

§Telling a move from standing still

moved_from is the subtle part. A room’s id is a hash of the room’s text when the room has no UID, so two unmapped rooms that read the same share an id. A fog between them looks like standing still.

The tie is broken by counting arrivals — GameState::arrivals, incremented in Room::arrive, which already distinguishes a re-declaration of the same room from a move. Counting room streams instead would also tick when the room you are standing in refreshes.

§What is NOT here

Casting, settling, pulsing mana and waiting for the move all send commands and sleep, so they belong above this crate. So does the rule for a second cast from the Rift, which is a rule about that sequence.
