Hazards: what in a room hurts whoever stays, whether the game draws it as an object or as a creature.

§Two tables, because the game draws hazards two ways

drawn astable
a room object, unbolded in room objsOBJECTS, 13 names
a creature, bolded, with a <crtrStatus>CREATURES, 2 names

The object-type table (data/gameobj-data.tsv) has no hazard category (cut -f2 gameobj-data.tsv | sort -u), which is why these lists exist. A gas cloud object is one of OBJECTS’ cloud.

§The two creatures a hunt would otherwise attack

Both are ordinary bestiary rows with hit points (data/creatures.tsv, shimmering_fungus and wasp_nest), and gameobj-data.tsv’s aggressive npc names both, so a target list holding any would attack them. A hunt should refuse them: drop them from its targets and leave when nothing else is left, or walk away from a wasp nest. The fungus summons maw spores (creatures.tsv’s special_other), and its shudder warns that the ground is about to erupt.

§Not here

The gas-cloud warning lines (a cloud forming above you, sparks, rumbling, dispersing). They are a room’s state over time, which the hunt’s flee messages already read as phrases.

Constants§

CREATURES
The creatures a hunt never targets, matched as the whole name, ignoring case.
OBJECTS
The room objects that are hazards. Each matches as whole words anywhere in the name, ignoring case, so cloud is also a gas cloud and web a sticky web.

Functions§

is_creature
Is a creature with this display name a hazard? The whole name is one of CREATURES, ignoring case.
is_object
Is a room object with this name a hazard? One of OBJECTS as whole words, and not a disk: any name holding disk is excluded.
