Floating disks: whose they are, and what they are called.

§A disk is a room object named for someone

Bagagwa disk, fiery red Vasstryke disk, four-toned Desorceri coffret. Eleven nouns carry them (DISK_NOUNS), and the display text puts the owner’s name, capitalised, right before the noun – which is what makes a disk findable without the game ever labelling one as such. The noun comes typed off the link, so only the owner’s word is read: the word before the noun, a capital then lowercase letters ([A-Z][a-z]+). The game allows no other shape of name: no McTavish, no D'iel.

There is no possessive. MEASURED over 45 wire logs (logs/**/*.bytes, every <a ... noun="<disk noun>">...</a>): 2,953 links, 83 distinct; 0 possessive (Ryeka's disk), 76 a capitalised name before the noun (Bagagwa disk, rusty iron Duffield disk), and 7 furniture or loot (iron-bound walnut chest, crimson sphere). A test written from an invented possessive line would agree with code written from the same invention and find no disk on the wire; the tests here use the wire’s shape (faenor Demandred disk).
