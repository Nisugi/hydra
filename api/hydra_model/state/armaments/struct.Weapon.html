Expand description

One weapon’s stats.

Fields§

§category: String

The skill category: edged, blunt, polearm, …

§id: String

The canonical id, e.g. broadsword.

§base_name: String

The display name.

§damage_factor: Vec<Option<f32>>

Damage factor by armor group, index 0 unused.

[None, 0.4, 0.3, 0.23, 0.26, 0.18] reads: 0.4 against cloth, 0.3 against leather, and so on. None where the table has no value.

§base_rt: Option<u8>

Base roundtime in seconds.

§min_rt: Option<u8>

The floor roundtime, whatever the character’s speed.

§slash: Option<f32>

Percentage of each damage type, where the table states it.

§crush: Option<f32>

See Self::slash.

§puncture: Option<f32>

See Self::slash.

§avd: Vec<Option<i16>>

Attack-versus-defense by armor sub-group 1..=20.
