Module pattern

Expand description

The model’s patterns, built as Lich’s Ruby reads them: \w, \d, \s and \b are ASCII there, and are here. Rust’s regex reads them as Unicode, and Unicode’s \w alone makes a pattern most of a megabyte to build and to search with; read as ASCII it is tens of kilobytes. The game writes ASCII, so what a pattern finds is the same.

compile builds a pattern so. compile_gated builds one that runs only on lines a gate or a first-word bucket already chose – the combat definitions and the crit patterns, thousands of them – with no lazy DFA of its own: its cache is kept for every thread that runs it, and for so many patterns, each run on few lines, those caches cost far more than they save. Measured over a four-character afternoon’s recordings, the two together halve what each matching thread holds, about 90 MB to about 45, for about a tenth more time.
