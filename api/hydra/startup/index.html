hydra

Module startup 

Source
Expand description

Hydra starting on its own: hydra serve --detach, which leaves the console and rests in the background; on Windows, the sign-in entry that runs it; and Hydra starting fresh, which starts the next process so, with --again (rest).

--in <dir> says the working directory, which the data folder and the logs are found from: at sign-in the system starts Hydra elsewhere. The sign-in entry is the user’s Run key, holding the command that starts Hydra here, in the directory it ran in when the entry was made.

On a Mac, Hydra started from its app runs in the user’s Application Support folder, Hydra in it (in_the_apps_home): the system starts an app at the disk’s root, where nothing can be made, and an app’s files belong there. Hydra started as a program alone, not from an app, runs where it is started, as everywhere else.
