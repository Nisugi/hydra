Source
Expand description

How long Hydra takes to start, stage by stage, written to its log: the wall clock as main began, then each stage with the time since, up to the first frame the windows draw. A start that is slow on one computer says in its log where the time went, before main ran included: that is the clock’s first line against the moment Hydra was asked for.
