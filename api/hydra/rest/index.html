Module rest

Expand description

Hydra between its windows: the computer kept awake while a character plays, and what Hydra holds in memory, written to the log each time what it is doing changes, and every minute while characters play. A build with measure says what each part of Hydra holds as well (hydra_mem).

One look every few seconds at the board: how many characters play, whether the windows are open, and how many maps are held laid out (hydra_map::Atlas::held). Memory is said once that has held for two looks, so a window’s first frames or a login’s burst have settled.

Hydra starts fresh once it has rested with nothing playing for the setting’s time (hydra_board::starts_fresh_after), a minute unless chosen, after a character has played or the windows have been open (until_fresh): what play read in, the graphics driver the windows started, and what the allocator kept are given back only when the process ends. A process that has done neither since it started holds nothing to give back, and rests on.
