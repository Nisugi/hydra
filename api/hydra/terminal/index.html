Module terminal 

Source
Expand description

A terminal opened by Hydra itself: hydra-tui in a console window of its own, on a character shown in a terminal as it starts, or on the hub from the tray.

It runs the hydra-tui beside this executable from Hydra’s working directory, where the data folder is, and attaches as any hydra-tui does.

On Windows cmd’s start opens the console: the program it starts has the new console’s own input and output, where one started directly would write to wherever Hydra’s own output goes, its log or its console. Windows 11 hands a new console to the terminal its settings choose. Elsewhere the system’s terminal is asked: Terminal on macOS, x-terminal-emulator on Linux and the like.
