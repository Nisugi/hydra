Module update 

Source
Expand description

Hydra updating itself (hydra_update): a newer release looked for as Hydra starts and every six hours while Check for updates is on, said on the hub and in the tray, and fetched when either asks for it, or as soon as it is found with Update on its own on. Fetched, it is in place of the program running, and runs from Hydra’s next start: when Hydra starts fresh, or is started again.

The settings are read again every minute, so a switch turned on takes within one. A look that failed is made again in a quarter of an hour. A fetch that failed is not tried again on its own; the hub offers it again.
