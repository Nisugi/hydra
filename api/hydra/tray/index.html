Module tray 

Source
Expand description

Hydra’s icon in the Windows tray, for as long as it runs, its windows open or not.

A click on it opens the hub. Its menu opens the hub, fetches a newer release when one is out, starts a roster character or a team, keeps Hydra starting at sign-in, and shuts Hydra down. A character or team started here has its play windows opened, the hub left as it is; one already playing is listed with a *, and chosen, has its window shown. Its tooltip says how many characters play.

The icon runs on a thread of its own, on an event loop of its own (tao): eframe’s runs only while the windows are open, and an icon whose loop is not running answers nothing. That loop looks at the board every two seconds and builds the menu again when what it offers has changed. It leaves the process’s DPI awareness to eframe.
