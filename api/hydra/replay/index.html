hydra replay <file>: run a recording through the parser and print the frames.

Shows what the parser makes of real traffic. Takes a .bytes session log or a Lich logxml .xml file (the same framing). Prints one frame per line (or, with --text, what hydra play would show), then a summary of frame kinds and unknown tags.
