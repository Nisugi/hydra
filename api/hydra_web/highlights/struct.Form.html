What the page edits of a highlight.

Fields§

§category: String

Its category.

§find: String

What it looks for: its words, or its pattern when pattern.

§pattern: bool

find is a pattern, not words.

§case_sensitive: bool

Capitals count.

§whole_word: bool

The words only where they stand alone.

§color: String

Its colour, #rrggbb; empty, none.

§background: String

Its ground; empty, none.

§line: bool

It paints the whole line.

§squelch: bool

The line is hidden.

§substitute: String

What is written instead of what it found; empty, nothing.

§sound: String

A sound’s file name; empty, none.

§alert: Option<String>

A banner: None, none; empty, the line; else its own words.

§notify: Option<String>

A notification, as alert.

§push: Option<String>

A banner on each phone paired for push, as alert.

§send: String

Game commands sent, lines apart by \r; empty, none.

§when: Option<Condition>

What must hold of the character for it to act; none, nothing.

§rearm: Option<f64>

Seconds a condition alone waits before acting again; none, 3.

§timer: String

A timer’s name its words start; empty, none.

§seconds: Option<u32>

The timer’s seconds unless the words say; none, none.

§caught: String

$1, the group the seconds are caught from; empty, none.

§times: Option<u32>

What a number caught is multiplied by; none, 1.

§down: String

The timer’s down words; empty, none.

§list: String

The list the timer shows in; empty, the player’s own.

§flag: Option<MarkForm>

A flag set or cleared; none, none.

§status: Option<MarkForm>

A custom status lit or put out; none, none.

§rumble: String

A rumble pattern’s name; empty, none.

§picture: String

The picture placed in the story after the line found: an https address, a data URI, or a file in the pictures folder; empty, none.

§cooldown: Option<f64>

Seconds before its sound, banner or notification comes again; none, 3.

§volume: Option<u8>

How loud the sound plays, a percent; none, 100.

§speak: Option<String>

Words spoken aloud: None, none; empty, the line; else its own words.

§characters: String

Whose it is, names apart by commas; empty, everyone’s.

§stream: String

The stream whose lines alone it looks at, as they reach it; empty, every line as it is shown.

§off: bool

Switched off.
