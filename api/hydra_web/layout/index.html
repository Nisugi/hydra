hydra_web

Module layout 

Source
Expand description

The web page’s layout for a wide screen – where its modules sit, and how big – kept in the data folder beside the other layouts, so every device and browser finds it as last left.

Shared, or a character’s own. Every character uses one shared layout, layouts/web.json, unless it has its own, layouts/<game>_<name>.web.json beside its windows’ layout. A character can share its own (it becomes the shared one, and its own is set aside), take a copy of the shared one as its own, or go back to the shared one (its own set aside).

The page asks as it would of an HTTP server: GET reads the layout the character uses, PUT keeps a new one there, and SHARE, OWN and SHARED make those changes. What is kept is the page’s own: an envelope of a storage version, a revision and the layout, read here only for its revision. A PUT older than what is kept is refused with what is kept, so two pages saving at once settle on the newer: each answer has the files to itself from its read to its write, and a write replaces a file whole.
