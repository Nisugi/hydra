Module wire 

Source
Expand description

What crosses the page’s socket, as JSON: each message an object whose t names it.

The page draws and sends; it decides nothing about the game. A run comes with the theme colour it is drawn in already chosen (run_token), by the token’s name, which the page has as a CSS variable; the theme’s colours come in their own message, so a theme worn again recolours what is drawn without sending it again. Game text is text: the page sets it as text, never as markup.
