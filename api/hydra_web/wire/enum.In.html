What the page says.

Variants§

§

Hello

The pairing, said first: nothing else is answered before it.

Fields

§pairing: String

The pairing, as the address carried it.

§

Hub

Show the hub.

§

Attach

Show the character seated as id.

Fields

§id: u32

Its session’s number.

§

Send

Send line on the character shown, as typed.

Fields

§line: String

What was typed.

§

Link

A link tapped in what the character shown sees.

Fields

§link: RunLink

What the link does.

§

Choose

An entry of the object menu shown, chosen: its command.

Fields

§command: String

What the entry sends.

§

Characters

List the characters an account has on a game: the login form, answered only for a page on the device Hydra runs on.

Fields

§account: String

The account.

§password: Secret

Its password.

§game: String

The game’s code: GS3 is Prime.

§remember: bool

Keep the password on this device once the service has proved it.

§

Login

Log one of an account’s characters in: the login form, answered only for a page on the device Hydra runs on.

Fields

§account: String

The account.

§password: Secret

Its password.

§game: String

The game’s code.

§character: String

The character, by name.

§remember: bool

Keep the password on this device once the login is proven.

§

Launch

Start a roster character by its name, with its kept password.

Fields

§name: String

The name the hub offered it by.

§

LaunchTeam

Start a team by its name: each of its characters not playing.

Fields

§name: String

The team’s name.

§

Reconnect

Start a character whose connection ended, again.

Fields

§id: u32

Its session’s number.

§

Remove

Take a character off the table: it quits.

Fields

§id: u32

Its session’s number.

§

Streams

The streams the page shows, by id: their lines are sent from now.

Fields

§ids: Vec<String>

The streams’ ids: thoughts, familiar.

§

Wheel

A slice of the touch wheel fired: its command is read from the character’s files and sent.

Fields

§wheel: String

The wheel, as Hydra named it.

§path: Vec<usize>

Each folder’s place, then the slice’s.

§

Hotbar

A hotbar’s button pressed: what it sends now is read from the character’s hotbars and sent.

Fields

§bar: String

The bar’s name.

§button: String

The button’s id.

§

Button

A button of the page’s own pressed, or a slice of its own wheel: what it sends, each line sent as typed; never a hotbar press.

Fields

§command: String

The command the page keeps for it, lines apart by \r or \n.

§

Theme

Wear name, one of Hydra’s themes, on this page alone; none, wear what the window wears.

Fields

§name: Option<String>

The theme’s name.

§

Workspace

Read or keep the shown character’s workspace, as an HTTP request would: GET, or PUT with the workspace kept in body.

Fields

§ask: u32

The page’s number for the request, which the answer carries.

§method: String

GET or PUT.

§body: Option<String>

What a PUT keeps.

§character: Option<String>

The character it is for, GAME:Name; none, the character shown.

§

Highlights

The page’s highlights editor opened or closed: while it is open the highlights are sent, and again whenever they change.

Fields

§open: bool

Opened.

§

HighlightSave

Keep a highlight as the page’s form says, in place of the one called was when it was one.

Fields

§was: Option<String>

The name it had; none, a new one.

§name: String

Its name.

§form: Box<Form>

What the page edits of it.

§

HighlightSwitch

Switch the highlight or category called name on or off.

Fields

§name: String

The highlight’s or the category’s name.

§on: bool

On.

§

HighlightRemove

Take the highlight called name away.

Fields

§name: String

Its name.

§

HighlightsText

The highlights file as this computer keeps it, asked for: answered with Out::HighlightsText.

§

HighlightsMerge

A phone’s highlights merged into this computer’s: each kept by name, the rest added, none taken away.

Fields

§text: String

The file’s text, TOML.

§

PhoneGet

What this computer keeps as the phone’s kind – its buttons, its wheel, its layout – asked for: answered with Out::Phone.

Fields

§kind: String

buttons, wheel or ui.

§

PhonePut

The phone’s kind copied to this computer, as the page keeps it.

Fields

§kind: String

buttons, wheel or ui.

§text: String

The file’s text, JSON.

§

Inventory

The page’s inventory opened or closed: while it is open, the shown character’s inventory is sent, and again whenever it changes.

Fields

§open: bool

Opened.

§

InventoryAct

An act from an item’s menu: what it sends is made by Hydra, and only when the menu offers it.

Fields

§id: String

The item’s id.

§act: String

The act’s name: inspect, look, right, left, drop, wear, open, close.

§

InventoryRefresh

Ask the game for the whole inventory again.

§

Tasks

The page’s tasks opened or closed: while they are open, the shown character’s bounty and objectives are sent, and again whenever they change.

Fields

§open: bool

Opened.

§

Trainer

The page’s skill trainer opened or closed: while it is open, the shown character’s trainer is sent, and again whenever it changes.

Fields

§open: bool

Opened.

§

TrainerStep

A goal on the shown character’s trainer stepped times ranks.

Fields

§id: u32

The skill’s id.

§up: bool

Up rather than down.

§times: u32

How many ranks.

§

TrainerReset

Every goal on the trainer back to the ranks it has.

§

TrainerApply

The trainer’s goals applied on play.net.

§

TrainerProfile

A goal profile loaded into the trainer, the goals now saved under its name, or it deleted: act is load, save or delete.

Fields

§act: String

What to do with it.

§name: String

The profile’s name.
