One page on the socket: paired first, then shown the hub or a character, and what it asks done.

The page shows a character from its seat, as the window does: the same story, so what was said before the page came is there, and the highlights and triggers have already run, once, in the seat’s feed. A line typed on the page is sent as one typed in the window; a link’s command, or an object menu’s entry, is checked as a line from the game is ([hydra_ui::game_line]).

What changed is looked for every TICK while the page shows a character, and every HUB_TICK on the hub: each message is sent only when it differs from the last of its kind. The streams the page shows (thoughts, familiar) are followed as the story is, once it names them. Its layout is kept with the other layouts (crate::layout). Its highlights editor changes the highlights as the window’s does (crate::highlights).
