hydra_web

Module workspace 

Source
Expand description

Each character’s workspace on the web page – where its modules sit, and how big – kept in the data folder, so every device and browser that shows the character finds it as last left.

The page asks as it would of an HTTP server: GET reads what is kept, PUT keeps a new one. What is kept is the page’s own: an envelope of a storage version, a revision and the layout, read here only for its revision. A PUT older than what is kept is refused with what is kept, so two pages saving at once settle on the newer: each answer has the file to itself from its read to its write, and a write replaces the file whole.
