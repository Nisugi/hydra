A character’s settings: one file, a section per system.

<data>/<instance>_<character>.settings.json

Every system’s settings and preferences share this one file, next to the character’s facts.

§Not the snapshot

The snapshot (crate::character_store) is what the game said, rewritten whole and refused when the parser changes. This is what the player chose, which the game never teaches again: a file that cannot be trusted is never written over, and a schema change migrates.

§Sections are kept as JSON until someone asks for one

Each system reads and writes its own section by name, and every other section rides along untouched. A typed struct of every section would drop, on its next save, a section written by a system this build has not heard of.
