The writer’s end: where lines arrive.

Held by the writer task (super::writer), which is the only thing that should own one.

pub fn try_recv(&mut self) -> Option<LogLine>

The next line if one is already waiting, without awaiting.

For tests that assert a line arrived, and for a writer draining what is queued before it flushes. Returns None both when the channel is empty and when it has ended – a caller that needs to tell those apart wants Self::recv.

Source

pub fn dropped(&self) -> u64

The shared drop count, so the writer can report it alongside its own failures. The writer adds write errors to this same counter: from a reader’s side, a line lost to a full channel and one lost to a full disk are the same hole.

Count a line lost after it left the channel.

For the writer, whose failures are the other half of what PlayerLog::dropped reports.
