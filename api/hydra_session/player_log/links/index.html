hydra_session::player_log

Module links 

Source
Expand description

A logged line’s links: where in its text each sits and what a click on it does, so the log window draws them as the story did.

On disk they follow the text, after a unit separator (\u{1f}, a character the game’s text never holds), as a JSON list:

[06:47:12.481][main] You see a steel broadsword.␟[{"from":6,"to":25,"object":{"exist":"123","noun":"broadsword"}}]

so the text before it reads, greps and exports as it always did, and a line written before links were kept reads as a line with none.

A link that works once is not kept: play.net’s own links that carry a one-time key (the skill manager’s loader.asp, an hmac=), which would be dead, or worse, in a log read later. Every other link is: an object’s (its id may be gone by the time it is read, and the game says so), a command’s, a web address.
