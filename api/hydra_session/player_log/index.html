Module player_log

Expand description

The player log: what each character read, as text, one file per day, kept for years and searched.

The second of the two logs: the wire log (hydra_net::sink) keeps the raw bytes for development and churns; this keeps the processed text a player read – the game’s lines by stream, what was sent, and Hydra’s own word on the connection – and is the record a player goes back to.

<log_dir>/player/<character>/<character>_2026-10-02.log
[06:47:12.481][main] You see a rock.
[06:47:13.002][main/combat] You swing a steel broadsword at a kobold!
[06:47:13.110][cmd/player] look
  • channel: the record and the bounded channel. The actor never blocks on the disk; a full channel drops a line and counts it.
  • feed: one connection’s lines, held to the prompt so a combat chunk is tagged main/combat, and what is captured.
  • writer: lines to disk, buffered, a file per character per day.
  • archive: a closed month’s (or week’s) days into one gzip file, monthly by default; retention: what is old enough to go, forever by default; both run when a character starts.
  • reader: the days, the tail, a time window, and search, plain or archived.
  • links: a line’s links, kept after its text, so the log window draws them.

Constants§

COMMANDS
The tag sent commands are logged under, each with its sender after it: cmd/player, cmd/lich, cmd/travel, cmd/trigger, cmd/survey. A log written before senders were kept says cmd alone.
MAIN
The tag the main window’s lines are logged under.
NOTICES
The tag Hydra’s own lines are logged under.
READOUTS
Streams that carry state rather than history, which the player log leaves out: the streams the game clears and rewrites whole, found by a survey of 24 logs across 6 characters, which the connection’s recording keeps. A capture that asks for one (Capture::set) writes it only when it changes.

Functions§

class
The class of a line logged under tag: its tag’s last part, what Hydra’s definitions made of it, so main/combat is combat and main is main; a command is COMMANDS whoever sent it.
command_tag
The tag a command from origin is logged under: COMMANDS and its sender.
sender
Who sent the command a line logged under tag holds: player, lich, and so on; None for a line that is no command, or a command logged before senders were kept.
