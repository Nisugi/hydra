pub fn adopt_unscoped(root: &Path, character: &str) -> Result<Adopted>
Expand description

Move character’s log from where logs were kept before games were told apart, player/<name>/, to its game’s folder: for Prime’s character only, whose those logs almost always are.

File by file, none written over, and the old folder removed once empty: a move cut short – or one the writer’s own folder got in the way of – is finished the next time, and a file of the same name in both stays where it was.
