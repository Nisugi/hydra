Module ask 

Source
Expand description

A line sent and its answer collected: the game’s lines until the prompt that closes them, with the roundtime they cost.

A Listener joins a session once (SessionHandle::join) and keeps its own [GameState] from the stream, so it can tell which lines the model finished since it last looked. Listener::ask writes a line to the game at once, past the queue, waits for the session to echo it (Event::Sent) so nothing said before it is taken for its answer, then keeps every main-window line until the next prompt. A prompt that closes nothing (the game sends one for someone arriving, a spell wearing off) is not taken for the answer’s own: the answer is the lines up to the first prompt after at least one line, or whatever came by the time the wait ran out. Reply::prompt_closed says which. A command can answer in more than one burst with a prompt after each (incant is a prepare and a cast), so the answer is held open for a short quiet spell after its prompt and takes what follows, prompts and all, and for as long as the roundtime it stated lasts (a cast’s effect comes when its cast time ends). And nothing is written while the game is still talking: a line asked waits for a quiet spell first, so what a command of the player’s left in the stream is not taken for the answer either. A line is never taken for the next command’s answer, and one answer taken wrongly does not shift every answer after it.

The roundtime is read from the state at the close: how many seconds the game said remain, as the game counts them, never the absolute epoch the frame carries.

Constants§

ANSWER_WAIT
How long an answer is waited for once the line is written: the game answers most lines within a second, a lagging one within a few.
LONGEST_ROUNDTIME
The longest a stated roundtime is honoured before a line is sent anyway: a stuck clock does not hold a caller for ever.
QUIET_WAIT
The longest a line waits for the stream to go quiet before it is written anyway.
SETTLE
How long an answer is held open after its prompt for more of itself, and how long the stream must be quiet before a line is written.
