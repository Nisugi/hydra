SupervisedSession: a session that outlives its connections.

A Session is one connection. This opens connections, runs one actor over each, and decides whether to open another. Between two, in order:

  1. the game state forgets what the new connection has not told it (GameState::invalidate_for_reconnect);
  2. the generation advances, so a command meant for the old connection is not sent on the new one;
  3. State::Reconnecting is published;
  4. it waits one rung of the backoff ladder (backoff), answering its handles meanwhile;
  5. it asks the connector for a new connection.

What stops it: a quit or a cancel; a connect error that cannot succeed by trying again (Retryability::Fatal); and MAX_UNATTENDED_LOSSES drops in a row with nobody using the session – an idle character is not logged back in forever.
