Module notice 

Source
Expand description

Hydra speaking to the player: a message with a kind that picks its colour, prose or a mono block for tables, and whether it answers something the player did. Every feature that tells the player anything goes through it: a route table, a trip that ends with a sword still stored, a crossing that stops and says why.

§Typed, not markup

A notice is never written as game markup (<preset id='whisper'>, <output class="mono"/>, <pushBold/>) for the parser to read back. Hydra is one binary: emitting markup only to parse it again is a round trip with a forgery in the middle, and it would put text the game never sent into a stream whose whole value is that the game sent it.

So a notice is typed, and travels as an Event beside the frames rather than among them. The terminal prints it; a web frontend draws a mono block in a fixed-width box; neither parses anything, and neither can mistake Hydra’s voice for the game’s.

§Links

A table may carry links (Body::Linked): a creature’s name that opens its bestiary entry, a [go2] that walks to its ground, a wiki page. Each line is spans (Span), a span’s link one of Hydra’s own commands, sent with the command symbol before it; a game command, sent as the game’s; or a web address. A frontend with no links draws the words alone (Notice::lines).
