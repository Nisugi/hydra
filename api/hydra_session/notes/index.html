hydra_session

Module notes 

Source
Expand description

The player’s notes: named pieces of text, kept in one file for every character and filed under the character that made each.

<data>/notes.json
{ "schema_version": 1,
  "characters": { "prime_nisugi": { "bounty": { "text": "…", "made": "2026-10-15 14:02",
                                                "changed": "2026-10-15 14:10" } } } }

Every note is every character’s to read: the notes are the player’s. A character writes under its own name; a name looked for is its own first, then anyone’s. Times are the wall clock’s, written as a person reads them, so the file is readable and mendable by hand.

§Never written over when it cannot be read

Prose the player wrote is not had again from anywhere: a file that cannot be read, or that a newer Hydra wrote, is refused and left alone.
