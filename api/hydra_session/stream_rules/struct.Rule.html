Expand description

One rule: what lines it matches, and the stream it puts them in.

Fields§

§name: String

What the player calls it.

§text: Option<String>

Words the line holds, whatever their case; | between words any of which will do.

§regex: Option<String>

A regular expression the line matches, as written: case matters unless it says (?i).

§from: Option<String>

Only the lines the game sent to this stream: main, thoughts.

§fighting: bool

Only the lines of a chunk the combat reader found fighting in.

§looting: bool

Only the lines of a chunk the loot reader found a creature searched or skinned in.

§marked: bool

Only the lines the combat reader marked: a flare, a status landing on the character, a killing blow.

§creature: Vec<String>

Only a creature’s messages of these kinds, as the bestiary has them: ambient, arrival, death, flee, spell_prep…

§to: String

The stream it puts them in: one the game sends, or one of the player’s own.

§copy: bool

Kept in the stream the game sent them to as well.

§off: bool

Not used.

§commands: Option<Vec<String>>

For a rule that takes fights: the first words of a script’s commands that go with their fight. For a rule that takes loot: of the commands, anyone’s, that go with their search or skin. None is FIGHT_COMMANDS or LOOT_COMMANDS.

§setup: Option<Vec<String>>

For a rule that takes fights: the first words of the commands, the player’s or a script’s, that take their chunk with them while a hostile creature is in the room. None is SETUP_COMMANDS.

The built-in rule: every main line of a chunk with a search or a skin in it to LOOT, kept in main too.

Source

pub fn commands_built_in(&self) -> &'static [&'static str]

The first words its commands go by when it names none: LOOT_COMMANDS for a rule that takes loot, FIGHT_COMMANDS else.

Source

pub fn like( from: Option<&str>, text: &str, names: &[Range<usize>], to: &str, ) -> Self

A rule for the lines like text that puts them in to: matched by like, from the stream from alone when it is known which the game sent the line to, moved. names are where the line names a creature, a player or a thing, by byte: where the game linked one.
