Behaviour words: a chain’s piece Hydra carries out with intelligence, reading the model before it sends and the game after (crate::steps::BEHAVIOURS).

§stance <x>

  1. Already in the stance asked for: nothing sent.
  2. In roundtime: it is waited for, then the stance asked.
  3. In cast roundtime, asked for anything but guarded: the game would refuse it and put the character in guarded itself, so Hydra sends stance guarded first, sees the bar show it, waits the cast roundtime out, then asks for the stance wanted – a roundtime begun meanwhile waited for first.
  4. Sent, the bar (pbarStance) is the truth: done when it shows the stance’s band; said to have failed, and the chain stopped, when it does not within a few seconds.
