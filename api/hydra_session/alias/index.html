Module alias 

Source
Expand description

Aliases: a short trigger typed in place of one or more commands.

aliases.json in the data folder keeps them: everyone’s, then each character’s own, each a trigger and its target:

{ "global": { "ls": "look" },
  "characters": { "Prime_Ashryn": { "zap": "prep 901\\rcast \\?" } } }

A line expands when it starts with a trigger, capitals aside, and the trigger is followed by a space or the end of the line; what follows it, its leading spaces dropped, is the rest. The character’s own are tried before everyone’s, and of those that fit, the longest trigger is the one meant: go n over go.

The target is commands and waits, as a key macro’s (crate::steps): \r between two commands, written as the two characters, and a piece s1.5 a wait of a second and a half. \? is the rest:

  • no rest: each \? is dropped;
  • a target with a \?: each is the rest; a command ;e… "\?", run by the player’s Lich, takes it as a quoted string;
  • a target of one command and no \?: the rest goes after it, ls in bag as look in bag;
  • a target of several and no \?: the rest has nowhere to go, and is said to be dropped (Expanded::dropped).

What an alias makes is sent as typed, and is never expanded again, so no alias can loop.
