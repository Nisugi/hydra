Teams: roster characters started together, each of its windows kept where it was put for that team.

Kept in teams.json in the data directory, written as the roster is: whole, to a temp file renamed over it. A team names its characters as the roster does, GAME:Name, one per account, since an account plays one at a time. Its name keys its windows’ places (team:<name>:play:...), so it holds no colon; a team renamed starts its windows over from where each character’s own go.
