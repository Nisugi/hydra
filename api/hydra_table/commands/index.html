Module commands 

Source
Expand description

Hydra’s own command line: every line that starts with the command symbol, . (hydra_session::claimant).

Installed when the session is built, before it connects: the command line is there from the start, not something the player turns on.

The symbol decides and the word routes: a line marked as Hydra’s goes to the first family that knows its word, and a word nobody knows is answered “I do not know” by the session. It never reaches the game either way.

The families so far: help, version, history, theme, targetid, sorter, alias, highlight, to and all (relay), lich, go2 and route2 (travel_command), quick, timer, inventory, bestiary, and stop.

HELP
What .help says: a line for each family, its word first. A table: the words make one column and what they do another, so it is said in fixed width, as every list of Hydra’s with columns is.
