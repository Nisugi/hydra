hydra_table

Source
Expand description

The session table behind the windows: every character this process runs, started on the host, seated in the windows, and the hub’s requests answered.

It starts a character – from the command line, the hub’s roster, or the hub’s login – and seats it; keeps the hub’s roster cards current; and answers quit, remove, reconnect, forget, star, remember, list an account’s characters, and shut down.

A login reaching Ready puts its character on the roster; a password typed in the hub with its box ticked is kept in the OS keyring then, once the service has proved it, and never before.
