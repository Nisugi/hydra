.lich: the player’s own Lich for a character, switched on and off.

.lich on starts the character’s Lich through the relay (hydra_lich) and keeps it on, so it starts again whenever the character does; .lich off stops it and keeps it off. Off until asked. Kept in the character’s settings file, as its command symbol is. A Lich switched on while the character plays is handed a login built from what the session knows (hydra_session::lich), so it knows who and where the character is.

Kept on, it starts once the game has let the character in (Ready), not before the connection: the character connects as fast as with Lich off, and its window shows the game while Ruby and Lich start. It is handed a login as one switched on in play is.

.lich view lich or .lich view game chooses which text the window shows while it runs (hydra_ui::story): what Lich shows, its squelches held, or the game’s own text with Lich’s own lines beside it. Kept with the switch.

Lich is the player’s own install: .lich folder <folder> says where, the folder with lich.rbw in it, once for every character (lich.json in Hydra’s data folder). It runs on the Ruby Lich’s installer put in ([hydra_lich::find_ruby]).
