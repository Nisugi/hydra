hydra_table

Module pages 

Source
Expand description

A character’s own pages in the settings menu, from its settings file (hydra_session::settings_store): General, how it is shown as it starts on its own, the command symbol, whether creatures’ tags are shown (.targetid) and how container looks are sorted; Player log, how old days are kept (every feed is written); and Theme, the theme its window wears and its own accent; Travel, travel’s settings (hydra_travel::settings); and Fights, how its story shows fights, beside the page of every character’s (fights).

A character is named as the roster names it, GAME:Name, running or not: its file is named by the instance its game calls itself. A file there that cannot be trusted is shown with why, and never written over.
