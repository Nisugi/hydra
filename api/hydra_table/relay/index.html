Module relay

.to <character> <command> and .all <command>: a line typed on one character and sent on another, or on every one.

Each character has one command line, and a line typed in it goes on that character. To send a line on another character, or on all of them, the line is prefaced with a command that says which.

Two words, kept apart, so a character named All is never a broadcast. The line goes on each character as if typed there: its own command line first (.to Baelor .highlight list runs on Baelor’s), then its Lich while one runs, for Lich’s aliases and hooks, then the game, a leading command symbol made that character’s own. Its Hydra aliases are not expanded on it, so two characters’ aliases cannot pass a line back and forth without end. A character is named in full, or by the start of its name when only one fits; one whose name is on two games is named with its game, .to GSF:Baelor look, and the name alone is refused rather than sent to either.

.all can leave characters out, or name only some: .all -Dicate,Maravel stand sends on everyone but those two, and .all +Nisugi,Dicate stand on those two alone. Each name is picked as .to picks one; one that picks nobody refuses the whole line, so a typo never sends on the wrong characters.

Only the player’s own typing relays: a line from anything else on the command line is not taken.
