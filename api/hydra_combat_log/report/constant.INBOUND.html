pub const INBOUND: &str = "a.inbound = 1 AND a.foreign_caster = 0 AND a.unowned = 0 \
    AND COALESCE(a.attacker, '') NOT IN ('self', 'environment') \
    AND COALESCE(a.outcome, '') <> 'already_dead' \
    AND NOT (COALESCE(a.attacker_exist_id, 0) < 0 AND a.outcome IS NULL \
             AND NOT EXISTS (SELECT 1 FROM hits h WHERE h.attack_id = a.id))";

A creature’s attack at us: not a nearby player’s, not an unowned tick, and not what we do to ourselves (the thorns’ recoil) or the room does (the cold), which the reader files as inbound from self and environment.
