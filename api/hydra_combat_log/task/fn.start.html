pub fn start(
    handle: &SessionHandle,
    ledger: &Ledger,
    who: Who,
    tell: Teller,
) -> Result<(), Error>
Expand description

Start recording who’s combat on handle into ledger; tell hears each hunt close. The recording ends with the session, closing the hunt under way at its last event. Err when the ledger cannot be opened.

§Errors

The ledger cannot be opened for writing, or the thread cannot start.
