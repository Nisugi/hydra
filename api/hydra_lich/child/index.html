hydra_lich

Module child 

Source
Expand description

The player’s own Lich, started as a child of Hydra.

It is never handed a password. It runs code Hydra did not write: any script can read its environment (ENV[...] in Ruby). A password given through the environment, HYDRA_PASSWORD_<ACCOUNT> (the binary’s account::env_name), lives in Hydra’s own environment, which a child inherits unless told otherwise; command removes every variable of that family before anything else is set. The rest of the environment (PATH, Ruby’s and the system’s own variables) is inherited as before.

On Windows it has no console window. Ruby is a console program, and one started by Hydra with no console of its own – resting in the background, or started fresh – would be given a window of its own, empty, since Lich talks to Hydra through pipes and sockets.

Constants§

PASSWORD_PREFIX
What every password variable’s name starts with: HYDRA_PASSWORD_ and the account (the binary’s account::env_name).

Functions§

command
A command for program whose environment is Hydra’s without a password in it: every variable named PASSWORD_PREFIX and more, matched without regard to case, as Windows matches a variable’s name. On Windows it opens no console window.
