The player’s own Lich, run behind Hydra: the relay.

Hydra keeps each character’s game connection; Lich, one process per character that wants it, takes Hydra as its game. This crate starts that process and carries between it and the session’s LichDoor (hydra_session::lich), which it holds and never the handle.
