pub const NAMED_TOLD: Duration;
Expand description

How long what the player types for Lich has waited for Lich to know the character before the player is told it still waits.

Lich learns whose game it is from the game’s <app char=...> line, and a script run before then – a ; typed as the character logs in – reads the character’s settings under no name at all: Lich then keeps an empty set for the session, and saves it over the character’s own. So the typing waits until Lich has passed that line on to its frontend, which it does only once it has read it, however long that is: handed sooner, it would do the harm the wait is for. What waits when Lich ends is listed as never given.
