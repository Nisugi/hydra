Expand description

Run the player’s Lich for the character door reaches, until stop, or until Lich or the session ends; then tell the player how it ended, and say so.

Lich is claimed from the moment this is called, not when the future is first polled: what the player types for it from now on waits for it. It is handed the game once it has connected, and only then do the windows turn to its text: while Ruby and Lich start, which can take half a minute, they show the game’s own.
