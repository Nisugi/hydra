The Lich relay: the player’s own Lich, for one character, with Hydra keeping the game’s connection.

run starts Lich in pipe mode, pointed at a port it holds:

ruby lich.rbw --pipe --stormfront -g 127.0.0.1:<port>

Lich reads a key and a version line from its standard input, as a frontend sends them, and writes both to that port before anything else. The key is a new token, and only a connection that says it first is taken: until Lich connects, anything on this machine could reach the port, and what comes through it goes to the game. It is not the game’s key, which Hydra has already given. Lich never holds a credential, nor does its environment (crate::child).

From then on Lich takes the port as its game:

  • the game’s bytes, as they came, go to it, after a login built from what the session knows as it connects ([LichDoor::claim]);
  • what it writes back goes to the game ([LichDoor::send]). A line with Lich’s <c> is one of its scripts’; one without is what the player typed, passed on after Lich’s own hooks;
  • what the player types that Hydra does not take goes to its standard input, as a frontend’s typing does, and Hydra’s own lines that start with Lich’s ; (hydra_session::lich);
  • what it would show a frontend comes out of its standard output, always read, so Lich never waits to write it, and is shown ([LichDoor::show]). Lich is asked to mark the lines it forwards from the game (--sentinel), so a window can tell them from its own; a Lich release without that flag ignores it, as it ignores any flag it does not know.

Closing its standard input stops it.

A Lich that stops reading is let go, never waited on (as the session’s copy is): one whose script’s hook never returns reads neither its game nor its standard input. Each write to it is a task of its own (feed), so a stop, its exit, and the [WIRE_CHUNKS] chunks it has left unread are always seen, and end it.

§Hydra is stormfront

Pipe mode tells Lich its frontend is unknown, so a script’s text would come out unescaped and the many scripts that ask for stormfront would take another branch. Hydra speaks Wrayth’s protocol, which Lich calls stormfront: Lich is started with --stormfront, and, for a Lich release that drops that flag in pipe mode, STORMFRONT puts unknown back to stormfront whenever Lich sets it.

CONNECT_DEADLINE
How long Lich has to connect once started. It takes about 3 to 5 s without its windows; with them, and on a slower machine, it takes longer. Lich allows itself 30 s to reach a game.
