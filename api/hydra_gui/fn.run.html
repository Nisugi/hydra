Expand description

Open the windows over sessions – the hub shown or hidden as open says, and each character’s play window it keeps – and run until the last closes, or the binary closes them once the run is over ([Sessions::close]). A character seated after opens its play window unless it was started headless or for the web. The hub’s requests run on runtime; layouts, presets, keys and pictures are kept in data, the data folder. Blocks the calling thread, which must be the main one.

Closed, the windows can be opened again by another call, on the same thread: eframe keeps its event loop between them. What drew them is let go as they close.

§Errors

The window could not be opened: no display, or no graphics adapter.
