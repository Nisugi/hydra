The table of sessions one Hydra runs: many heads, one body.

A session (hydra-session) is one character, and knows nothing of any other. This is what knows there are several: it runs each, numbers it, refuses a second character on an account that already has one online, and stops them in order.

§Built to sit behind a shared lock

Host::take removes a session from the table at once, and the slow part – quit, then waiting for the game to close – is Hosted::stop, awaited with the lock released. So nothing waits on another session’s goodbye.
