Find a character’s launch code in a C response.

Format: C \t n \t n \t n \t n \t <code> \t <Name> [\t <code> \t <Name>]... – four counts, then code/name pairs from field 5.

Split out of authenticate so it can be tested without a socket: this is the one piece of parsing in the sequence with an off-by-one to get wrong, and a live login is a poor place to discover it.
