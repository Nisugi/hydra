hydra_net::trainer

Module http 

Source
Expand description

Fetching the skill manager and applying goals to it, over HTTPS.

One Trainer keeps the website’s session from the page to the goals applied: the one-time link sets the session’s cookie, and the form’s post is answered only within it. The website answers a request without a browser’s User-Agent with a 500, and a form post without a browser’s headers may be turned away, so both are sent as a browser sends them. Nothing here is tested against the website: what it reads is (super::page), and where a fetch landed (landed).
