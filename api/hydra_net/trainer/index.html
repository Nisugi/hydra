The play.net skill manager, read and answered without a browser.

GOALS in the game answers with a one-time link to the skill manager (<LaunchURL>). page reads the page it opens into the character’s skills and goals (goals), whose arithmetic changes them as the website would; applying them posts the page’s own form back.

What can be tested without a network – the page, the form, the answer – is pure and kept apart from what fetches it.
