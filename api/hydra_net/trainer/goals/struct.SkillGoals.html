Expand description

A character’s skills and goals, as the skill manager page states them, and the points the goals have spent.

Per base skill, the most ranks the character may have.

Per base skill, the ranks it has.

Per base skill, the ranks it is to have: changed as goals are.

The spell circles’ names, three, the last empty for a profession of two.

The ranks each circle has.

The ranks each lore branch has, by id.

§lore_goals: BTreeMap<u32, i64>

The ranks each lore branch is to have, by id.

§physical_total: i64

The character’s physical training points, all of them. Never changed: applied goals post it back as it came, for a total that drifted would be taken for the new one.

§mental_total: i64

Its mental training points, all of them; never changed.

§physical_left: i64

Physical points left.

§mental_left: i64

Mental points left.

§physical_converted: i64

Physical points converted into mental.

§mental_converted: i64

Mental points converted into physical.

§physical_spent: i64

Physical points the changed goals spent.

§mental_spent: i64

Mental points the changed goals spent.

§rows: Vec<Row>

The rows, in the page’s order.

§hidden: Vec<(String, String)>

Every hidden field of the page’s form, in order: posted back with the goals, as a browser would.

§page_url: String

Where the page was read from, which the form posts relative to.

§action: String

The form’s action.

Source

pub fn aim(&mut self, targets: &BTreeMap<u32, i64>) -> bool

Each goal in targets stepped to its ranks a rank at a time, as the website would, the points with them: every one lowered first, for the points it frees, then every one raised. Whether each was reached: one not is short of points, or past the most the character may have.

Source
