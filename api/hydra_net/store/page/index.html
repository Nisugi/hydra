hydra_net::store

Module page 

Source
Expand description

The store’s pages, read: the sign-in token, who is signed in, the reward message and the Simucoin balance.

The pages are read by what the store marks them with (id="login", class="RewardMessage", class="balance"), as the trainer’s page is. What the message says when the month’s bonus is already taken is Next Subscription Bonus in 3d, 20h: a countdown, read by next_in. A date in the message is read too (next_available), should the store ever write one; no time found is not an error, the caller looks again later.
