Expand description

A source of raw wire bytes for one session.

Send because each session runs as one supervised task, and a task’s future must cross threads on a multi-thread runtime.

Required Methods§

Source

fn read(&mut self, buf: &mut [u8]) -> impl Future<Output = Result<usize>> + Send

Read the next available chunk into buf.

Ok(0) means end of stream: the peer hung up, or the recording ran out. It is not an error: a clean disconnect (the task ends, no socket leaks, nothing panics) is the normal end of a session, so it must not arrive as an Err.

Source

fn write_all( &mut self, message: &[u8], ) -> impl Future<Output = Result<()>> + Send

Write one whole message, as one write.

Two write_all calls can emit two TLS records, and the server does not tolerate a command split across records. That is why this method takes the finished message rather than offering a write plus a write_newline.

Source

fn shutdown(&mut self) -> impl Future<Output = Result<()>> + Send

Close the source. Idempotent, because no socket may leak and the session shuts down on several paths – cancellation, end of stream, and read error – which must not be mutually exclusive.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
