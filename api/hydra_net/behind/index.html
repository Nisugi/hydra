Module behind 

Source
Expand description

A file written behind its writer: what is written is handed to a thread of the file’s own and written there, so the task that writes – a session’s, which holds the game’s connection – never waits on the disk. A disk that stalls (a busy SSD, a build writing gigabytes to it) holds the file’s thread, never the game.

What waits for the disk is held in memory, up to HELD_MOST a file; past that, what more is written is left out and said once, rather than the writer ever waiting. A flush hands over what is gathered and asks the file’s thread to flush; Behind::settle waits, a bounded time, until all of it is written.

Hydra waits for every file still being written before it exits (settle_all): each file’s thread, and any other writing thread that holds a Live, is counted until it ends.
