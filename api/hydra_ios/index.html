Crate hydra_ios 

Source
Expand description

Hydra inside the HydraFE app: the table, every character’s session and the web page, run on the phone and served to it alone, through a few C calls (include/hydra.h) the app makes from Swift.

  • hydra_start(data_dir): start Hydra (once), its data under the app’s folder, and answer {"url": ...} once its page is served on 127.0.0.1, or {"error": ...}.
  • hydra_stop(): quit every character in order and stop.
  • hydra_status(): {"running": ..., "url": ..., "characters": ...}.
  • hydra_asleep(), hydra_awake(): the app left the screen, or came back to it (run).
  • hydra_string_free(s): a string these returned, given back.

Hydra’s messages go to the app’s standard error (Xcode’s console) and to hydra.log in its folder (log).

Each string returned is Hydra’s own; the app copies it and gives it back once. No call panics across the boundary: what fails is said in JSON.

No Lich runs on a phone (hydra-table without lich), and no window is drawn: the page is the phone’s frontend.
