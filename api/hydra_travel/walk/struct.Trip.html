pub fn to(goal: RoomId) -> Trip

A trip to goal. Nothing is planned until the first Self::tick, because where it starts is not known until then.

pub fn seeded(goal: RoomId, seed: u64) -> Trip

Self::to, with the seed for the choices a maze asks for. The session records it, so a replay walks the same way.

pub fn ban(&mut self, from: RoomId, to: RoomId)

Never offer an exit from from to to to the trip again: every one between the two rooms.

Source

pub fn replans(&self) -> u32

How many times this trip has planned again.

Source

pub fn ahead(&self) -> Vec<RoomId>

The rooms still ahead, the goal last: those already sent for, in a batch or a crossing under way, then those planned. Empty before the first plan.

Source

pub fn goal(&self) -> RoomId

Where the trip is going.

Source

pub fn wrong_for_the_map(&self) -> &[(RoomId, RoomId)]

Exits the game said do not exist – “You can’t go there” – as (from, to). The trip only goes round them; whether the map should change is for whoever reads this.

Source

pub fn heard(&mut self, line: &str)

A line of text from the game. Kept for the next Self::tick: see the module docs for why nothing happens here.

Source

pub fn arrived(&mut self)

The character arrived in a room, as the game told it: in the game’s order with what Self::heard is told, which is how a refusal among moves sent ahead is put to the move it refused.

Source

pub fn prompted(&mut self)

The game has prompted: whatever was sent has been answered.

Source

pub fn could_not(&mut self)

The deed just handed over could not be done: there is no such key. The crossing that asked for it is given up, and the trip goes round.

Source

pub fn aside(&mut self, steps: Vec<Step>, to: Option<RoomId>)

Run these steps from wherever the walker is, beside the plan: a routine’s go door gets the whole ladder a plain exit has, and its deeds are owed back like any crossing’s. to is where they should land, when that is known. The answer is Said::Aside.

Source

pub fn path_from( &self, map: &Map, walker: &Walker, from: RoomId, to: RoomId, ) -> Option<Vec<RoomId>>

The rooms this trip would walk from from to to, both included, by its own pricing. For pre-flight, which prices a walk in silver.

Source

pub fn routine_to(&self) -> Option<RoomId>

Where the routine just handed over is meant to land.

Source

pub fn draw(&mut self) -> u64

A number from the trip’s seed, for a routine’s own choices.

Source

pub fn cannot_send(&mut self)

What was last asked to be sent names a thing nobody has ({item:…}): the exit is given up for this trip.

Source

pub fn owed(&mut self) -> Vec<Deed>

What the trip has changed and not yet put back. Taking it clears it. The driver keeps its own record of what it stored and took out, and takes back from that when it is stopped; this is the trip’s side of the same debt, which the tests read.

Source

pub fn tick(&mut self, map: &Map, walker: &Walker, now: Now) -> Said

Where the walker is, what time it is, and what it knows of itself. Answers with what to do.

Safe to call as often as the driver likes: a move under way answers Said::Hold and is not sent twice, and a finished trip goes on giving the answer it finished with.

Source

pub fn pricing<'a>( &'a self, walker: &'a Walker, ) -> impl Fn(&Room, &Exit) -> Option<f64> + 'a

The trip’s own pricing: every route’s (crate::route::pricing), less what the trip has banned.
