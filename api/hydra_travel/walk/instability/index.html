hydra_travel::walk

Module instability 

Source
Expand description

The way into the Elemental Confluence: the map has no exit into the plane, only the instabilities that open on it, which wander. Pure: the game’s answers and the map in, rooms and facts out; the searching is the driver’s (drive::confluence).

In order: the walker’s element (attune); an instability of that element seen in the last six hours within ten seconds’ walk; else attune sense, which says where the fluctuations are – Sensed – and so which rooms may hold one (narrow); then each of those, nearest first, looked at until one of the walker’s element is found. Pushed with a soulstone it opens on the plane, and leaving the plane puts the walker back there: so the way out to each town costs the walk from that instability (instability_table), which is the map’s instability table.
