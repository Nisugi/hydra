What the map may ask of a character, read from its model: a Walker.

Pure: a state and the travel settings and memories in, a Walker out, so every line is tested without a game.

§Unknown stays unknown

A fact is None until the game has said something, and a question about it then has no answer: an exit priced on it is shut, which is safe and not free. So nothing here defaults: a status never reported is not false, and no effect ever listed is “not told”, not “nothing is up”. The settings are the exception, and not one: an unset setting is not set, which is an answer (crate::settings).

§Mounted is the one fact taken as no

The game has no indicator for a mount and never says a character is on foot, so mounted could never be known to be no, and every way that asks for a walker on foot – the urchin guides are one – would stay shut for good. It is no here; a walk that is refused for being mounted says yes for the rest of that walk.

Not yet, and so unknown: hunting, own_disk_here, leading_group, and the day passes held – each is the walk’s to learn.
