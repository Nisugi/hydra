Expand description

The travel settings, kept in the character’s settings file under SECTION and shown on its Travel page, in the settings menu like every other setting.

§Every setting the map asks about, and the walker’s own

TABLE names each once. The map’s are every name the built-in map asks (Map::setting_names, held to this table by a test); the walker’s own are the ones Hydra’s walk reads and the map never asks. The map spells two of its names two ways (keysack, Mularos_Lover): one row answers to both (Key::also).

§Unset is not unknown

A setting never set is simply not set: not true, and not a question without an answer. So a walker is given every setting (TravelSettings::for_walker), an unset one as its default – empty for a switch that is off or words not given, auto for the ice – and the map’s questions about them always have an answer.

Structs§

Group
One group of the Travel page: its heading, whether it starts folded shut, and its settings in order, each with whether it sits under the setting before it (a sub-setting the page indents).
Key
One setting.
Memory
A memory the map keys on: which side of a place the character came in by, or where it left from. The memory is the setting: Hydra writes it on the crossing and clears it on the way out, and the page shows the same value for the player to set between. Blank is unknown, and the way back is then priced impassable.
TravelSettings
The settings as the file keeps them: each by name, as text. A switch is true when on and absent when off.
