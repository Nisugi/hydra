What Hydra’s walker can cross, and the count of what it cannot yet: the finish line for travel, which is done when the walker can cross every exit the map has.

Every exit is crossed by one kind of crossing – a plain command, a pass through an urchin hub, a list of steps (each step one kind of action), or a named routine – and priced by one kind of cost. kinds names them, by the map’s own names for its variants, so a kind a later map adds is counted the day it appears, unrun. RUNS is what the walker runs, and an exit is walked only when every kind it needs is in it.

An exit the map gives no cost is not a route anywhere – no walker is meant to take it – and is not counted.

The test at the foot of this file holds the built-in map’s count of exits not yet walked exactly: a change that makes the walker run more must lower it, and nothing may raise it. Travel is done at zero.

Constants§

RUNS
The kinds the walker runs: every crossing, step and routine the map names, and every cost. cost Table is the way out of the Confluence, priced from the instability the walker entered by (walk::instability). Travel is done when the map holds nothing else.
