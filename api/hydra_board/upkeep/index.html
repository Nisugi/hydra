Module upkeep 

Source
Expand description

What Hydra keeps up for every character whether a window is open or not, a few times a second on the binary’s runtime: the highlights and stream rules files read again when they change, the highlights’ redirects made stream rules, Hydra’s volume and merchant switches, each character’s container looks sorted, its story kept as long as its file says and its fights shown as it and every character chose, the performance log while Performance is on, and what a write that failed has to tell.

While no window is open – Hydra at rest, a character headless or played from the web page or a terminal – it also wears Hydra’s theme for the page and the terminals, and presses the .hotbar buttons the command lines claimed: the windows do both themselves while they are open, the theme as the computer’s light or dark mode has it and a button’s command through the window’s own commands.
