Module lookout

Expand description

The lookout’s page among Hydra’s own in the settings menu: its choices, kept in lookout.toml in the data folder for every character (hydra_lookout::settings), taken by every session at once.

The ignore list is the Editors window’s Lookout page; the lines a player forgets or always shows are its stream’s right-click menu and .lookout.
