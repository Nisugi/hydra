Vellum’s folder (.vellum-fe in the home folder) brought into Hydra’s data folder: what both front ends’ .vellum import does with files alone. The keys and the highlights are each front end’s own import and Hydra’s .trigger import; here are the rest:

  • Terminal layouts. Vellum’s layout files are the terminal’s own format, so each is taken as it is: a character’s (profiles/<name>/layout.toml) becomes its terminal layout, or, when it has one already, a layout kept by the name vellum-<name>; each of layouts/*.toml a layout kept by its name, never over one kept so.
  • Hotbars and the controller. Vellum’s global/hotbars.toml and global/controller.toml are Hydra’s format: each becomes every character’s when Hydra has none.
  • History. A character’s profiles/<name>/history.txt goes before what it has sent in Hydra, its lines oldest first, as Hydra keeps them. A character in play is passed by: its screen writes its history from what it holds.

A profile is a character’s by its name, on whichever game the character plays; one of a character Hydra does not know is named, not imported.
