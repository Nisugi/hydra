Hydra’s own settings, one set for every character, kept in the window’s own file, window.toml in the data folder.

They are:

  • Recording each session’s raw stream to .bytes in the logs folder: on in a development build, off in a release one, until the switch says otherwise. HYDRA_RECORD=1 or 0 overrides the file, for a run from the terminal.
  • Keeping the player log: on unless switched off.
  • The theme: the one worn, Despana unless chosen; and, with Follow the computer on, a light one worn while the computer is in light mode.
  • Zoom: how large everything is drawn, 1 unless chosen; the title bar’s − and + step it by a tenth, between ZOOM_LEAST and ZOOM_MOST. One size for every window: egui draws them all at one zoom.
  • Volume: how loud every highlight’s sound plays, a percent, 100 unless chosen; a highlight’s own percent is of this.
  • Ebon Gate merchants: when one opens for business, a banner in the window of each character the game tells, and a notification from the computer, once however many it tells (crate::merchants); each on unless switched off.
  • Pictures in the story: the pictures scripts place there, on unless switched off; and the pictures folder a script’s files may be read from, with the folders inside it, none unless chosen (hydra_ui::picture).
  • The web page: off unless switched on, and the port it is served on, WEB_PORT unless chosen. On, any device on the home network that has the pairing can play; the hub shows the address.
  • Starting fresh: how many minutes after the last character stops, with no window open, Hydra starts itself again in the background, giving back all the memory its play held; FRESH_AFTER unless chosen, 0 never.
  • Updates: Hydra looks for a newer release as it starts and every few hours, on unless switched off, and the hub says when one is out. With Update on its own on, off unless switched on, it fetches one as soon as it is out, to run from Hydra’s next start.

The settings menu shows them as its Window page (Own::page), drawn as any other; no behavior is behind them, so the window makes a change itself (Own::change).
