hydra_board

Module looks 

Source
Expand description

A character’s own theme and accent, read from its settings file: the theme section the binary’s Theme page and .theme write ([Chosen]), which its windows wear in place of Hydra’s; and whether its creatures’ tags are shown (.targetid, [Shown]), how its container looks are sorted (.sorter, [Sorting]), and how short a typed line its history keeps, read with it.

The file is the binary’s to write; this reads it off the caller’s thread (crate::disk), once a second at most and only when its modified time has moved, and keeps the outfit worked out from it until the file, Hydra’s theme or the themes change.
