The board: what Hydra’s windows, its web page and its binary share, with no window toolkit in it.

Every character seated (Sessions, Seat): what its feed heard and its last snapshot, and the way to send it a line; the highlights its story looks through; the hotbars and the controller’s wheel as their files say, which the window and the page both resolve; and the files Hydra keeps for each character, read and written off the caller’s thread. Whatever draws the board wakes through Wake, which it fills in while it is open.
