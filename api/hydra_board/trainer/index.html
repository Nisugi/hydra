Expand description

One character’s skill trainer: what GOALS was asked for, and the skill manager it opened.

goals typed asks the game for the skill manager’s one-time link, and the link it answers with (<LaunchURL>) is the trainer’s: Hydra reads the page itself and the Skill trainer widget shows it. goals web asks the same and opens the link in the browser, the website’s own trainer: typed on the web page, the page’s browser, where the page offers it for a tap. A link nothing asked for opens in the browser too, as the game means, and only when it is play.net’s.

Profiles. A set of goals saved under a name (normal, ensorcell) and loaded again later, each goal stepped to its ranks as the website would. Kept per character beside its layout, in <game>_<name>.goals.json.
