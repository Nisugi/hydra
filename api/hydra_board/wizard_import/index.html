A Wizard front end folder brought into Hydra: its scripts as aliases, and where its profile’s macros and highlights are, for the keys and the highlights to be imported by their own readers.

§Scripts

A Wizard script (.Cmd or .Wiz) of the kind a player writes by hand is a list of lines to send, with waits between:

#pool-return.Cmd
put ;go bank
pause 2
put ASK attend TO RETURN %1
waitrt
put stow all box

That is what an alias’s target is ([hydra_session::alias]): the commands with \r between, a wait as s2, roundtime as rt, %1 and %2 as the words typed after the alias, \1 and \2. So each script becomes an alias named after its file, typed with the command symbol first as the Wizard ran it: .pool-return with the box’s name after it, the file’s name alone left to the game. A .Wiz whose name a .Cmd also has is named <name>-wiz.

Two more shapes are read. A script that runs another (put .nexus) has that script’s lines put in at that point, the .Cmd of the name first and the .Wiz when there is no .Cmd. A script that is one loop, a label on its first line and goto it on its last with a pause before the jump, becomes the alias of its lines, to be run on the clock as .every <pause> .<name>, which the import says.

The Wizard’s scripting language also has matching, other labels, counters and variables, which an alias has not; a script using them needs Lich, which runs Wizard scripts as they are, and is said, not imported. A line the reader does not know (a typo, fput) is said and skipped.
