Expand description

One character, for its windows.

Fields§

§id: u32

Its session’s number in the host table.

§name: String

The character’s name.

§game: String

The game it plays on, by its code (GS3): with the name, which character it is, since one name can be on two games.

§instance: Option<String>

The instance that game calls itself (Prime), which its layout is kept by; None for a game Hydra does not know.
