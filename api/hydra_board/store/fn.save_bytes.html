Function save_bytes 

pub fn save_bytes(dir: &Path, path: &Path, bytes: &[u8]) -> Result<(), Error>
Expand description

Write bytes to path in dir, atomically: to a temp file of this write’s own, synced, then renamed over path. Two writes of one file at once never rename each other’s half-written temp into place.

§Errors

The directory cannot be created, or the file cannot be written or renamed.
