hydra_board

Module highlights 

Source
Expand description

The highlights every character’s story looks through, shared between the window, which reads the file when it changes, and each character’s feed, which builds its own from them; and the desk that plays their sounds and shows their notifications, and what Hydra calls attention to beside them: an Ebon Gate merchant opening, told once however many characters hear it.

The feed runs whether the character’s window is open or not, so a character nobody is watching still sounds.
