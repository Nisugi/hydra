Module tuning 

Source
Expand description

How the controller feels: [controller_tuning] in the controller file. Every field is optional, and one not written is Hydra’s.

[controller_tuning]
movement_stick = "left"    # the stick that walks: left or right
opposing_stick = "scroll"  # the other, while no wheel is open: scroll or none
back_slice = "down"        # where Back sits in a wheel's folder, or none
deadzone = 50              # % a stick is pushed before a slice is aimed
aim_dwell_ms = 150         # held on a leaf this long, it is committed
nav_dwell_ms = 150         # held on a folder or Back, the wheel goes in or out
fire_debounce_ms = 300     # a fire this soon after the last is not sent
release_grace_ms = 40      # the walking stick stilled this long after a wheel closes
fire_mode = "release"      # how a leaf fires: release, edge or retract
edge_threshold = 90        # % out an edge leaf fires
retract_delta = 10         # % back from its furthest a retract leaf fires
trigger_open_pct = 60      # % an analog trigger is pulled to open its wheel
trigger_close_pct = 40     # % it falls under to let go
wheel_min_open_ms = 150    # a wheel stays open at least this long
