Module rumble 

Source
Expand description

The controller’s rumble: on roundtime or casttime ending, on being stunned, on dying, and when a highlight that names a pattern finds its words.

[controller_rumble]
enabled = true
roundtime_end = "short"   # hands free again
stunned = "long"
death = "double"

[[controller_rumble.patterns]]
name = "knock"
strength = 0.6            # 0.05 to 1
pulse_ms = 120            # each pulse, 20 to 2000
pulses = 3                # 1 to 8
gap_ms = 80               # between pulses, at most 2000

A pattern is off, one of Hydra’s three (short, long, double), or one of the file’s by name; Hydra’s win on a name both have. The events are the window with the keyboard’s character’s; a highlight’s are any character’s, at most one each HIGHLIGHT_GAP and the rest let go.
