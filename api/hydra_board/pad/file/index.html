A controller file: [controller], each bind’s key and what it does, and [controller_overlay], the binds the legend lists.

[controller]
south = { macro_text = "look\r" }          # commands, sent
east = { hotbar = "combat", button = "hide" }  # a hotbar's button
l2 = "controller_modifier"                 # held for chords
"l2+dpad_up" = "scroll_current_window_up_page"
select = "controller_overlay"

[controller_overlay]
buttons = ["l2", "l2+south"]

A macro’s text is sent as typed, a trailing \r or none alike, and a \r inside it parts two commands. An action is one of Hydra’s, by its keybinds name (scroll_page_up), or by the name a controller file written for Vellum gives it (scroll_current_window_up_page), so such a file works as it is. A hotbar’s button is pressed as a click on it would be, by its bar and its id or nickname; a wheel’s slice presses one with the command .hotbar <bar> <button>. The file’s other tables are the wheel’s, rumble’s and tuning’s, read where those are.
