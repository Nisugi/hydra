Module card

Expand description

The hub’s card design, as its file keeps it: a custom window’s inside (Custom) – widgets in cells, each a free rect, the inside’s size the card’s – that every character’s card is drawn from.

A custom window is a play window’s own model one level down: its widgets held bare, each in a cell kept from the inside’s top left, a cell one widget or a tab stack of several with one showing. Its geometry is kept in points as plain numbers; whatever draws it measures with them.

The design is kept in the data folder’s FILE; with no file, or one that does not read, the card is Hydra’s own (hydras).
