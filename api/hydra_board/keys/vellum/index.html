Vellum’s keybinds read: a keybinds.toml of Vellum’s – its global one, a character’s, or a named set – into Hydra’s set 0, since Vellum has no macro sets.

an actionHydra’s action for the same (ACTIONS)

Vellum’s own defaults are left. Vellum writes its shipped keys into every player’s global file, so a key found at one of them is Vellum’s, not the player’s, and keeps what Hydra has it do. What the player changed is brought.

Not carried, each said: an action Hydra’s keys have none for – the command line’s editing, which Hydra’s input does itself on its own keys; reading aloud, the sound and performance switches, interact mode, a controller’s; a macro naming <target_id> or <target_noun>, which Hydra has no target for; a key Hydra refuses, one that types. [menu], the keys of Vellum’s menus, is said where the player changed it, since Hydra’s menus take their own keys.
