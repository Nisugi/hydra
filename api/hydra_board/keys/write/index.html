hydra_board::keys

Module write 

Source
Expand description

The keys files’ writer: every character’s keybinds file, and a character’s own. The Keys page’s changes are made one at a time to a file’s text, a line at a time, so what a player wrote there by hand – a comment, the order – is kept. The result is read back first: a file this cannot change in place, a [keys] written as an inline table say, is refused rather than mangled.

A frontend makes a change to the text it holds at once, and the same change to the file with the next batch of saves (crate::store).
