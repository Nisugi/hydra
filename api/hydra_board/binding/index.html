What a key does: a macro is a keybind that sends one or more commands to the game, fills the command input, or performs one of Hydra’s actions.

A send macro’s text is cut into commands at each \r, each piece one command, empty pieces dropped, and a piece that is s and a number of seconds (s1.5) a wait before the rest. Each command is one line, as every key’s must be (hydra_ui::validate_line). A trailing \r means nothing: a macro’s kind, not its last character, says whether it is sent.
