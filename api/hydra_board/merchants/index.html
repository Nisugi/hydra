Module merchants

Expand description

An Ebon Gate merchant opening for business, called to the player’s attention as the Window page says: a banner in the window of each character the game tells, and a notification from the computer once, however many characters it tells.

The game tells every character logged in of the same merchant, each on its own connection, so the notification is made by the first of them to hear it and let go of for the rest (ONCE). An opening is the merchant’s name and the second the game gave it, so the same merchant opening again later is told again.

Constants§

ONCE
How long one merchant’s opening, told to one character, is the same opening told to another.

told
What a merchant’s opening says: their announcement, or where they work, or that they are open.
