Functions§

adopt_files
Every hotbars file in data, everyone’s and each character’s, whose buttons are not yet only places for macros, made so: each button of its own kept as a macro in the macros file beside it ([hydra_ui::macros::adopt]). The two files as they were are kept first, beside them, ending .before-macros. What was done, a line a file.
button_lines
The lines a button of the web page’s own sends, command being what the page keeps for it: one line per \r or \n, each trimmed, empty ones dropped. symbol is the character’s command symbol.
character_path
The file of the character name on instance, beside its layout.
hotbar_command
What pressing the bar bar’s button key sends in world, for the web page as for .hotbar; never a press of another button, symbol being the character’s command symbol.
hotbars_for
A character’s hotbars as its files have them now, for the web page: every character’s in data, the character name’s own (on instance) over it; a file that does not read gives none, and says why.
hotbars_paths
The files hotbars_for reads: every character’s, then the character’s own.
is_macro_run
Whether rest, after macro, names a macro to run, rather than one of the words the command line answers itself (hydra-table’s .macro).
named
The bar and the button a .hotbar line names, its command symbol and word taken off already: the bar, then the button, which may be words.
press
What pressing the bar bar’s button key (an id or a nickname) sends in world; or why nothing is.
presses_another
Whether command is .hotbar …, symbol being the character’s command symbol: a button that would press a hotbar.
put_bar
bar put in file in place of the bar named replacing, or of the bar of its own name, or after the rest; its name trimmed.
remove_bar
The bar named name taken out of the hotbars file at path, with the next batch of saves.
save_bar
bar kept in the hotbars file at path as put_bar puts it, with the next batch of saves (crate::store): made to the file as it then stands, read and written whole, so what it says that Hydra does not read is kept and its comments are not. A change refused then is the store’s to tell; put_bar on the bars as last read says so first.
take_bar
The bar named name taken out of file: whether it was there.
