The lookout: every line the game says that Hydra has not learned yet.

A GM’s script check is something out of the ordinary that asks for an answer. No pattern describes it: it is a line never seen before. So the lookout learns what is routine, and every line it has not learned goes to the lookout stream. Once the routine is learned the stream is all but silent, and a new line stands out. Nothing is ever sent to the game.

§How a line is judged

Cheapest test first (Lookout::judge):

  1. A resolution stat at or over the floor – an AS: +12000 no character reaches – is always shown, marked (Verdict::Stat).
  2. Left out: a stream the lookout does not read, a room’s description, and a line the ignore list takes.
  3. The sentence: the line with each game object in it a placeholder and every one of Hydra’s characters taken out, its digits and spaces dropped (key::sentence). Not learned, it is new.
  4. Each object in it, by its words (key::object). Not learned, it is new.
  5. The line is shown when its sentence or any object in it is new.

A sentence or an object is learned after it has come on Settings::occasions occasions. The same line heard by several of Hydra’s characters within Settings::window seconds is one occasion: a group of five must not learn a line the first time it comes.

§One set for a game’s characters

Every character of one game shares one set (open), kept in the data folder in a file of its own, lookout_<game>.bin (file): a hash of each learned key, and of each still learning its count and the day it last came. One still learning that has not come in Settings::forget_days days is dropped, which keeps the file small.

  • key: a line’s sentence and objects as keys, and their hashes.
  • settings: lookout.toml, the player’s choices.
  • file: the learned set on disk.
