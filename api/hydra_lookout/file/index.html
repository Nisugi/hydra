hydra_lookout

Source
Expand description

The learned set on disk: lookout_<game>.bin in the data folder.

Hashes alone, never the lines: a learned key is eight bytes, one still learning thirteen. Little-endian throughout.

"HYDRALK1"                      what the file is, and its version
u32 learned, then each u64
u32 learning, then each u64 key, u8 count, u32 day last come

Written to a file of its own and renamed over the old, so a write cut off leaves the last one whole.
