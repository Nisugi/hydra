hydra_survey

Module log 

Source
Expand description

The survey’s log: JSON Lines, append-only, one file per run, every record stamped with the run, the time, the server and the character.

Four kinds of record. A room is written once, on the first arrival: what the game states about it, and what the verbs asked there said in their own fields. A verb is one line asked and its reply verbatim. An edge is one exit walked: where it led, or how it was refused. An event is a death, a heal, a resume or a stop. The log is the survey’s only memory: a run resumes by reading it back.
