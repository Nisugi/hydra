hydra_survey

Module run 

Source
Expand description

The walk: every reachable room entered once, asked the verbs on its first arrival, and every exit of every room tried once in each direction, depth first, on the survey’s own map.

In a room with an exit left to try, the first is sent. In one with none, the nearest room that has one is reached over the edges already walked. When no room has one, the survey is done. A refused exit is logged with the game’s words and never sent again; one the game asks a wait or a stand for is sent again after it. Dead, the character says healme and goes on from where it stands. Hurt, it rests where it is.
