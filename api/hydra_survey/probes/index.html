What each verb’s reply says, read from its lines. The reply is logged verbatim either way; what is read here fills a room’s own fields and decides the survey’s next move, nothing more.

Functions§

analyzed_exits
The things anal room lists as exits, each as the game words it without its article. Empty when it sees none.
go_commands
The go commands for the ways out ways names, each a thing’s words and its noun, in order and without repeats. A noun named once is go <noun>; one that names more than one thing is told apart by the word before it (go fieldstone shop, go simple shop), as the game takes it, and by its place (go second shop) when those collide too. Each command with the thing’s words, so the thing can be found again in the room and sent by its id.
