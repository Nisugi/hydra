Crate hydra_survey 

Source
Expand description

The room survey: every room the character can reach walked once, asked what the game says of it, and logged, on a map of the survey’s own that owes nothing to the built-in one.

  • log: the run file, JSON Lines, and its records.
  • probes: what each verb’s reply says.
  • graph: the rooms seen, the exits left, the edges walked.
  • run: the walk itself.

Modules§

graph
The survey’s own map: the rooms it has seen under its own ids, the exits each still has to try, and the edges walked between them. Built as the walk goes, and built again from the log when a run resumes.
log
The survey’s log: JSON Lines, append-only, one file per run, every record stamped with the run, the time, the server and the character.
probes
What each verb’s reply says, read from its lines. The reply is logged verbatim either way; what is read here fills a room’s own fields and decides the survey’s next move, nothing more.
run
The walk: every reachable room entered once, asked the verbs on its first arrival, and every exit of every room tried once in each direction, depth first, on the survey’s own map.
