When a claim may be made, and whose: rewards.toml, and the rules over it, pure.

time = "19:05"                       # the local time to log in for the login reward at
skip = ["GS3:Dicate", "Nerten"]      # characters never logged in for it
store = true                         # the month's store Simucoins

The login reward and the store are two switches. The login reward is on when time is set; the store, when store is true (off when absent). With no file, neither is claimed. With a time, every character on the roster whose account has a kept password is logged in for, but for those skipped.

The rules, in the order they are asked:

  1. The set time has passed today (the player’s own clock).
  2. Hydra was running when it came, or has since sat idle for IDLE: nothing connected through it that long. A Hydra started after the time waits for the idle, so a launch to play is never met by a login of its own.
  3. The character’s account has no character connected through Hydra. The account is left alone while anyone is on it.
  4. Today’s reward (the game’s day, Eastern) is not already in.
