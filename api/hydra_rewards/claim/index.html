hydra_rewards

Module claim 

Source
Expand description

A login made for the reward alone: the game’s bytes read until the reward is told, or it is clear there is none to tell.

The caller has logged in and opened the game connection; this reads it. The game says the reward in the burst that follows the login, before the prompt that closes it. A prompt with no reward before it is the game’s way of saying it was given today already, but the lines and the prompt can come in either order across reads, so a prompt is waited on a moment before it is believed.
