The terminal’s widgets for the windows of a Vellum layout: each a struct filled with what it shows and drawn into its area. They are filled from a character’s state (feed.rs, lists.rs, panels.rs, text.rs), and each window’s frame is drawn once (crate::chrome), so a widget here draws its content alone.
