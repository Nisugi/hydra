hydra_tui::vellum

Module panels 

Source
Expand description

The panels, filled from a character’s state: the missing effects, the objectives, the spells and inventory streams, one container, the whole inventory, the Betrayer’s blood and a dialog of the game’s. Each is built for the frame and drawn into the inside of its window’s frame.

Functions§

betrayer
A Betrayer window drawn: its blood points, and its items when shown.
container
A container window drawn: the one the window names, as the game last listed it.
containers
A containers window drawn: everything carried, as a tree of what is in what, from the last whole-inventory snapshot.
dialog_panel
A dialog panel drawn: the game’s dialog the window names, as banded rows.
inventory
An inventory window drawn: the game’s inventory stream.
missing
A missing window drawn: every tracked effect that is not up, a click on one typing what puts it up.
quests
A quests window drawn: the objectives the game lists, a click on an action typing it.
spells
A spells window drawn: the game’s Spells stream, each spell a link.
