Module keys

Expand description

The keys, as the windows have them: Hydra’s defaults, every character’s keybinds file over them, and a character’s own file over that, in the macro set it has chosen (hydra_board::keys). A key pressed on a character’s screen does what its binding says before anything else sees it; one bound to nothing types, or moves the line, as keys do.

The files are read again when they change, looked at no oftener than every LOOK_EVERY: a key changed on the windows’ Keys page, or by hand, works here a moment later.

A terminal names the key that typed a character, not always the key: a numpad key is told apart only in the Windows console and in the terminals that speak the kitty keyboard protocol. A numpad key bound does its binding; unbound, it types its digit.

The files are changed here too (Files): by the Keys editor, and by .keys import, a Wrayth settings file’s key sets, and .keys vellum, a Vellum keybinds file’s keys (vellum), each into the character’s own keys or, with global, every character’s.

A change is made to the file as it then stands, with the batch of saves (hydra_board::store), so one made by the windows at the same time is kept too; the batch is written at once, so the keys pressed next do it, and the files are read again.
