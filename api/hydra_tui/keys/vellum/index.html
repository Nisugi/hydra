hydra_tui::keys

Module vellum 

Source
Expand description

A Vellum keybinds file read: the keys of its [user] table, each a key string and what it does, made Hydra’s. Vellum has one set of keys; they go into set 0.

A key string is its modifiers, ctrl+, alt+ and shift+, in any order and case, then the key: a name (enter, esc, page_up, left, f3), a numpad key (num_8, num_plus, or the older num_+), or a single character, taken as the key that types it on a US keyboard (] is BracketRight, ! is Shift and Digit1).

What it does is an action’s name, made Hydra’s action like it where Hydra has one, or { macro_text = "..." }, sent: its line ends at the end dropped, and a \r inside it parting one command from the next. The command line’s own editing (cursor_left and the rest) is the command line’s, and is never bound.
