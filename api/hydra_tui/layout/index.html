hydra_tui

Module layout 

Source
Expand description

A character’s screen in a terminal, laid out in Vellum’s layout format: a Vellum layout.toml reads as it is, and Hydra’s is one.

Each window (vellum_schema::WindowDef, tagged by widget_type) has its place by row and column, its chrome (border sides and style, title and where it sits, colours) and the widget it shows with that widget’s own settings. Hydra adds to the format only what Vellum has none of: a hydra window of one of its own widgets, a window that follows another character, and which hand a hand window shows. A window’s defaults are its widget kind’s: there are no window templates.

The layout keeps the size of terminal it was arranged for (terminal_width, terminal_height). A terminal of another size draws it scaled, every edge where it falls in proportion, so windows that touched still touch; a window a row or three tall keeps its height. A window this build does not know is kept and written back as it was.

Kept beside the character’s other files as <instance>_<name>.tui.toml in the data folder’s layouts, and by name for any character in layouts/tui/. A file that does not read is kept aside, not written over, and the screen starts from the default, Vellum’s sidebar layout. A layout Hydra wrote in its earlier form is read and written in this one.
