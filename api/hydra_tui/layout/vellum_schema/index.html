Module vellum_schema 

Source
Expand description

A terminal layout’s windows, in Vellum’s layout format: each window’s place and chrome (WindowBase), and the widget it shows with that widget’s own settings (WindowDef, tagged by widget_type). A Vellum layout file reads as it is.
