Work mode: the terminal’s screen covered, so that a glance at it shows a terminal at work and nothing of the game.

.work typed on a character’s screen covers it; .work off, or .work again, lifts the cover. .work on covers and .work off lifts, for a key bound to one or the other. While covered, nothing of the game is drawn, no menu or editor opens, the mouse does nothing, and the title is a shell’s; the command line is still the command line, drawn after a shell’s prompt, so what is typed goes to the game as always, and the characters play on.

The cover plays a scene: a shell running a job, line by line at a believable pace, with its names drawn afresh each time round. Four are shipped and written to global/work/ in the data folder the first time the cover goes up, where a player may change them or add their own: curl (repositories fetched and cloned), build (a Rust workspace compiled and tested), tail (a web server’s log followed) and ssh (a remote host’s journal). .work curl plays that one and keeps to it; bare .work plays one at random each time round. Nothing is fetched from anywhere: a progress meter is a formula, and the names are lists in the scene’s file.

One thing of the game does pass the cover: a line the lookout picked out (hydra_lookout), which may be a script check. It is written into the scene as its next line of output, in the scene’s own colour, with no mark: one odd line in a wall of output to anyone else, and the warning to the player, who knows to look.

A scene file:

title = "curl"                 # the terminal's title while this plays
prompt = "PS C:\\src{dir}> "   # {dir}: where the scene has gone
rest = 20                      # seconds idle at the prompt before it plays again

[names]                        # {repo}, {user}: one picked each time round
repo = ["fast-json-rs", "kube-rollout"]
user = ["mkdev", "lindqvist"]

[[lines]]
text = "git clone https://github.com/{user}/{repo}.git"
wait = 1.5                     # seconds after the line before
jitter = 1                     # at most this much more or less
color = "plain"                # plain, dim, green, yellow, red, cyan, magenta

[[lines]]
meter = "git"                  # a progress meter, redrawn in place
lasts = 8                      # seconds to reach the end

[[lines]]
text = "cd {repo}"
dir = "\\{repo}"               # the prompt's {dir} from here

[[lines]]
text = "{n:100-999} {hash}"    # a number in a range, a short commit hash
times = 40                     # the line again this many times, names drawn afresh

[[lines]]
text = "{date} {clock} ok"     # today, and the time of day as the scene has it

The clock is the real one, read when the cover goes up, and runs with it: {clock} is 14:36:10, {date} is 28/Oct/2026, {day} is Oct 28.
