Module overlay 

Source
Expand description

What shows over a terminal’s screen and takes its keys while it does: a form, an editor, a list to choose from, the main menu. They stack: the one on top has the keys and the mouse, and closing it shows the one beneath. Escape closes the one on top unless it says otherwise.

The main menu (F10, or the ≡ at the foot) opens Hydra’s own: the settings, the highlights, the hotbars, the theme, the keys, the web page, the performance log, and Shut down. Over a character’s screen it holds that screen’s too: Windows (show or hide each, add a widget, edit one, arrange) and Layouts (load one kept, save this one, fit it to the terminal).
