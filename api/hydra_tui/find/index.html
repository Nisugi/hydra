Module find 

Source
Expand description

Finding words in a window of text: Ctrl+F, then F3 and Shift+F3 for the next and the one before.

The find line opens at the foot of the window in use when it is text, or of the story when it is not, and takes the command line’s keys while it is open. The lines that hold what is typed, whatever its case, are found and what they hold is marked, the current one’s in the accent. The current one counts from the newest, so the first found is the latest said: F3, and Enter in the line, go back to the one found before it; Shift+F3 and Shift+Enter forward again. The window is brought to the current one each time it moves. The line says which it is, 2 of 11. Escape closes it.
