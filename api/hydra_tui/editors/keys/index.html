Module keys 

Source
Expand description

The keys editor, over a terminal’s screen: every key a macro set binds, Hydra’s own among them in set 0, each with what it does, whose file says so, and Hydra’s default. Opened over a character’s screen it is that character’s keys, its own file over every character’s; over the hub’s, every character’s alone.

On the list, Enter changes what the key marked does: commands sent, \r between two and s1.5 a wait; the input filled; or one of Hydra’s actions, Tab stepping between the three. n binds a new key, pressed rather than named, and m moves the marked key’s macro to another key pressed; a key that types is refused, as the file refuses it, and Escape stops the wait. Delete unbinds the key; r takes its line out of its file, so what is beneath does again. 0 to 9 show a macro set. Over a character, g moves a key between its own file and every character’s, and s uses the set shown over set 0; over the hub, p switches whether the numpad sends its keys with NumLock on too.

Each change is written at once (crate::keys::Files), and the keys pressed next do it.
