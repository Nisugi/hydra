hydra_tui

Module wire 

Source
Expand description

What a terminal and Hydra say to each other over the instance’s loopback port, once the terminal has asked for a screen (hydra-tui).

The terminal sends what the player does – each key, paste, mouse event, resize – and Hydra sends each frame drawn, as the bytes the terminal writes; and asks the terminal to copy text or open a link, which only the terminal’s own computer can do.

Each message is a frame: its kind (a byte), its length (four bytes, little-endian) and its payload. A drawn frame’s payload is the bytes to write; every other is JSON. No frame is longer than MOST.
