Module seat

Expand description

One character’s screen: its layout’s windows, and its command line at the foot. What was typed is sent as the windows send it; the keys do what the keybinds say (keys.rs), Hydra’s own by default: the arrows walk the history, Page Up and Page Down scroll the window in use, Tab finishes what is typed or targets the next creature.

One window is in use, framed in the accent: what scrolls, and what the tab keys turn. A click on a window puts it in use; F6 and Shift+F6 go round them too. A tab with lines it has not shown is marked *. F2 arranges the windows (arrange.rs).

A link clicked does what the windows do: a command link sends its command; an object link whose coord= names a command sends that; any other asks the game for the object’s menu, _menu #<id> <n>, sent without an echo, and the menu it answers with shows over the screen (hydra_ui::object_menu); a web address is opened by the terminal.

Ctrl+F finds words in the window in use (find.rs); a drag over a window chooses its text and copies it (select.rs). The banners the highlights raise show over the top of the windows while they last.

The screen’s own commands, typed with the character’s command symbol: arrange (as F2), savelayout <name>, loadlayout [<name>], and layout import <Vellum layout file>, layout fit, layout default.
