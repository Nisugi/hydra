What a cast asked for does: the checks it passes or is refused by, the stance it is cast from, its verb, and the commands it sends.

The checks, in order; a refusal is said and nothing is sent:

  • the spell is known: refused only when the game’s own list of the character’s spells says it is not (a society power is not on that list, and is never refused here);
  • with conserve: mana enough for every cast asked for (Mana Leech, 516, needs only 1), and an attack spell’s target a live one here;
  • with safety: an attack spell with a live target in the room.

An attack spell is any whose roles include attack: attack/area (410) and attack/utility (516) as well.

A live target is one the game lists as a target that is in the room and not dead, leaving out an animated one (but for animated slush) and a creature’s limb (but for a kraken’s named tentacle). A target typed is found among them as the game would: kobold the last that fits, second kobold (or other kobold) the second, and two words the first, then anything, then the second (great kobold).

The stance: the spell’s own, or its alias’s; else offensive for an aimed spell while the stance option is on; else none.

The verb: the spell’s own, or its alias’s; else cast. While the channel option is on, a spell that can be channeled is channeled, and evoked with channel evoke.

The commands:

targetverbsent
nonecastincant N [count]
noneanotherincant N <verb> [count]
onecastprepare N, then cast <target> [count]
oneanothertarget <target>, then incant N <verb> [count]

A spell that is never incanted (410, incant='no') is prepared and cast instead. A society power sends the line the game knows it by, the target after it when it takes one.
