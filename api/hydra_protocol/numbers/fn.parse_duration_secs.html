Parse a time= countdown into whole seconds.

Buffs, debuffs and cooldowns carry time='00:00:37', and a consumer that wants to know when a cooldown expires needs a duration rather than the string. Parsing belongs in this crate, so the conversion is here.

The wire form is uniform: every time= value seen in recorded sessions matches HH:MM:SS. MM:SS is accepted too, because it costs one line and the alternative is silently returning None if the game ever drops the hour. Anything else is None rather than a guess – a fabricated duration is the same class of lie as the fabricated maximum above.

use hydra_protocol::numbers::parse_duration_secs;

assert_eq!(parse_duration_secs("00:00:37"), Some(37));
assert_eq!(parse_duration_secs("01:02:03"), Some(3723));
assert_eq!(parse_duration_secs("soon"), None);
