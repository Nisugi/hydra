The frame vocabulary: what the wire can say.

A Frame is one thing the game said, typed. The list of variants is the protocol’s vocabulary as Hydra understands it; crate::tags lists the tag names behind it.

§What is deliberately not a frame

  • Client-side inventions. Tags a client injects into its own log, and events a client raises from user-configured patterns over text, are not wire vocabulary. A protocol parser whose output depends on a user’s config file is not a protocol parser; game meaning belongs above this layer, consuming frames. A client tag that does reach the wire falls to Frame::UnknownTag.
  • One variant per widget. The dialog widget tags (buttons, controls, drop-downs, fields, label lists, progress bars) are one shape – “the game sent a widget tag with these attributes” – so they are one payload::DialogWidgets keyed by the tag name. Frame::DialogOpen and Frame::DialogPanelOpen are separate; they carry a dialog, not a widget.
  • A variant nothing constructs. Every variant here is produced by the parser. Dialogs not yet modelled (injuries as a popup, the quickbar’s entries, the target drop-down) come back with their handlers, in one change, when they are needed.

Frame::UnknownTag, Frame::MalformedTag and Frame::Structural are Hydra’s own: the first two so a protocol change or a broken tag is visible rather than dropped or mistaken for prose, the third so the tags that carry no payload of their own are seen too. Frame::ClientCommand and Frame::ClientSettings type the regions a log carries around the player’s own commands and the login’s settings blob, and Frame::CmdListUpdate and Frame::CmdTimestamp the dictionary rows that keep the game’s command labels current.

§Presentation is not here

The Frame is the vocabulary boundary; this crate carries wire shape, not render intent:

  • There is no render class (normal, link, monsterbold, spell, speech). The preset id travels as data in Style::preset instead, so a preset the game invents tomorrow needs no change in this crate.
  • Colours are not resolved here. A palette is user configuration, and resolving it would make the same bytes give different frames under a different theme, which is disqualifying for a replay test. This crate emits the markup structure and the layer that draws resolves colour.
  • A link’s kind is a real enum, LinkKind, not a marker stuffed into a string. Which URL schemes may be opened is click-safety policy and belongs with the layer that opens browsers.
