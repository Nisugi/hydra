Crate hydra_report 

Source
Expand description

A report as blocks. A report crate says what it shows: a heading, a card of facts, a table with typed columns, a chart of bars or lines, a note, or plain lines. A front end draws each block its own way: the Reports window as real tables and painted charts, a terminal or an export as the text Report::text renders. A link is a command, as a cell or inside a line, and a front end runs it when clicked.

Text lines carry a link as \u{1}text\u{2}command\u{3}, the markup the combat reports write; Report::text keeps it, so whatever reads the text rendering finds the links where they were.
