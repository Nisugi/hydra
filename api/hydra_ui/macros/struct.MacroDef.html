Expand description

One macro.

Fields§

§name: String

Its name, one word: what a button, a key and .macro run it by.

§chain: String

Its commands: the chain, as the file’s commands (or chain).

§key: Option<String>

A key that runs it, written as the keybinds file writes a key.

§set: Option<u8>

The macro set its key is in, 0 to 9; none, every set.

§alias: Option<String>

A word that runs it from the command line, kept as an alias.

§when: Option<Condition>

The condition it runs under; none, always. Not holding, the macro is unavailable: a button greys, and a press runs nothing.

§repeat_after: Option<f32>

Seconds that must pass after it ran before it runs again; none, as often as pressed.

§once_per_room: bool

Runs once in a room: pressed again there, it runs nothing until the character has moved.

§tooltip: Option<String>

What a hover says.

§countdown: Countdowns

What it counts down, when a button shows it.

§states: Vec<MacroState>

Its states, in order: the first whose condition holds decides.

§label: Option<String>

What a button shows; none, its name.

§default_style: Option<Style>

A button’s look while no state holds, and beneath a state’s.

§icon: Option<Icon>

A button’s icon.

§icon_mode: IconMode

A button’s face: its label, its icon, or both.

§rest: BTreeMap<String, Value>

Anything a later Hydra keeps here, kept as it is.
