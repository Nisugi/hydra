Module macros

Expand description

Macros: the player’s chains, each with the logic, a key, an alias word and its states. A macro is the core a keybind, an alias word and a hotbar button are three doors into: the key for the hands, the word for the command line and Lich, the button for the eyes.

The file is macros.toml, in the data folder for every character and beside a character’s layout for that one; a character’s macro replaces every character’s macro of the same name, whole.

[[macros]]
name = "barrage"
commands = "stance off, rt, weapon barrage" # the chain language (hydra_session::steps)
key = "F5"                                 # a key that runs it, as the keybinds write one
set = 1                                    # in this macro set; none, every set
alias = "wb"                               # a word that runs it from the command line
when = { type = "vital", vital = "stamina", cmp = ">=", value = 60, unit = "absolute" }
                                           # runs only when this holds; else unavailable

[[macros.states]]
when = { type = "vital", vital = "stamina", cmp = "<", value = 60, unit = "absolute" }
unavailable = true                         # a press runs nothing: a reserve kept back

[[macros.states]]
when = { type = "indicator", id = "stunned" }
chain = "stance def"                       # runs this instead

when is the macro’s condition: not holding, the macro is unavailable and a press runs nothing. Its states are more logic, the first that holds deciding: unavailable, or another chain.

A macro is a hotbar’s button (crate::hotbar): a bar’s slot only names it. Its label (its name unless given), icon, icon_mode and default_style are how the button looks, and a state’s style how it looks while that state holds; unavailable, the button is dim.
