Expand description

The effect lists as their widgets show them, whatever draws them: the effects of a list that are up, one row a name, the player’s own timers filed with them; and the colour an effect’s bar wears for the spell circle its spell is in.

Circles. A Minor Spirit spell’s bar one colour, a Wizard spell’s another, so a glance at a list tells which circles are up. The colours are the character’s, one for every effect list, kept with the layout and shown on each list’s page as a table of circle and colour. Hydra starts with a palette over the circles a character casts from; a row removed leaves its circle in the list’s own colour, and the table emptied leaves every bar so. An effect’s spell is found by the effect’s name, as the spell table names it; an effect that is no spell, or a tracked effect given a colour of its own, is not coloured by its circle.
