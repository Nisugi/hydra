Source
Expand description

Where a picture placed in the story may come from: what a <sagaImage src=> may lead to, decided before anything is fetched or read.

Three sources are taken:

  • An https:// address, on any host. Plain http is not: what a script shows the player is not sent in the clear.
  • A data URI of one of the four kinds a frontend draws, data:image/png;base64,... (or jpeg, gif, webp): a script’s picture carried in the line itself.
  • A file in the player’s pictures folder, or a folder inside it: named from that folder (pumpkin.png, ebon/pumpkin.png), or by a path or file: address that lies inside it. Nothing outside the folder is read, and no file at all while no folder is set.

The rule here is on the name alone. A link inside the folder that leads out of it is caught where the file is read, by its real path (within).
