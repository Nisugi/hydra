Module room 

Source
Expand description

The room as its widgets show it, whatever draws it: its name and number, its description with what is here run on after it, who else is here, the ways out; the creatures to target, the others, and who is fighting.

What the game wrote comes as runs, its links kept; each creature, object and player named apart is a link to it by its id, in the colour it is given. Which creatures are targets, what is said of each, and which side each fighter is on are read here off the model, so every front end lists the same.
