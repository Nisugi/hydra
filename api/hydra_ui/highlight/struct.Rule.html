Fields§

§category: String

The group it is listed in, and switched off with.

§text: Option<String>

The words it looks for: several with | between them, each trimmed (Nisugi | Ashryn); one alone, as written. A | to look for takes a pattern, \|.

§regex: Option<String>

A pattern it looks for instead (Rust’s regex: no look-around).

§case_sensitive: bool

Capitals count.

§whole_word: bool

The words only where they stand alone, not inside another word.

§color: Option<String>

The colour it paints, #rrggbb.

§background: Option<String>

The ground it paints under, #rrggbb.

§line: bool

It paints the whole line, not only what it found.

§squelch: bool

The line is hidden.

§substitute: Option<String>

The words found written instead as this: $1, $2 the pattern’s groups.

§redirect: Option<String>

The line sent to this stream’s windows, out of the story.

§copy: bool

The line redirected is kept where it was as well.

§flag: Option<Mark>

A flag set or cleared: what a condition’s flag reads.

§send: Option<String>

Game commands sent: \r between two, $1 and $2 the pattern’s groups, which may fill a command’s words but never choose the command. Never Hydra’s or Lich’s commands.

§approved: Option<String>

For one an import brought: the send the player approved. A send is sent only when it is the one approved.

§status: Option<Mark>

A custom status lit or put out: shown in the Custom statuses widget, and read by a condition’s indicator as the game’s own are.

§sound: Option<String>

A sound to play: a file name in the sounds folder.

§volume: Option<u8>

How loud the sound plays, a percent of the window’s volume: 100 unless said.

§alert: Option<Say>

A banner over the story.

§notify: Option<Say>

A notification from the computer.

§speak: Option<Say>

Words spoken aloud by the computer’s voice.

§rumble: Option<String>

A rumble of the game controller, by its pattern’s name: short, long, double, or one of the controller file’s.

§picture: Option<String>

A picture placed in the story after the line it found: an https:// address, a data URI, or a file in the pictures folder, as a script’s is (crate::picture).

§cooldown: Option<f64>

Seconds before its sound, banner or notification comes again; 3 unless said.

§timer: Option<String>

A timer of the player’s own, by name, that its words – the timer’s up message – start: the Timers widget counts it down. .timer <name> starts it too.

§seconds: Option<u32>

How long its timer runs unless the up message says: its default duration, in seconds.

§caught: Option<String>

"$1": the up message says how long, the number its pattern’s first group caught ("$2" the second’s), in place of the default.

§times: Option<u32>

What a number caught is multiplied by: 5 for rounds of five seconds.

§down: Option<String>

The timer’s down message: words that end it, as text finds them.

§list: Option<String>

The list its timer shows in: active spell, buff, debuff, cooldown, or custom, the player’s own, unless said.

§when: Option<Condition>

What must hold of the character for it to act: a line found while it does not hold is left as it is. With no words to look for, it is a condition alone, acting each time it comes to hold.

§rearm: Option<f64>

A condition alone acts again only once it has not held this many seconds; 3 unless said.

§characters: Vec<String>

Whose it is, by name or GAME:Name; none, everyone’s.

§origin: Option<String>

Where it came from, when an import brought it: importing that file again replaces what it brought.

§off: bool

Switched off.
