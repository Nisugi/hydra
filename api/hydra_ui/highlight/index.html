Module highlight 

Source
Expand description

Highlights: words or a pattern in what the game says, and what Hydra does when they come – colour them or their whole line, hide the line, play a sound, raise a banner, show a notification.

Display and attention alone: conditions, sends, substitutions, redirects and flags are automation, and automation is Lich’s job.

§The file

One file in the data folder, highlights.toml: a [highlight."name"] table for each, and [categories] switching a category off whole.

[categories]
"Wrayth ignores" = false

[highlight."Friends"]
category = "Friends"
text = "Nisugi | Ashryn"   # words; `|` between several
color = "#ecc013"
background = "#311c1c"
case_sensitive = true
whole_word = true
line = false          # the whole line, not only the words
sound = "ding.wav"    # a file name in the data folder's sounds folder
alert = true          # a banner of the line; or alert = "words to show"
notify = "Nisugi!"    # a notification from the computer; or true
squelch = false       # hide the line (an alert still comes)
characters = ["GS3:Ashryn"]   # whose; none, everyone's

§Moving a line

A line is sent to another stream by the stream rules (hydra_session::stream_rules), never by a highlight. A highlight’s redirect, from a file written before or an import, is made a stream rule when Hydra reads the file (HighlightFile::redirects) and taken off the highlight.

§Where it is applied

Once, as each line of the game’s is finished in a character’s story (crate::Story), before any window draws it: the story’s lines and every stream’s. The player log keeps what the game said.
