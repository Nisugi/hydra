Module theme

Expand description

The palette’s tokens: every colour Hydra draws, named by what it means, and a palette holding a colour for each.

A token names a meaning, never a screen: health, not the bar in the vitals window. A frontend asks the palette for a token’s colour and draws with it; a theme fills the palette from its recipe and pins. Until one does, Palette::bare holds Hydra’s plain colours over egui’s own dark mode: not a theme, and never shipped as one.

Beside the tokens: the harmony generator (harmony.rs, oklch.rs), theme files (file.rs), a theme’s shape (shape.rs) and type (typeface.rs), a character’s own theme (Chosen) and Wrayth’s colours (wrayth.rs).
