Expand description

A request from a hub, for whoever runs the sessions.

A session is named by its number in the host table.

Variants§

§

Add(String)

Start this character: one the hub offered as available.

§

Remove(u32)

Quit this session and take it off the table.

§

Reconnect(u32)

Log this stopped session’s character back in.

§

Shutdown

Shut Hydra down in order, as Ctrl-C does.

§

Login(Login)

Log a character in by what the player typed. Only the window’s hub asks it: no wire message carries it, so a password never crosses a socket.

§

Forget(String)

Take this character off the roster, named as the roster names it.

§

ForgetPassword(String)

Forget the password kept for this account.

§

Favourite(String, bool)

Star this roster character as a favourite, or unstar it.

§

Nickname(String, String)

Call this roster character, named as the roster names it, by this nickname where it is tagged; empty, by its name.

§

Characters(Account)

List the characters an account has on one game. The binary answers with a line and gives the window the Listing. Only the window’s hub asks it, as it does HubRequest::Login.

§

Remember(Saved)

Put this character on the roster without playing it.

§

Settings(String)

A character’s settings pages, named as the roster names it (GAME:Name): the binary gives them to the window, and says nothing.

§

Change(Change)

Change one setting on a character’s page; the binary says what it did and gives the window the pages as they are now.

§

SaveTeam

Keep this team: a new one, or the one named was, perhaps renamed.

Fields

§was: Option<String>

The name of the team it replaces, when it is an edit.

§team: TeamCard

The team as it is to be kept.

§

ForgetTeam(String)

Forget the team of this name.

§

LaunchTeam(String)

Start the team of this name: each of its characters not already playing, with its kept password, its windows where the team keeps them.

§

Restart

Shut Hydra down in order and start it again, the hub open: so an update fetched runs. With again, the characters playing start again with it, each with its team.

Fields

§again: bool

The characters playing start again.
