Expand description

What a window shows of one character’s story.

Fields§

§lines: VecDeque<(Stamp, Shown)>

The story, oldest first, each line with when it arrived.

§dropped: u64

Lines dropped from the front, ever: the first kept line’s number.

§said: VecDeque<String>

Hydra’s messages, oldest first, for Hydra’s own pane.

§heard: u64

Lines of the game’s heard, ever: a tab not showing counts how many came since it last did.

§told: u64

Hydra’s messages told, ever, for the same.

§streams: Streams

Each stream’s own lines, for a widget of it.

§menu: Option<(u64, Menu)>

The game’s last answer to a menu asked for on this connection, and how many came before it, for a request to know one after it.

§flags: Flags

The flags the triggers set.

§statuses: Flags

The custom statuses the triggers lit.

§perf: Perf

How quick the window is, stage by stage.
