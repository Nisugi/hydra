Module frame 

Source
Expand description

A frame: a picture drawn round a window, a card, or a custom window’s cells, composed from a library of parts by a recipe.

The frames folder, global/images/frames/ in the data folder, the tree the studio and Hydra read alike, holds the player’s own library in parts/ (edges/, stickers/ and ornaments/ of PNGs), their recipes beside it, and installed packs in packs/<pack>/, each a library and recipes of its own. A frame is a recipe, <name>.toml, naming an edge, a sticker for each kind of junction (corner, tee, cross) and any number of ornament rules, each saying which sides it goes on and where along them. A recipe finds a part in its own library first, then every pack’s, then the player’s own. Every part is authored for the top run (the edge horizontal, the corner sticker top-left, the tee sticker’s stem pointing down) and turned for the other sides, by rotation or by mirroring as the recipe says.

Frame::lay places the pieces round a set of touching cells: a run of edge along every line, drawn once where two cells share it and reaching half a thickness through each junction so the runs meet under the sticker; the sticker for each junction’s kind, centred on it; and the ornaments where their rules put them. The drawing is a toolkit’s: this module only says where each piece goes and which way it faces.
