Module condition 

Source
Expand description

Conditions: what a character’s state is tested for, before a trigger acts, or by itself as a trigger of its own.

A tree, type-tagged, as a controller or hotbar file written for Vellum writes one, so those read as they are:

when = { type = "all", conditions = [
    { type = "vital", vital = "health", cmp = "<", value = 50 },
    { type = "not", condition = { type = "rt_active" } },
    { type = "effect_active", category = "Buffs", name = "Celerity" },
] }

all and any hold conditions; not turns one over. The tests: an effect up or not (effect_active, effect_inactive) and how long it has (effect_time), roundtime and casttime (rt_active, ct_active), a status indicator (indicator, standing, stunned, hidden…), a vital by percent or amount (vital), a body part’s wound or scar (injury), a spell the vitals pay for (spell_affordable), the time of day in the game (time_of_day), a hand empty or holding a kind or name of thing (hand_empty, hand_holds), a spell prepared (spell_prepared), and Hydra’s own: a flag a trigger set (flag), the room by its title (room) and the stance (stance).

What is not known is false. A vital not yet told, an effect list the game never filled, an indicator never reported: each test reads false, so not of it reads true. An indicator never reported reads inactive, so { type = "indicator", id = "poisoned", active = false } holds from the start.
