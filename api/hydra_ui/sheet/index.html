hydra_ui

Module sheet 

Source
Expand description

The character sheet in words, whatever draws it: the gauges the game words, the vitals Hydra works out (field experience, the Betrayer panel’s blood points), and the lines its widgets say – level, training points, the experience numbers, society, resources, objectives and the world’s events. Each reads a fact the model already holds; a line the game has not told yet says so.
