Module printed 

Source
Expand description

The game state’s print: everything the model holds for a character, as GameState’s {:#?} prints it, read as a tree, and one value found in it by its path.

So no field is left off, and a field added to the model shows with no change here. A field is found by its path through the print: each step a field’s name, or an item’s place in a list, [2]. The print has no names of its own to keep a choice by: a field the model renames is “not found” until it is picked again.

What is said of a value is the value alone, as plainly as the print allows: Some(42) is 42, None is —, a quoted string its words; a list or a record says how many it holds.

The committed fixtures, folded together, print about 600 KB: 15,676 lines, formatted in 6 ms in a debug build. So a print is taken at most once each EVERY, not every frame, and kept for whatever reads it (Prints): every widget and card field drawing one character shares its print.
