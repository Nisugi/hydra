pub fn run_token(run: &StyledRun) -> Option<Token>
Expand description

Which colour of the theme’s draws run, when its own does not: the creature colour for a bold one (the game’s bold marks a creature, as the bold preset colours it), else a link’s (Token::Link, or Token::Command for one that sends a command), else its preset’s (preset_token); None for the text colour. A link comes before a preset so that one in a room’s description or in speech is seen as a link.
