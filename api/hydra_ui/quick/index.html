Module quick

Expand description

The quick bar, whatever draws it: one widget for the game’s quick bars, a script’s, and the player’s own pages.

The game sends its bars as dialogs of links – quick (the main one), quick-combat and quick-simu – and says which to show with <switchQuickBar id=> (the model keeps it as Dialogs::quick_bar). A Lich script opens a bar of its own the same way, a dialog at location='quickBar' – foreach.lic’s, quick-foreach-1, says how far it has come – shown while it is open and gone when the script closes it. Every page there is to show: the game’s, a script’s, then the player’s own, each a list of links made on the widget’s settings page.

Which page shows. The game’s switch, until the player picks one of their own; the pick holds until the game switches again, then the game’s shows. Picking the game’s bar or a script’s asks the game to switch, _qlink change <id>, as Wrayth does: the game sends that bar afresh, and a script listening for it answers for its own. A bar is its labels, separators and links. A link sends its command as if typed – a script’s as the player’s own, a game’s once checked; a game link whose command is url: opens that page of play.net instead.
