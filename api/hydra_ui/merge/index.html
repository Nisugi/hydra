Module merge 

Source
Expand description

Shared streams, merged across characters, for the hub’s Chat card.

  • The same line is a duplicate line. A thought on a channel reaches every listening character verbatim, and so does another player’s speech in a room two characters share. Identical text on the same stream from two characters is one line.
  • Within one second. A repeat after that is a new line, as is a repeat heard by the same character.
  • Tagged by character, each by its key, GAME:Name, so the line says whose it was and the hub can call them by their nicknames.
  • A line said to one of them reads as the others read it. Kiyna says to you, "hi" to Nisugi is Kiyna says to Nisugi, "hi" to Dicate: one line, matched by putting each copy said to its receiver into that third-person form (addressed), which is also the form shown, since “you” on a shared card names nobody. Own speech (You say) stays its own line.

Every stream read alongside the story (crate::story::STREAMS) merges, and those of the player’s own the stream rules make that a card shows (MergedHistory::merge_also); which of them a card shows is the card’s. Pure: the caller supplies the clock, so the window is testable.
