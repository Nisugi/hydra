hydra_ui

Module widget 

Source
Expand description

The catalog of widgets, with no toolkit in it: each kind a player can place, what it is called, which of the Add-a-widget list’s groups it is in, the size it would like and the palette’s token its bar fills with. A new kind is a variant and a line in each table here.

Widgets are individual things: a bar for health is a widget, a bar for stamina is another, and each hand is its own. A layout keeps them by these names, so a variant’s serde name never changes.

The status indicators and the game’s lists of effects, each a widget of its own (Indicator, Category), and the clocks they and the pulse say, are here too.

The pulse as a clock at server second now: seconds to its earliest, then below zero, how late it is, until it comes and the clock starts again: 20 counting down to 0, then -1, -2, -3, until the pulse comes.

What the pulse bar says at server second now, and how full it is: a countdown from the pulse to the earliest the next can come, 45 seconds, which goes on below zero until it does – “Pulse 20s”, “Pulse 0s”, “Pulse -12s”, the next coming by -30 – and a mark, ✦, when the next brings mana; the bar filling as it nears and full once it is due; name asking before the first pulse or the game’s clock.
