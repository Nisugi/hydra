Module finds 

Source
Expand description

The rare finds reported, each against the searches it took: ascension gemstones and dust off the listed creatures, keys and locks and legendary treasures off any creature.

A search is a searched, mugged or fled row. For gemstones and dust only a listed creature’s counts (crate::ascension), the Onslaught’s invaders shown apart. The week turns Sunday midnight Eastern and the month on the first, as the game’s gemstone limits do: one a week, three a month, and a character is eligible while under both.
