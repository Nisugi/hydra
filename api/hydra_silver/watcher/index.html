Module watcher

Expand description

Lines in, transactions heard out.

A line reaches the watcher as the runs of text the parser cut it into; it is assembled here and read when the line ends, with the ids of the objects it linked. The withdraw line typed is kept, so the note the teller writes for it, which states no amount, is recorded for the amount asked.

Coin piles are followed across the household (Piles): a search or mug of this character’s that states silver drops a pile, and the pile is the coins the room shows that it did not show before. The game sends the room’s objects at the head of the blob, before the search’s own lines and the prompt that ends it, so the pile is shown before the line that states it: a pile shown since the last prompt and claimed by nobody is the drop’s, else the next pile the room shows is. The prompt forgets the piles nobody claimed. A drop no pile answers within those seconds landed on a pile already there, which the game keeps as one: it grows that pile, when the room holds exactly one, and stays the first finder’s. A pile this character picks up, by hand or by the fossil charm, is then this character’s own (nothing more to record: the search already did), another household character’s (recorded as picked up, with the finder named, not as new silver), or unknown (the charm’s line states what it held; a hand pickup states nothing).
