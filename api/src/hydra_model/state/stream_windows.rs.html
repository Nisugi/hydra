1//! What a stream's text does when its window is **closed**: the wire's own
2//! rule, read off `<streamWindow ifClosed= styleIfClosed=>`.
3//!
4//! # The question this answers
5//!
6//! When a stream arrives with an `ifClosed=` attribute, that attribute says
7//! what to do with the stream's text if its window is closed. It is the whole
8//! of this problem, in four lines:
9//!
10//! ```text
11//! <pushStream id="speech"/><preset id='speech'>You <a ...>say</a></preset>, "Yep."
12//! <popStream/>
13//! <preset id='speech'>You <a ...>say</a></preset>, "Yep."
14//! <prompt time="1790052928">&gt;</prompt>
15//! ```
16//!
17//! The same sentence twice: once inside the `speech` stream, once in the main
18//! window. A renderer that shows both prints everything the character says
19//! twice.
20//!
21//! **That is not a defect in the game.** `speech` is declared `ifClosed=''`,
22//! and the protocol's documentation says what that means: *"The stream is a
23//! duplicate -- the server also sends the same line to main, so the closed
24//! window's copy drops harmlessly"*. The duplicate is the wire keeping a
25//! promise to a client that has a speech window open. A client without one
26//! is supposed to drop the copy.
27//!
28//! # The four behaviours, MEASURED
29//!
30//! The protocol names four. All four are here in real traffic -- census over
31//! **208** recorded sessions, **157,220** `<streamWindow>` tags:
32//!
33//! | behaviour | declaration | streams seen |
34//! |---|---|---|
35//! | [`Closed::Drop`] | `ifClosed=''` | `room` 77,411 · `society` 1,087 · **`speech` 201** · `inv` 162 · `Spells` 86 · `announcements` · `bounty` · `loot` · `reserve` · `charprofile` |
36//! | [`Closed::Styled`] | `styleIfClosed='x'`, no `ifClosed` | `thoughts` → *thought* 86 · `familiar` → *watching* 86 |
37//! | [`Closed::Main`] | neither | `main` 77,497 · `death` 86 · `logons` 86 |
38//! | [`Closed::Route`] | `ifClosed='<window>'` | **none** -- see below |
39//!
40//! **`Route` is UNVERIFIED.** The documentation cites `voln → thoughts →
41//! main-as-thought` and no recorded character declared one, so it is
42//! implemented from the documentation and labelled rather than claimed. It
43//! is also the only behaviour that chains, which is why [`Windows::route`]
44//! is written as a loop with a visit-set rather than a `match`.
45//!
46//! **`ambients` inverts the usual shape** -- `ifClosed` absent,
47//! `styleIfClosed` **present and empty** -- which the documented table does
48//! not name. Read here as [`Closed::Main`]: an empty style is no style, and
49//! falling through unstyled is what the `Unspecified` row does anyway.
50//!
51//! # Why `ifClosed=''` and a missing `ifClosed` cannot be one case
52//!
53//! They mean opposite things -- drop the text, versus show it in main -- so
54//! this module lives or dies on telling them apart. `Attrs` is
55//! `Vec<(String, String)>` (`frame.rs`), so an empty value survives as
56//! `Some("")` and an absent one is `None`. VERIFIED against the parser:
57//! `speech` reads `Some("")`, `logons` reads `None`.
58//!
59//! Collapsing them -- `attrs.get("ifClosed").unwrap_or_default()` -- would make
60//! every `Unspecified` stream drop its text, losing `death` and `logons`
61//! entirely. Absent is not empty.
62//!
63//! # This decides routing; it does not decide windows
64//!
65//! Whether a window is *open* is a frontend fact, so it is a parameter rather
66//! than state here. `streams.rs` keeps the same line: a map of buffers and a
67//! routing rule, with layout left to the UI. This module adds the second
68//! half of that rule -- the part that needs to know what the window would have
69//! been for.
70
71use std::collections::{BTreeMap, BTreeSet};
72
73use hydra_protocol::frame::Attrs;

75/// What happens to a stream's text when its window is closed.
76#[derive(Clone, Debug, PartialEq, Eq)]
77pub enum Closed {
78    /// `ifClosed=''`: the line is a **duplicate**. The server sends the same
79    /// text to main as well, so this copy is dropped.
80    ///
81    /// This is `speech`, and showing it as well as main shows every spoken
82    /// line twice.
83    Drop,
84    /// `ifClosed='<window>'`: send it to that window instead, which may itself
85    /// be closed -- so this chains.
86    ///
87    /// **UNVERIFIED against live traffic.** The documented example is
88    /// `voln → thoughts`; the 208-file census found no `Route` declaration.
89    Route(String),
90    /// `styleIfClosed='x'` with no `ifClosed`: falls through to main, wrapped
91    /// in that style. The classic inline-thoughts look.
92    Styled(String),
93    /// Neither attribute: falls through to main, unstyled.
94    Main,
95}
96
97impl Closed {
98    /// Read the behaviour off a `<streamWindow>`'s attributes.
99    ///
100    /// Order matters: `ifClosed` is checked before `styleIfClosed`, because
101    /// the documented `Exclusive` row is *"`ifClosed` absent, `styleIfClosed`
102    /// set"* -- a stream carrying both is routed, not styled.
103    #[must_use]
104    pub fn read(attrs: &Attrs) -> Self {
105        let value = |name: &str| {
106            attrs
107                .iter()
108                .find(|(key, _)| key == name)
109                .map(|(_, value)| value.as_str())
110        };
111        match value("ifClosed") {
112            // Present and empty: a duplicate the server also sent to main.
113            Some("") => Self::Drop,
114            Some(window) => Self::Route(window.to_owned()),
115            // An EMPTY `styleIfClosed` is no style: `ambients` declares it that
116            // way, and an unstyled fall-through is `Main`.
117            None => match value("styleIfClosed") {
118                Some("") | None => Self::Main,
119                Some(style) => Self::Styled(style.to_owned()),
120            },
121        }
122    }
123}

125/// Where a line should actually go, once the closed-window rule is applied.
126#[derive(Clone, Debug, PartialEq, Eq)]
127pub enum Destination {
128    /// Its own window, which is open.
129    Window(String),
130    /// The main window, unstyled.
131    Main,
132    /// The main window, wrapped in this style.
133    MainStyled(String),
134    /// Nowhere: the server already sent this text to main.
135    Dropped,
136}
137
138/// What each stream declared it does when closed.
139///
140/// A map rather than a fixed table, because the ids are the game's: the census
141/// found 16 declared against 8 ever pushed to, and a frontend must not
142/// assume either set is closed. An
143/// undeclared stream is not an error -- see [`Self::route`].
144#[derive(Clone, Debug, Default, PartialEq, Eq)]
145pub struct Windows {
146    declared: BTreeMap<String, Closed>,
147}
148
149impl Windows {
150    /// Record a `<streamWindow>` declaration.
151    ///
152    /// Later declarations replace earlier ones: `main` and `room` are
153    /// re-declared on **every room move** (77,497 and 77,411 of the census's
154    /// 157,220 tags), carrying the room name as a subtitle, so this runs
155    /// constantly and must be idempotent rather than accumulate.
156    pub fn declare(&mut self, id: &str, attrs: &Attrs) {
157        self.declared.insert(id.to_owned(), Closed::read(attrs));
158    }
159
160    /// What a stream declared, if it declared anything.
161    #[must_use]
162    pub fn declared(&self, id: &str) -> Option<&Closed> {
163        self.declared.get(id)
164    }
165
166    /// Where a line on `stream` should go, given which windows are open.
167    ///
168    /// `is_open` is the frontend's answer, asked rather than stored: whether a
169    /// window is on screen is not a fact about the game.
170    ///
171    /// # An undeclared stream goes to main
172    ///
173    /// Not dropped. The census found **16** declared ids: windows are
174    /// declared far more widely than they are pushed to -- so a stream nobody
175    /// declared is likelier to be one this build has
176    /// not seen than one the server means to suppress. Dropping on a guess
177    /// would lose text; showing it in main is recoverable and visible.
178    ///
179    /// # The chain terminates
180    ///
181    /// [`Closed::Route`] can point at a window that is also closed, and the
182    /// documented example is two hops (`voln → thoughts → main`). Nothing
183    /// stops a server -- or a third-party tool injecting windows, which is
184    /// indistinguishable by design -- from declaring a cycle.
185    /// A visited set makes that terminate at main rather than hang.
186    #[must_use]
187    pub fn route(&self, stream: &str, is_open: &impl Fn(&str) -> bool) -> Destination {
188        // The main window is not a stream with a fallback; it IS the fallback.
189        if stream.is_empty() || stream == MAIN {
190            return Destination::Main;
191        }
192        let mut at = stream.to_owned();
193        let mut seen = BTreeSet::new();
194        loop {
195            if is_open(&at) {
196                return Destination::Window(at);
197            }
198            if !seen.insert(at.clone()) {
199                // A cycle among closed windows. Main is the only safe answer.
200                return Destination::Main;
201            }
202            match self.declared.get(&at) {
203                Some(Closed::Drop) => return Destination::Dropped,
204                Some(Closed::Styled(style)) => return Destination::MainStyled(style.clone()),
205                Some(Closed::Route(next)) => at.clone_from(next),
206                // Declared as plain fall-through, or never declared at all.
207                Some(Closed::Main) | None => return Destination::Main,
208            }
209        }
210    }
211}

213/// The main window's stream id.
214///
215/// The wire writes main-window text with an **empty** stream, and names the
216/// window `main` in `<streamWindow id="main">`. Both are handled by
217/// [`Windows::route`], which is why this is one constant and not two.
218pub const MAIN: &str = "main";

220impl crate::GameState {
221    /// Apply a `<streamWindow>`: **two independent facts ride one tag.**
222    ///
223    /// The room's name, on the `room`/`main` re-title that fires on every move
224    /// (MEASURED: 77,497 and 77,411 of the census's 157,220 tags), and what
225    /// this stream does when its window is closed. Both are recorded; only the
226    /// first can change the room.
227    ///
228    /// Here rather than in `state.rs`'s `apply` -- move code down, do not
229    /// raise the cap (`split_parents_stay_facades` holds `state.rs` to it).
230    /// Takes the whole frame rather than its three parts, so the
231    /// destructuring lives here too rather than in `apply`'s match arm.
232    pub(super) fn apply_stream_window(&mut self, frame: &hydra_protocol::Frame) {
233        let hydra_protocol::Frame::StreamWindow {
234            id,
235            subtitle,
236            attrs,
237            ..
238        } = frame
239        else {
240            return;
241        };
242        self.stream_windows.declare(id, attrs);
243        self.name_room(id, subtitle.as_deref());
244    }
