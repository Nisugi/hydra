1//! Someone's familiar, companion or summon: a creature that is nobody's
2//! target, whatever a hunt's `any` says.
3//!
4//! # The gap this closes
5//!
6//! A hunt skips a creature the server calls unhostile (`hostile() ==
7//! Some(false)`). One with no `<crtrStatus>` yet -- registered off a combat
8//! line, `creatures.rs`'s choice 2 -- reads `None`, and a target list
9//! holding `any` would attack it. The object-type table
10//! (`data/gameobj-data.tsv`) has no `familiar` or `companion` type, so these
11//! are their tables.
12//!
13//! # The tables
14//!
15//! | [`Ally`] | read from | the table |
16//! |---|---|---|
17//! | `Familiar` | the name | 34 families (`FAMILIARS`) |
18//! | `Companion` | the noun | 128 nouns (`COMPANION_NOUNS`) |
19//! | `Demon` | the name | minor demons and the illusions they wear (`DEMONS`, `ILLUSIONS`) |
20//! | `Passive` | name or noun | `data/gameobj-data.tsv`'s `passive npc` |
21//!
22//! **Spirit servants are `Passive`.** Every spirit servant name, across 93
23//! demeanors by 39 kinds, is already `passive npc` in the object-type table,
24//! MEASURED, so they need no table of their own.
25//!
26//! # Three rules outrank the tables
27//!
28//! 1. **The server.** A creature the wire calls `hostile` is a foe, and
29//!    [`CreatureInstance::ally`] answers `None` for it: a creature that can be
30//!    targeted is always treated as hostile.
31//! 2. **Named exceptions.** A name ending `abyran'ra` or `slush` is hostile.
32//! 3. **The bestiary.** A name with a template, a boon adjective stripped as
33//!    the bestiary retries, is a creature of the world and nobody's. A fixed
34//!    list of excluded companion names would go stale: MEASURED, five
35//!    templates carry a companion noun (`mongrel wolfhound`, `storm hound`,
36//!    `vapor hound`, `water hound`, `wharf rat`), and two templates spell a
37//!    familiar (`large black cat`, `large ring-tailed lemur`). So the
38//!    bestiary is the exclusion.
39//!
40//! # Igaesha
41//!
42//! The Igaesha pattern matches `a cloud of {color} {subtype}`, the names the
43//! game gives it, with any color words between `cloud of` and the subtype.
44//!
45//! # What stays UNVERIFIED
46//!
47//! Whether the game's own target list (`dDBTarget`, `targeting.rs`) already
48//! leaves these out. INFERRED that it does, not measured.
49

285/// The wild-animal illusions.
286const ILLUSION_PATTERN: &str =
287    r"^(?:lazy wild .+ dog|listless .+ jackal|docile .+ coyote|languid .+ wolf|mangy .+ fox)$";

289/// Names never called friendly.
290const HOSTILE: &str = r"(?:abyran'ra|slush)$";
291
292struct Tables {
293    familiar: Pat,
294    demons: [Pat; 3],
295    illusion: Pat,
296    hostile: Pat,
297}
298
299fn tables() -> &'static Tables {
300    static T: OnceLock<Tables> = OnceLock::new();
301    T.get_or_init(|| Tables {
302        familiar: Pat::new(&format!("^(?:{})$", FAMILIARS.join("|"))),
303        demons: DEMONS.map(Pat::new),
304        illusion: Pat::new(ILLUSION_PATTERN),
305        hostile: Pat::new(HOSTILE),
306    })
307}

309/// Whose a creature is by its display name and noun. `None`: nothing says
310/// it is anyone's, which is not proof that it is a foe.
311///
312/// Stateless: [`CreatureInstance::ally`] adds the server's word.
313#[must_use]
314pub fn classify(name: &str, noun: Option<&str>) -> Option<Ally> {
315    let t = tables();
316    if t.hostile.is_match(name) || in_bestiary(name) {
317        return None;
318    }
319    if t.familiar.is_match(name) {
320        return Some(Ally::Familiar);
321    }
322    if noun.is_some_and(|n| COMPANION_NOUNS.contains(&n)) {
323        return Some(Ally::Companion);
324    }
325    if ILLUSIONS.contains(&name)
326        || t.illusion.is_match(name)
327        || t.demons.iter().any(|d| d.is_match(name))
328    {
329        return Some(Ally::Demon);
330    }
331    crate::state::gameobj::classify(noun.unwrap_or_default(), name)
332        .is("passive npc")
333        .then_some(Ally::Passive)
334}
335
336/// A bestiary template has this name, or has it with a boon adjective
337/// stripped.
338fn in_bestiary(name: &str) -> bool {
339    !by_name(name).is_empty() || without_boon(name).is_some_and(|n| !by_name(&n).is_empty())
340}
341
342impl CreatureInstance {
343    /// **Whose is it?** Someone's familiar, companion, summon or a passive
344    /// NPC by its name and noun, looked up when it was first seen.
345    ///
346    /// `None` when the server has called it `hostile`, whatever its name
347    /// (rule 1 in the module doc), and when nothing says it is anyone's.
348    /// So `None` is not proof of a foe: it is the ordinary answer for every
349    /// creature a hunt fights.
350    #[must_use]
351    pub fn ally(&self) -> Option<Ally> {
352        if self.flag(Classification::Hostile) {
353            return None;
354        }
355        self.ally
356    }
357}
