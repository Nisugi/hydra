1//! Creature facts only a line of prose states: a kill that leaves no
2//! corpse, a boss that leaves by a portal, a boss's phase, and the two spell
3//! marks a hunt tracks by creature ([`SpellMark`]).
4//!
5//! # The gap this closes
6//!
7//! A hunt loots what [`CreatureInstance::corpse`] calls a corpse and fights
8//! what [`CreatureInstance::valid_target`] allows, and both read the wire's
9//! flags and hit points. Three endings come with no flag to say so:
10//!
11//! - **Implosion (720) vaporizes** its target: instant death, no body.
12//! - **The Empyrean captain leaves by a portal**, a departure with no `<d>`
13//!   direction, so `departure.rs` cannot see it and
14//!   [`Creatures::vanished_unaccounted`] would report it as hiding.
15//! - **The captain's corpse fades**, "leaving nothing behind", some seconds
16//!   after it collapses.
17//!
18//! And one boss changes by phase: the cold wyrm on the ground, in the air,
19//! or with its scales disrupting energy attacks.
20//!
21//! # The lines
22//!
23//! | fact | the line |
24//! |---|---|
25//! | [`Ending::Vaporized`] | `Rather abrupt decompression causes X to explode`, `Blast disperses the X into a fine mist`, `X inverts as the intense vacuum rips it to shreds` |
26//! | [`Ending::Portal`] | the captain, a `portal`, then `disappearing from sight`, `vanishing`, `winks away` or `dives into it` |
27//! | [`Ending::Collapsed`] | the captain `collapses` |
28//! | [`Ending::Faded`] | `fading away with a final shimmer`, `leaving nothing behind` |
29//! | [`BossPhase`] | the cold wyrm `plummets toward the ground` ... `radiating wall of devastation`; `launches herself into the air`; `Corruscations of color` ... `disrupting the attack` |
30//! | [`SpellMark`] | `is suddenly surrounded by a blood red haze` / `The blood red haze dissipates from around`; `visibly struggling against` or `in awe of` `your radiant aura!` / `recovers from being rebuked` |
31//!
32//! A mark is laid and lifted by the creature's own bold link on the line,
33//! and never by name. It is forgotten when the character leaves the room,
34//! including by `You bolt`, which a move follows.
35//!
36//! The captain's flee wording is randomised per encounter, so the pattern
37//! keys on the captain, the portal and a vanishing verb; and its death is
38//! two lines about 35 seconds apart, the collapse and then the fading
39//! corpse. They are read apart, because only the second leaves nothing.
40//!
41//! # Which creature
42//!
43//! The line's first bolded object (`text.rs`'s `creature`): bold is
44//! the wire's mark for a creature. A mark line that links none is not
45//! applied, as a vaporization is not. A captain or wyrm line that links none
46//! falls back to the one creature in the room whose name holds the boss's;
47//! none or two, and the line is not applied. A vaporization needs its link.
48//! Only a creature the registry knows is changed, as with a departure.
49//!
50//! # Read on arrival, and a room listing outranks it
51//!
52//! `streams.rs` reads each line as it arrives, beside the hiding and group
53//! readers and for their reason: order. A `room objs` listing that names the
54//! creature after the line says it is here, and [`Creatures::apply_room_objs`]
55//! clears its ending; the wire outranks an inference. A listing before the
56//! line cannot. The phase is not cleared: the wyrm is listed on every
57//! refresh and stays in the phase the last line stated.
58//!
59//! # What an ending changes
60//!
61//! - [`CreatureInstance::valid_target`] is false: dead or gone.
62//! - [`CreatureInstance::corpse`] is true only for [`Ending::Collapsed`].
63//! - A killed ending puts the creature on the death watch, and the sweep
64//!   emits its `Fact::Dead` once, so the kill is counted though no `dead`
65//!   flag may ever come.
66//! - [`Ending::Portal`] is also a departure with no direction:
67//!   [`Creatures::fled`] answers `Some(None)`.
68//!
69//! # UNVERIFIED
70//!
71//! - **Every line's wire shape.** No committed fixture carries one; the
72//!   tests are synthetic lines built from the patterns.
73//! - Whether a vaporized creature is ever listed again with `dead="1"`. If
74//!   it is, the relisting rule makes it a corpse again.
75//! - Whether the captain's corpse can be looted before it fades.
76//!   [`Ending::Collapsed`] says it can.
77//! - The wyrm's phase is the latest phase line's. Weighing several recent
78//!   lines would give the same answer whenever one phase line is in view.

87/// How a creature left the fight, when only prose says so.
88#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
89pub enum Ending {
90    /// Killed and destroyed at once, by Implosion: no corpse ever lies.
91    Vaporized,
92    /// Killed, and its corpse lies until it fades: the Empyrean captain's
93    /// defeat.
94    Collapsed,
95    /// Its corpse faded away, leaving nothing behind.
96    Faded,
97    /// Left through a portal, alive: the Empyrean captain's retreat.
98    Portal,
99}
100
101impl Ending {
102    /// Did it die? All but [`Self::Portal`].
103    #[must_use]
104    pub const fn killed(self) -> bool {
105        !matches!(self, Self::Portal)
106    }
107
108    /// Is there a body to loot? Only after [`Self::Collapsed`].
109    #[must_use]
110    pub const fn leaves_corpse(self) -> bool {
111        matches!(self, Self::Collapsed)
112    }
113}

115/// A boss's phase, as the last line about it stated. Only the cold wyrm
116/// states one.
117#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
118pub enum BossPhase {
119    /// Plummeted to the ground with a radiating wall of devastation.
120    Grounded,
121    /// Launched herself into the air.
122    Airborne,
123    /// Colour playing along her scales, disrupting the attack.
124    Shielded,
125}

127/// A spell's mark on a creature that only a line of prose states, so a hunt
128/// can skip a cast the creature already carries.
129#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
130pub enum SpellMark {
131    /// Corrupt Essence (703): `is suddenly surrounded by a blood red haze`,
132    /// until `The blood red haze dissipates from around` it.
133    BloodRedHaze,
134    /// Aura of the Arkati (1614): `visibly struggling against` or `in awe of`
135    /// your radiant aura, until it `recovers from being rebuked`.
136    Rebuked,
137}
138
139impl SpellMark {
140    /// The spell that lays it.
141    #[must_use]
142    pub const fn spell(self) -> u32 {
143        match self {
144            Self::BloodRedHaze => 703,
145            Self::Rebuked => 1614,
146        }
147    }
148}

150/// What one line states about a creature.
151#[derive(Clone, Copy, Debug, PartialEq, Eq)]
152pub enum Stated {
153    /// It left the fight.
154    Ended(Ending),
155    /// It is in this phase now.
156    Phase(BossPhase),
157    /// A mark was laid on it (`true`) or lifted (`false`).
158    Marked(SpellMark, bool),
159}
160
161/// The four mark lines, lowercased (they are matched case-insensitively),
162/// each with the mark and whether it lays or lifts it. Plain substrings: the
163/// only markup on these lines is the creature's bold link, which
164/// [`creature`] reads.
165const MARK_LINES: [(&str, SpellMark, bool); 5] = [
166    (
167        "is suddenly surrounded by a blood red haze",
168        SpellMark::BloodRedHaze,
169        true,
170    ),
171    (
172        "the blood red haze dissipates from around",
173        SpellMark::BloodRedHaze,
174        false,
175    ),
176    // Two wordings of the same rebuke.
177    (
178        "visibly struggling against your radiant aura!",
179        SpellMark::Rebuked,
180        true,
181    ),
182    ("in awe of your radiant aura!", SpellMark::Rebuked, true),
183    ("recovers from being rebuked", SpellMark::Rebuked, false),
184];
185
186/// The mark a line lays or lifts, if any.
187fn mark_in(text: &str) -> Option<(SpellMark, bool)> {
188    let text = text.to_lowercase();
189    MARK_LINES
190        .iter()
191        .find(|(phrase, _, _)| text.contains(phrase))
192        .map(|(_, mark, on)| (*mark, *on))
193}

195/// A creature fact one line states, and whom it is about.
196#[derive(Clone, Copy, Debug, PartialEq, Eq)]
197pub struct Told {
198    /// The creature's `exist` id, from the line's first bolded object.
199    pub id: Option<i64>,
200    /// The boss the pattern names, lowercased: for a line that links no
201    /// creature, the one creature in the room whose name holds it. `None`
202    /// for a vaporization or a mark, which need their link.
203    pub boss: Option<&'static str>,
204    /// What the line states.
205    pub stated: Stated,
206}

208/// The captain's name, as creaturewindow's patterns spell it, lowercased.
209const CAPTAIN: &str = "battle-worn empyrean captain";
210/// The wyrm, as creaturewindow's patterns name it.
211const WYRM: &str = "cold wyrm";
212
213struct Patterns {
214    vaporized: Pat,
215    portal: Pat,
216    faded: Pat,
217    collapsed: Pat,
218    grounded: Pat,
219    airborne: Pat,
220    shielded: Pat,
221}
222
223fn patterns() -> &'static Patterns {
224    static P: OnceLock<Patterns> = OnceLock::new();
225    P.get_or_init(|| Patterns {
226        // Three wordings, over the plain text.
227        vaporized: Pat::new(
228            r"Rather abrupt decompression causes .+ to explode|Blast disperses the .+ into a fine mist|inverts as the intense vacuum rips it to shreds",
229        ),
230        portal: Pat::new(
231            r"(?i)battle-worn Empyrean captain.*?portal.*?(?:disappearing from sight|vanishing|wink(?:s|ing)? away|dives? into it)",
232        ),
233        // The fading corpse, then the fall: read apart.
234        faded: Pat::new(
235            r"(?i)battle-worn Empyrean captain.*?(?:fading away with a final shimmer|leaving nothing behind)",
236        ),
237        collapsed: Pat::new(r"(?i)battle-worn Empyrean captain.*?collapses"),
238        grounded: Pat::new(
239            r"(?i)cold wyrm plummets toward the ground.*radiating wall of devastation",
240        ),
241        airborne: Pat::new(r"(?i)cold wyrm's muscles bunch and she launches herself into the air"),
242        shielded: Pat::new(
243            r"(?i)Corruscations of color play along a silver-scaled cold wyrm's scaled hide.*disrupting the attack",
244        ),
245    })
246}

248/// The creature fact a line states, if it states one. `text` is the line's
249/// plain text, rendered once by the caller.
250#[must_use]
251pub fn read(line: &ChunkLine, text: &str) -> Option<Told> {
252    let p = patterns();
253    let (boss, stated) = if p.vaporized.is_match(text) {
254        (None, Stated::Ended(Ending::Vaporized))
255    } else if p.portal.is_match(text) {
256        (Some(CAPTAIN), Stated::Ended(Ending::Portal))
257    } else if p.faded.is_match(text) {
258        (Some(CAPTAIN), Stated::Ended(Ending::Faded))
259    } else if p.collapsed.is_match(text) {
260        (Some(CAPTAIN), Stated::Ended(Ending::Collapsed))
261    } else if p.grounded.is_match(text) {
262        (Some(WYRM), Stated::Phase(BossPhase::Grounded))
263    } else if p.airborne.is_match(text) {
264        (Some(WYRM), Stated::Phase(BossPhase::Airborne))
265    } else if p.shielded.is_match(text) {
266        (Some(WYRM), Stated::Phase(BossPhase::Shielded))
267    } else if let Some((mark, on)) = mark_in(text) {
268        // A mark needs its link.
269        (None, Stated::Marked(mark, on))
270    } else {
271        return None;
272    };
273    let id = creature(line).and_then(|c| c.id.parse().ok());
274    Some(Told { id, boss, stated })
275}

277impl Creatures {
278    /// Apply what one line of prose states about a creature ([`read`]).
279    /// The creature's id when it applied.
280    pub(crate) fn read_prose(&mut self, line: &ChunkLine, text: &str) -> Option<i64> {
281        let told = read(line, text)?;
282        let id = match told.id {
283            Some(id) => id,
284            None => self.only_in_room(told.boss?)?,
285        };
286        let creature = self.instances.get_mut(&id)?;
287        match told.stated {
288            Stated::Phase(phase) => creature.phase = Some(phase),
289            Stated::Marked(mark, true) => {
290                creature.marks.insert(mark);
291            }
292            Stated::Marked(mark, false) => {
293                creature.marks.remove(&mark);
294            }
295            Stated::Ended(ending) => {
296                creature.ending = Some(ending);
297                if ending == Ending::Portal {
298                    self.note_fled(id, None);
299                }
300                if ending.killed() {
301                    self.watch_for_death(id);
302                }
303            }
304        }
305        Some(id)
306    }
307
308    /// Every mark is forgotten on leaving the room: a mark that lifts out of
309    /// sight is never seen to lift.
310    pub(super) fn forget_marks(&mut self) {
311        for creature in self.instances.values_mut() {
312            creature.marks.clear();
313        }
314    }
315
316    /// The one creature in the room whose name holds `boss`, if exactly one
317    /// does.
318    fn only_in_room(&self, boss: &str) -> Option<i64> {
319        let mut found = self
320            .in_room()
321            .filter(|c| c.name.to_ascii_lowercase().contains(boss))
322            .map(|c| c.id);
323        let first = found.next()?;
324        found.next().is_none().then_some(first)
325    }
326}

328impl CreatureInstance {
329    /// **How it left the fight**, when a line of prose said so.
330    ///
331    /// `None`: no line did, the ordinary case, and the flags and the roster
332    /// answer. A room listing that names it again clears it.
333    #[must_use]
334    pub const fn ending(&self) -> Option<Ending> {
335        self.ending
336    }
337
338    /// **Its boss phase**, as the last line about it stated.
339    ///
340    /// `None`: no phase line seen, which is not [`BossPhase::Grounded`].
341    /// Whether it is flying is also a `<crtrStatus>` status, when the wire
342    /// sends one ([`StatusName::Flying`](crate::StatusName::Flying)).
343    #[must_use]
344    pub const fn phase(&self) -> Option<BossPhase> {
345        self.phase
346    }
347
348    /// **Whether a line has laid this mark on it** and none has lifted it
349    /// since, in this room.
350    ///
351    /// `false` is also "no line seen": a creature with no mark gets the cast.
352    #[must_use]
353    pub fn marked(&self, mark: SpellMark) -> bool {
354        self.marks.contains(&mark)
355    }
356
357    /// A room listing named it: it is here, whatever a line said.
358    pub(super) const fn relisted(&mut self) {
359        self.ending = None;
360    }
361}
