1//! A creature seen to leave: **read off the markup, not matched against prose.**
2//!
3//! # The room gives a link with the id
4//!
5//! The bestiary's 1,067 flee lines, 802 of them with `{direction}`/`{pronoun}`
6//! placeholders, are matchable (`creature_message.rs`) -- but they are the
7//! wrong tool for *this* question. MEASURED on the wire:
8//!
9//! ```text
10//! <pushBold/>A <a exist="8365650" noun="ghast">cadaverous tatterdemalion ghast</a><popBold/>
11//! leans back on <pushBold/><a exist="8365650" noun="ghast">his</a><popBold/> haunches
12//! and bounds <d>southwest</d>.
13//! ```
14//!
15//! Both facts a departure carries are **in the markup**:
16//!
17//! | fact | where | not |
18//! |---|---|---|
19//! | which creature | the `<a exist=>` id, twice -- the pronoun is a link too | a name looked up in a table |
20//! | which direction | a bare `<d>` command link | a word matched from a list |
21//!
22//! So this reads the frame. No bestiary lookup, no placeholder expansion, no
23//! ambiguity about which of two creatures with the same name left, and a
24//! creature whose flee line nobody has recorded is handled exactly as well as
25//! one whose line is in the table.
26//!
27//! # The markup separates all three, and that is MEASURED
28//!
29//! Leaving a room carries a direction in `<d>`; arriving does not, and
30//! hiding does not. Measured over eight large combat logs, counting lines
31//! that carry a creature link:
32//!
33//! | shape | lines | carry a direction `<d>` |
34//! |---|---|---|
35//! | departure | 195 | **195** |
36//! | arrival | 142 | **0** |
37//! | hide | 38 | **0** |
38//!
39//! So a direction link beside a bolded creature link **is** a departure, and
40//! no prose is needed to tell it from the other two.
41//!
42//! # What this still requires, and why
43//!
44//! A bare `<d>` also appears in room descriptions and `<compass>`, and carries
45//! `go bridge` and `climb wall` as well as directions. So [`classify`] requires
46//! **a bolded creature link** *and* a `<d>` whose text is one of the eleven
47//! directions. Bold is the wire's own mark for a creature
48//! (`state/room.rs`); an unbolded `<a exist>` is an item or a player.
49
50use hydra_protocol::frame::LinkKind;
51
52use super::lines::ChunkLine;

54/// A creature the feed showed leaving.
55#[derive(Clone, Debug, PartialEq, Eq)]
56pub struct Departure {
57    /// The creature's `exist` id, from its link.
58    pub id: i64,
59    /// The direction it took, from the `<d>` link, lowercased.
60    pub direction: String,
61}
62
63/// The departure a line shows, if it shows one.
64///
65/// Requires a **bolded** creature link and a direction link in one line. Bold
66/// is the wire's own mark for a creature (`state/room.rs:207`), and requiring
67/// it is what keeps a clickable direction in a room description from reading as
68/// something leaving.
69#[must_use]
70pub fn classify(line: &ChunkLine) -> Option<Departure> {
71    let mut creature = None;
72    let mut direction = None;
73
74    for run in &line.runs.runs {
75        let Some(anchor) = &run.link else { continue };
76        match &anchor.kind {
77            // The creature. Bolded, and the FIRST such link: the line repeats
78            // the id on the pronoun, and both are the same creature anyway.
79            LinkKind::Exist { id, .. } if run.style.bold_depth > 0 && creature.is_none() => {
80                creature = id.parse::<i64>().ok();
81            }
82            // The direction. A bare `<d>` carries its command as its text,
83            // which for a movement link IS the direction.
84            LinkKind::DirectText if direction.is_none() => {
85                let word = anchor.text.trim().to_ascii_lowercase();
86                if is_direction(&word) {
87                    direction = Some(word);
88                }
89            }
90            _ => {}
91        }
92    }
93
94    Some(Departure {
95        id: creature?,
96        direction: direction?,
97    })
98}

100/// Whether a `<d>` link's text is a direction a creature can leave by.
101///
102/// The list includes `out` -- not a compass point, and without it every
103/// such line would be unmatchable.
104/// Checked rather than accepted, because a bare `<d>` also carries `go bridge`,
105/// `climb wall` and worse.
106#[must_use]
107pub fn is_direction(word: &str) -> bool {
108    matches!(
109        word,
110        "north"
111            | "south"
112            | "east"
113            | "west"
114            | "up"
115            | "down"
116            | "out"
117            | "northeast"
118            | "northwest"
119            | "southeast"
120            | "southwest"
121    )
122}
