1//! What `appraise` and `measure` say about the one thing they are aimed at:
2//! the two replies a hunt reads before a sacrifice and a briar raise.
3//!
4//! Stateless readers over the reply's text, for the behavior that sent the
5//! command and holds its reply lines. Nothing here is folded into
6//! [`GameState`](super::GameState): the answer is about one command, and the
7//! behavior that asked is the one that acts on it.
8//!
9//! # `appraise #id`, and which line is read
10//!
11//! The reply runs from a line matching `The <creature> is <size> in size` to
12//! the prompt, and the verdict is read off the reply's **last** line, which
13//! is the size line only when the reply is one line. A creature reads
14//! `enticingly frail` when it can be sacrificed; the other verdicts are
15//! `susceptible to manipulation`, and a soul `stalwart and formidable`,
16//! `firmly bound` or `indomitable`. No committed fixture carries an
17//! `appraise` reply: the shape is UNVERIFIED here.
18//!
19//! Blank lines are skipped when finding the last line, so a reply that ended
20//! in a blank line still reads its verdict. Whether one ever does is
21//! UNVERIFIED.
22//!
23//! # `measure #id`
24//!
25//! Each reply line is tested for `to be about N percent.`, any case, and the
26//! weapon is raised at 100. That is one line's question, so
27//! [`measured_percent`] takes one line. No committed fixture carries this
28//! reply either.
29
30/// The line `appraise` opens with: `The <name> is <word> in size`.
31///
32/// Anchored at the line's start; the size word is ASCII letters, digits and
33/// `_`.
34#[must_use]
35pub fn is_appraise_size(line: &str) -> bool {
36    let Some(rest) = line.strip_prefix("The ") else {
37        return false;
38    };
39    rest.match_indices(" in size").any(|(at, _)| {
40        rest.get(..at)
41            .and_then(|head| head.rsplit_once(" is "))
42            .is_some_and(|(name, word)| {
43                !name.is_empty()
44                    && !word.is_empty()
45                    && word.bytes().all(|b| b.is_ascii_alphanumeric() || b == b'_')
46            })
47    })
48}

50/// Whether an appraised creature reads **enticingly frail**, the test for
51/// `sacrifice`, over the reply's lines before the prompt.
52///
53/// `None`: no size line, so this is not an `appraise` reply. Otherwise
54/// whether the last non-blank line from the size line on says it.
55#[must_use]
56pub fn appraised_frail<'a>(reply: impl IntoIterator<Item = &'a str>) -> Option<bool> {
57    let mut lines = reply.into_iter().skip_while(|line| !is_appraise_size(line));
58    let first = lines.next()?;
59    let last = lines
60        .filter(|line| !line.trim().is_empty())
61        .last()
62        .unwrap_or(first);
63    Some(last.contains("enticingly frail"))
64}

66/// The charge `measure` reports: the `N` of `to be about N percent.`, any
67/// case. A hunt raises the weapon at 100.
68#[must_use]
69pub fn measured_percent(line: &str) -> Option<u32> {
70    const LEAD: &str = "to be about ";
71    const TAIL: &str = " percent.";
72    let lower = line.to_ascii_lowercase();
73    lower.match_indices(LEAD).find_map(|(at, _)| {
74        let rest = lower.get(at + LEAD.len()..)?;
75        let digits = rest.bytes().take_while(u8::is_ascii_digit).count();
76        if !rest.get(digits..)?.starts_with(TAIL) {
77            return None;
78        }
79        // No digits parses to nothing: `\d+` wants one or more.
80        rest.get(..digits)?.parse().ok()
81    })
