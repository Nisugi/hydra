1//! `hydra`, `hydra gui` and `hydra serve`: Hydra's own process, every
2//! character on a supervised session in one host table, and its windows
3//! whenever they are wanted.
4//!
5//! Hydra runs once on a data folder at a time (`instance`). Another launch
6//! on it opens the windows of the process running, and leaves.
7//!
8//! Hydra rests between its windows: its characters play on, the web page is
9//! served while its setting is on (`hydra_web::serve`), and the computer is
10//! kept awake while a character plays (`rest`). On Windows its icon is in
11//! the tray throughout (`tray`). `hydra serve` starts it resting; `hydra`
12//! and `hydra gui` open the windows at once. The windows take the main
13//! thread while they are open, so the sessions and their feeds run on the
14//! runtime's workers.
15//!
16//! Characters named on the command line start at once, their passwords asked
17//! at the terminal when none is kept; the hub and the web page start the
18//! roster's. Closing the hub hides it while another window is open, and
19//! once none is the windows close and Hydra rests. Its Shut down, or Ctrl-C,
20//! stops every character in order: `quit` to each, a wait for the game to
21//! close each connection, then the sessions end. A second Ctrl-C leaves at
22//! once.
23//!
24//! Rested long enough with nothing playing, Hydra starts fresh
25//! (`rest::until_fresh`): it starts the next process in the background,
26//! resting, and leaves, the lock held to its end; the next waits for it to
27//! go. A web page a team started for the web had is served by the next as
28//! well. A page open on a phone loses its connection for a moment and finds
29//! the next by itself. An update fetched (`update`) is the program the next
30//! process starts as.
31//!
32//! Each character's session runs on a runtime of its own, two threads
33//! (`game_runtime`), apart from the windows', the page's and the rest of
34//! Hydra's.
35//!
36//! The hub's *Restart now*, once an update is fetched, shuts Hydra down in
37//! order as Shut down does and starts the next process the same way, but
38//! with the hub open, and, if the player kept the box ticked, the
39//! characters that were playing started again, each with its team
40//! (`Table::resume`).

55/// What a start was told besides its characters and whether its windows
56/// open at once.
57#[derive(Clone, Copy, Debug, Default)]
58pub(crate) struct Told {
59    /// The process before started it fresh, and is leaving (`--again`).
60    pub(crate) again: bool,
61    /// The web page is served on this port for the run, whatever its
62    /// setting, as a team started for the web has it (`--web`).
63    pub(crate) web: Option<u16>,
64}
65
66/// How many threads the characters' sessions run on, at most.
67const GAME_THREADS: usize = 2;
68
69/// How long the characters' runtime is given to finish, once every
70/// character has stopped, before Hydra goes on without it.
71const GAME_STOPS: std::time::Duration = std::time::Duration::from_secs(5);
72
73/// How long Hydra waits, as it stops, for the logs and recordings still
74/// being written: a stalled disk may hold them a while.
75const FILES_SETTLE: std::time::Duration = std::time::Duration::from_secs(30);
76
77/// Every character quit, through its Lich where one runs, and every log and
78/// recording still being written written, before Hydra goes: their threads
79/// hold what a stalled disk has yet to take.
80fn stop_everything(runtime: &tokio::runtime::Runtime, table: &Table) {
81    runtime.block_on(table.stop_everything());
82    // The settings changed and not yet written, whatever changed them: the
83    // windows flush theirs as they close, but the page and the table save
84    // through the same batch, which a Hydra without windows would lose.
85    hydra_board::store::flush();
86    // What the lookout and the chunk kinds have learned since they were
87    // last written.
88    hydra_lookout::save_all();
89    hydra_session::chunk_kinds::save_all();
90    if !hydra_net::behind::settle_all(FILES_SETTLE) {
91        eprintln!("[hydra] some logs were still being written as Hydra stopped");
92    }
93}

95/// The runtime the characters' sessions run on, apart from the windows',
96/// the page's and the rest of Hydra's: their game text is read on its
97/// threads alone, two (one on a machine of one core), however many
98/// characters play. Each pattern the model matches keeps a copy of its
99/// caches for every thread that ever runs it, so this bounds the copies.
100///
101/// # Errors
102///
103/// The runtime could not start: why.
104fn game_runtime() -> Result<tokio::runtime::Runtime, String> {
105    let cores = std::thread::available_parallelism().map_or(1, std::num::NonZero::get);
106    tokio::runtime::Builder::new_multi_thread()
107        .worker_threads(GAME_THREADS.min(cores))
108        .thread_name("game")
109        .enable_all()
110        .on_thread_start(|| hydra_mem::thread(hydra_mem::Part::Background))
111        .build()
112        .map_err(|why| format!("the characters' runtime cannot start: {why}"))
113}

115/// How a rest between the windows ended.
116enum Rested {
117    /// The windows were asked for.
118    Open(Open),
119    /// Hydra is shut down.
120    Closed,
121    /// Nothing has played for long enough: Hydra starts fresh.
122    Fresh,
123}

125/// Log every target in, start again each character of `resume`, which a
126/// restart named, and run Hydra until it is shut down: its windows open at
127/// once when `open`, and whenever another launch asks for them.
128///
129/// # Errors
130///
131/// What failed before a named character's session could start, or the data
132/// folder could not be claimed.
133pub(crate) fn run(
134    runtime: &tokio::runtime::Runtime,
135    targets: Vec<Target>,
136    open: bool,
137    told: Told,
138    resume: Vec<Resume>,
139) -> Result<(), String> {
140    let data = crate::account::data_dir();
141    let Some((held, asks)) = claim(&data, open, told, !targets.is_empty())? else {
142        return Ok(());
143    };
144    crate::started::log_in(&data);
145    for said in hydra_board::hotbars::adopt_files(&data) {
146        eprintln!("[hotbars] {said}");
147    }
148    // Every password the command line needs, asked before anything opens.
149    let mut logins = Vec::new();
150    for target in targets {
151        let login = target.resolve()?;
152        let password = crate::account::password(&login.account).map_err(|e| e.to_string())?;
153        logins.push((login, password));
154    }
155    let game = game_runtime()?;
156    let sessions = board(runtime, &data);
157    let table = table(runtime, game.handle(), &sessions);
158    // Said before the command line's characters start, so one shown in a
159    // terminal has its terminal, and another launch, a terminal among them,
160    // is answered. The sender is held here as well, so the asking never
161    // ends while Hydra runs.
162    let (ask, mut opens) = mpsc::unbounded_channel();
163    let opener = windows_opener(&sessions, ask.clone());
164    sessions.opener(Arc::clone(&opener));
165    let bring_up = move || opener(Open::Hub);
166    answer(runtime, asks, (&sessions, &data), bring_up.clone());
167    start_logins(runtime, &table, logins, resume);
168    crate::started::stage("the roster is read and its passwords looked for");
169
170    serve_page(runtime, &sessions, &data, told);
171    crate::started::stage("the web page is served");
172    let windows = Arc::new(AtomicBool::new(false));
173    runtime.spawn(crate::rest::watch(sessions.clone(), Arc::clone(&windows)));
174    claim_rewards(runtime, &sessions, &data);
175    crate::update::start(runtime, &sessions, &data);
176    #[cfg(windows)]
177    let tray = {
178        let hub = sessions.clone();
179        crate::tray::Tray::start(sessions.clone(), runtime.handle().clone(), move || {
180            open_hub(&hub, &bring_up);
181        })
182    };
183    crate::started::stage("the tray is up");
184    runtime.spawn(stop_on_ctrl_c(Arc::clone(&table)));
185
186    let mut closes = sessions.closes();
187    let mut open_now = open.then_some(Open::Hub);
188    // The windows have been open in this run: theirs to give back.
189    let mut used = false;
190    let fresh = loop {
191        if let Some(how) = open_now {
192            used = true;
193            windows.store(true, Ordering::Relaxed);
194            crate::started::stage("the windows are opening");
195            hydra_gui::opening(crate::started::stage);
196            let shown = hydra_mem::part(hydra_mem::Part::Windows, || {
197                hydra_gui::run(sessions.clone(), runtime.handle().clone(), &data, how)
198            });
199            windows.store(false, Ordering::Relaxed);
200            if let Err(e) = shown {
201                eprintln!("[hydra] the windows cannot open: {e}");
202            }
203            // An ask that came as they closed is not a reason to open them
204            // again at once.
205            while opens.try_recv().is_ok() {}
206        }
207        if *closes.borrow() {
208            break false;
209        }
210        eprintln!("[hydra] resting: `hydra` opens the windows, Ctrl-C shuts Hydra down");
211        let rested = runtime.block_on(async {
212            tokio::select! {
213                // An ask for the windows as the time comes is answered.
214                biased;
215                asked = opens.recv() => asked.map_or(Rested::Closed, Rested::Open),
216                _ = closes.wait_for(|closing| *closing) => Rested::Closed,
217                () = crate::rest::until_fresh(&sessions, &data, used) => Rested::Fresh,
218            }
219        });
220        match rested {
221            Rested::Open(how) => open_now = Some(how),
222            Rested::Closed => break false,
223            Rested::Fresh => break true,
224        }
225    };
226
227    if fresh {
228        eprintln!(
229            "[hydra] nothing has played for a while: starting fresh, giving back what play held"
230        );
231    } else {
232        eprintln!("[hydra] shutting down; quitting every character");
233    }
234    stop_everything(runtime, &table);
235    game.shutdown_timeout(GAME_STOPS);
236    #[cfg(windows)]
237    if let Some(tray) = tray {
238        tray.close();
239    }
240    if fresh {
241        start_next(&sessions, None);
242    } else if let Some(resume) = table.restarting() {
243        start_next(&sessions, Some(resume));
244    }
245    drop((ask, held));
246    Ok(())
247}

249/// Claim `data`, the data folder, for this process: its lock, and where
250/// other launches ask it for its windows. `None` when Hydra already runs
251/// there and this process leaves: having asked for the windows when `open`,
252/// or because it was started fresh (`told.again`) and another took its
253/// place.
254///
255/// # Errors
256///
257/// Claim the login reward and the store's Simucoins as `rewards.toml` says:
258/// two loops that look at it every few minutes and do nothing without it.
259fn claim_rewards(runtime: &tokio::runtime::Runtime, sessions: &Sessions, data: &Path) {
260    runtime.spawn(hydra_table::reward_claim::run(
261        sessions.clone(),
262        data.to_path_buf(),
263    ));
264    runtime.spawn(hydra_table::store_claim::run(data.to_path_buf()));
265}

267/// The data folder could not be claimed, or Hydra already runs there and
268/// this process was started to rest.
269fn claim(
270    data: &Path,
271    open: bool,
272    told: Told,
273    characters: bool,
274) -> Result<Option<(Held, Asks)>, String> {
275    let claimed = if told.again {
276        instance::claim_once_left(data)?
277    } else {
278        instance::claim(data)?
279    };
280    match claimed {
281        Claim::First(held, asks) => {
282            if told.again {
283                eprintln!("[hydra] started fresh by the process before this one");
284            }
285            Ok(Some((held, asks)))
286        }
287        Claim::Running if told.again => {
288            eprintln!(
289                "[hydra] Hydra already runs on {}: this process leaves",
290                data.display()
291            );
292            Ok(None)
293        }
294        Claim::Running if open => {
295            instance::ask_open(data)?;
296            if characters {
297                eprintln!("[hydra] Hydra is already running: start characters from its hub.");
298            }
299            Ok(None)
300        }
301        Claim::Running => Err(format!(
302            "Hydra is already running on {}: `hydra` opens its windows.",
303            data.display()
304        )),
305    }
306}

308/// The session table over `sessions`, its characters' sessions run on
309/// `game`, answering the hubs' requests.
310fn table(
311    runtime: &tokio::runtime::Runtime,
312    game: &tokio::runtime::Handle,
313    sessions: &Sessions,
314) -> Arc<Table> {
315    let table = Table::with_game_runtime(sessions.clone(), runtime.handle().clone(), game.clone());
316    let answering = Arc::clone(&table);
317    let control: HubControl = Arc::new(move |request| {
318        let table = Arc::clone(&answering);
319        Box::pin(async move { table.answer(request).await })
320    });
321    sessions.control(control);
322    table
323}

325/// Each character of `logins` started on `table`, each of `resume` started
326/// again, and the roster offered.
327fn start_logins(
328    runtime: &tokio::runtime::Runtime,
329    table: &Arc<Table>,
330    logins: Vec<(crate::account::Login, String)>,
331    resume: Vec<Resume>,
332) {
333    runtime.block_on(async {
334        for (login, password) in logins {
335            if let Err(e) = table.start(login, password, false, None).await {
336                eprintln!("[hydra] {e}");
337            }
338        }
339        table.resume(resume).await;
340        table.offer().await;
341    });
342}

344/// What opens the windows over `sessions`. Another launch, the tray, a
345/// character started or shown again, or a team started with its play
346/// windows asks for them: open ones show the hub in front, or a seat's
347/// play window, or leave the hub be for play windows; or the main thread
348/// is told through `asking` to open them. A character shown in a terminal
349/// has one opened on it, the windows left as they are.
350fn windows_opener(sessions: &Sessions, asking: mpsc::UnboundedSender<Open>) -> Opener {
351    let (wake, seated) = (sessions.wake(), sessions.clone());
352    Arc::new(move |open| {
353        let open_already = match open {
354            Open::Hub => wake.raise(),
355            // Open already, each play window opens as it is seated.
356            Open::PlayWindows => wake.is_open(),
357            Open::Seat(id) => wake.raise_seat(id),
358            Open::Terminal(id) => {
359                crate::terminal::open_on(&seated, id);
360                true
361            }
362        };
363        if !open_already {
364            let _ = asking.send(open);
365        }
366    })
367}

369/// The hub opened where Hydra's own settings say: a terminal on it, when
370/// Hydra's hub is a terminal's; else the windows' hub, as `windows` brings
371/// it up.
372#[cfg(windows)]
373fn open_hub(sessions: &Sessions, windows: &impl Fn()) {
374    if sessions.own().hub_in_terminal() {
375        if let Err(why) = crate::terminal::open(None) {
376            eprintln!("[hydra] {why}");
377            sessions.tell(why);
378        }
379    } else {
380        windows();
381    }
382}

384/// Answer every other launch on `runtime`: one asking for the windows
385/// brings them up as `bring_up` does; a terminal attaching gets a screen
386/// of its own, drawn here over `sessions`, kept in `data`.
387fn answer(
388    runtime: &tokio::runtime::Runtime,
389    asks: Asks,
390    (sessions, data): (&Sessions, &Path),
391    bring_up: impl Fn() + Send + 'static,
392) {
393    let context = hydra_tui::Context {
394        sessions: sessions.clone(),
395        runtime: runtime.handle().clone(),
396        data: data.to_path_buf(),
397    };
398    runtime.spawn(instance::answer(asks, move |asked| match asked {
399        Asked::Open => bring_up(),
400        Asked::Tui(stream, seat) => hydra_tui::relay::serve(stream, seat, context.clone()),
401    }));
402}

404/// The board over the data folder `data`: Hydra's own settings read, the
405/// desk that plays the highlights' sounds and shows their notifications
406/// started, and what is kept up for every character, whether a window is
407/// open or not, running on `runtime`.
408fn board(runtime: &tokio::runtime::Runtime, data: &Path) -> Sessions {
409    let sessions = Sessions::new(Wake::default());
410    sessions.load_own(data);
411    let (quiet_highlights, quiet_wake) = (sessions.highlights(), sessions.wake());
412    sessions.highlights().start_desk(|| {
413        let desk = crate::attention::start(data);
414        Arc::new(move |called| {
415            // A terminal covered by work mode, and no window open: a sound
416            // or a notification would give the game away at a desk.
417            if quiet_highlights.covered() > 0 && !quiet_wake.is_open() {
418                return;
419            }
420            let _ = desk.send(called);
421        })
422    });
423    runtime.spawn(hydra_mem::task(
424        hydra_mem::Part::Highlights,
425        hydra_board::upkeep::run(sessions.clone(), data.to_path_buf()),
426    ));
427    sessions
428}

430/// Serve the web page on `runtime` while it is wanted: by the settings the
431/// window keeps, kept in `data`, so with no window open too, and on the
432/// port `told.web` says for the run.
433fn serve_page(runtime: &tokio::runtime::Runtime, sessions: &Sessions, data: &Path, told: Told) {
434    let web = sessions.own().web();
435    sessions.want_web(web);
436    if let Some(port) = told.web {
437        sessions.serve_web(port);
438    }
439    // The process before lets the page's port go as it ends.
440    let wanted = *sessions.web_wanted().borrow();
441    if told.again
442        && let Some(port) = wanted
443    {
444        instance::until_free(port);
445    }
446    let page = hydra_web::serve(sessions.clone(), data.to_path_buf());
447    runtime.spawn(hydra_mem::task(hydra_mem::Part::WebPage, page));
448}

450/// Start the next process and leave: fresh and resting, or, restarting,
451/// with the hub open and each character of `restart` started again. The
452/// web page a team started for the web had served goes on being served.
453/// Said, when it cannot be started, and this one ends all the same.
454fn start_next(sessions: &Sessions, restart: Option<Vec<Resume>>) {
455    if restart.is_some() {
456        eprintln!("[hydra] starting again");
457    }
458    let next = Serve {
459        again: true,
460        web: sessions.web_team(),
461        open: restart.is_some(),
462        resume: restart.unwrap_or_default(),
463        ..Serve::default()
464    };
465    match crate::startup::detach(&next.args()) {
466        // The lock held to the end, so the next has it only once this one,
467        // and the web page's port, are gone.
468        Ok(()) => std::process::exit(0),
469        Err(why) => eprintln!("[hydra] {why}: Hydra has shut down"),
470    }
471}

473/// Ctrl-C shuts Hydra down in order, as the hub's Shut down does; a second
474/// leaves at once.
475async fn stop_on_ctrl_c(table: Arc<Table>) {
476    if tokio::signal::ctrl_c().await.is_err() {
477        return;
478    }
479    eprintln!("[hydra] Ctrl-C: shutting down (Ctrl-C again leaves at once)");
480    table.answer(HubRequest::Shutdown).await;
481    if tokio::signal::ctrl_c().await.is_ok() {
482        eprintln!("[hydra] leaving now");
483        std::process::exit(1);
484    }
