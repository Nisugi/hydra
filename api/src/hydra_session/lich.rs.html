1//! The player's own Lich, through the relay: what it may do to the character
2//! it runs for, through [`LichDoor`], which `hydra-lich` holds.
3//!
4//! Hydra keeps the game's connection. Lich, started in pipe mode and pointed
5//! at a port the relay holds, takes the relay as its game. Once
6//! [attached](LichDoor::attach) it is handed the game's bytes as they came,
7//! and what the player types that Hydra does not take; what it writes to
8//! that port comes here as lines to send ([`LichDoor::send`]).
9//!
10//! # The bytes, not the lines
11//!
12//! Lich parses the stream itself, markup and all, so it is handed exactly
13//! what the game sent, as the recorder is: copied where a chunk arrives,
14//! before the parser, and read by nothing here.
15//!
16//! # The player's typing
17//!
18//! The symbol a line starts with says whose it is: a line starting with
19//! Lich's command symbol goes to Lich, one starting with Hydra's goes to
20//! Hydra. The rest of what the player types goes to Lich too, for its
21//! aliases and hooks.
22//!
23//! So a line is Hydra's first, by its symbol (`claimant`). Then:
24//!
25//! - a line with Lich's symbol ([`SessionHandle::lich_symbol`], `;` unless
26//!   the player chose another) is Lich's, handed to its standard input, and
27//!   never Hydra's or the game's: with no Lich running, the player is told;
28//! - what the player typed at a window ([`SessionHandle::send_typed`]) is
29//!   Lich's while one runs, and Lich sends what it makes of it;
30//! - Hydra's own lines (a relayed `.to`'s) go to the game, past Lich's
31//!   hooks, as a Lich script's `put` never meets them.
32//!
33//! # Kept up, and let go
34//!
35//! The Lich attached is the session's, not a connection's, so it stays up
36//! through a reconnect and sees the new login as more of the stream. Its
37//! scripts cannot work with no game connection, so while there is none its
38//! lines are not sent, and the relay says so.
39//!
40//! A Lich that stops reading is let go rather than waited on, or fed a
41//! stream with a hole in it: the copy holds [`WIRE_CHUNKS`] chunks, and the
42//! first that finds it full ends it ([`Wire::fell_behind`]). Dropping
43//! chunks would leave a hole Lich cannot recover from, and blocking would
44//! stall the game's own reader, so neither is done.
45//!
46//! # What it shows
47//!
48//! What Lich would show a frontend, its standard output, is handed back
49//! ([`LichDoor::show`]), parsed by a parser of its own (`text.rs`), and
50//! published as [`Event::LichShown`], each frame marked with whose line it
51//! was. A window shows it in place of the game's text while Lich runs
52//! ([`View::Lich`]: Lich's squelches hold and its scripts' messages show),
53//! or the game's own text and Lich's own lines beside it ([`View::Game`]);
54//! the player toggles between the two. The
55//! session's own parse of the game is everything else, as it was: the model,
56//! the panels, the log.
57//!
58//! # Started late
59//!
60//! A Lich attached after the login is handed a login first, built from what
61//! the session knows as it attaches (`GameState::login`), then the live
62//! stream. The session's actor builds it, from its model, between one chunk
63//! and the next, so the Lich misses nothing and is told nothing twice.
64//!
65//! # Claimed while it starts
66//!
67//! Ruby and Lich take from seconds to half a minute to start. The relay
68//! [claims](LichDoor::claim) the character's Lich as it starts one: what
69//! the player types for it waits for it from then on, and no second starts
70//! beside it. Nothing else changes while it starts: it is handed none of the
71//! game, and the windows show the game's own text. Once it has connected,
72//! the relay says so ([`Wire::begin`]), and at the actor's next turn, half a
73//! second at most, it is handed its login and the game, and the windows
74//! turn to its text ([`Event::LichBegun`]).

102/// How many chunks of the game's bytes wait for a Lich that has not read
103/// them, as many records as Lich's own queue holds.
104pub const WIRE_CHUNKS: usize = 4_096;

106/// How many typed lines wait for a Lich: those typed while it starts. Past
107/// them the player's line is not handed, and the player is told.
108pub const TYPED_LINES: usize = 64;

110/// Who began a line Lich sends.
111#[derive(Clone, Copy, Debug, PartialEq, Eq)]
112pub enum LineFrom {
113    /// One of Lich's scripts put it, marked `<c>`: [`Origin::Lich`].
114    Lich,
115    /// The player typed it, and Lich passed it on after its own hooks:
116    /// [`Origin::Player`], and the player is there.
117    Player,
118}

120/// What came of a line Lich sent.
121#[derive(Clone, Copy, Debug, PartialEq, Eq)]
122pub enum Sending {

124    Sent,
125    /// One of Hydra's own commands, and run.
126    Ran,

143/// The game's bytes, copied for a Lich as they arrive. Dropped, the Lich
144/// is gone, and the windows are told.
145#[derive(Debug)]
146pub struct Wire {
147    bytes: mpsc::Receiver<Vec<u8>>,
148    behind: Arc<AtomicBool>,
149    /// The Lich has connected, and is to be handed the game.
150    begun: Arc<AtomicBool>,
151    events: broadcast::Sender<Event>,
152}
153
154impl Drop for Wire {
155    fn drop(&mut self) {
156        let _ = self.events.send(Event::LichEnded);
157    }
158}

161#[derive(Debug)]

164/// The session's end of an [`Attached`].
165#[derive(Debug)]
166struct Tap {
167    bytes: mpsc::Sender<Vec<u8>>,
168    typing: mpsc::Sender<String>,
169    behind: Arc<AtomicBool>,
170    begun: Arc<AtomicBool>,
171}
172
173impl Tap {
174    /// Whether a Lich is still attached.
175    fn is_open(&self) -> bool {
176        !self.bytes.is_closed()
177    }
178
179    /// Whether its Lich has connected, to be handed the game.
180    fn begun(&self) -> bool {
181        self.begun.load(Ordering::Relaxed)
182    }
183
184    /// Copy `chunk`. False when the copy ends here: the Lich stopped taking
185    /// it, or has [`WIRE_CHUNKS`] unread.
186    fn copy(&self, chunk: &[u8]) -> bool {
187        match self.bytes.try_send(chunk.to_vec()) {
188            Ok(()) => true,
189            Err(mpsc::error::TrySendError::Full(_)) => {
190                self.behind.store(true, Ordering::Relaxed);
191                false
192            }
193            Err(mpsc::error::TrySendError::Closed(_)) => false,
194        }
195    }
196}

198/// The player's Lich as the session holds it: the one attached, and one
199/// claimed, starting or waiting to be handed its login.
200#[derive(Debug, Default)]
201pub(crate) struct Slot {
202    tap: Option<Tap>,
203    pending: Option<Tap>,
204    /// What the Lich attached shows, read as it comes.
205    text: LichText,
206    /// The session has ended: nothing attaches again.
207    over: bool,
208}
209
210/// The slot, shared by a session's handles and each connection's actor.
211pub(crate) type Shared = Arc<Mutex<Slot>>;
212
213/// Closes the slot when dropped: however the session's task ends -- in
214/// order, by a panic, or aborted -- its Lich is let go.
215pub(crate) struct Closes(pub(crate) Shared);
216
217impl Drop for Closes {
218    fn drop(&mut self) {
219        lock(&self.0).close();
220    }
221}
222
223/// The slot, held.
224pub(crate) fn lock(slot: &Shared) -> MutexGuard<'_, Slot> {
225    slot.lock().unwrap_or_else(PoisonError::into_inner)
226}
227
228impl Slot {
229    /// Claim the character's Lich, to be handed its login at the actor's
230    /// turn after it connects. False, and `tap` unused, while another is
231    /// attached: one per character.
232    fn attach(&mut self, tap: Tap) -> bool {
233        if self.over || self.attached() {
234            return false;
235        }
236        self.pending = Some(tap);
237        self.text = LichText::default();
238        true
239    }
240
241    /// Whether one has connected and waits to be handed its login.
242    pub(crate) fn waits(&self) -> bool {
243        self.pending
244            .as_ref()
245            .is_some_and(|tap| tap.is_open() && tap.begun())
246    }
247
248    /// Hand the Lich attached since the actor's last turn `login`, and copy
249    /// the game's bytes to it from now on. False with none waiting.
250    pub(crate) fn begin(&mut self, login: &[u8]) -> bool {
251        let Some(tap) = self.pending.take() else {
252            return false;
253        };
254        if !login.is_empty() {
255            tap.copy(login);
256        }
257        self.tap = Some(tap);
258        true
259    }
260
261    /// Whether a Lich is attached, or waits to be handed its login.
262    pub(crate) fn attached(&self) -> bool {
263        self.tap.iter().chain(&self.pending).any(Tap::is_open)
264    }
265
266    /// Copy a chunk of the game's bytes to the Lich attached. One that
267    /// stopped, or fell behind, is let go here.
268    pub(crate) fn wire(&mut self, chunk: &[u8]) {
269        if let Some(tap) = &self.tap
270            && !tap.copy(chunk)
271        {
272            self.tap = None;
273        }
274    }
275
276    /// The session has ended: whatever is attached is let go, and its copy
277    /// ends. Nothing attaches after.
278    pub(crate) fn close(&mut self) {
279        self.tap = None;
280        self.pending = None;
281        self.over = true;
282    }
283
284    /// Hand a typed line to the Lich attached: `None` with none attached,
285    /// and `Some(false)` when it has too many waiting.
286    fn hand(&self, line: &str) -> Option<bool> {
287        self.tap
288            .iter()
289            .chain(&self.pending)
290            .find(|tap| tap.is_open())
291            .map(|tap| tap.typing.try_send(line.to_owned()).is_ok())
292    }
293}

295impl Wire {
296    /// The next chunk, as the game sent it. `None` once the copy has ended:
297    /// the session is gone, or the Lich [fell behind](Self::fell_behind).
298    pub async fn next(&mut self) -> Option<Vec<u8>> {
299        self.bytes.recv().await
300    }
301
302    /// Whether the copy ended because the Lich had [`WIRE_CHUNKS`] unread.
303    #[must_use]
304    pub fn fell_behind(&self) -> bool {
305        self.behind.load(Ordering::Relaxed)
306    }
307
308    /// The Lich [claimed](LichDoor::claim) has connected: at the actor's
309    /// next turn it is handed its login and the game from then, and the
310    /// windows turn to its text.
311    pub fn begin(&self) {
312        self.begun.store(true, Ordering::Relaxed);
313    }
314}

316impl Typing {
317    /// The next line the player typed for Lich. `None` once the session is
318    /// gone.
319    pub async fn next(&mut self) -> Option<String> {
320        self.0.recv().await
321    }
322
323    /// Every line typed for Lich and not yet taken, taken now: what a Lich
324    /// that ended was never given.
325    pub fn waiting(&mut self) -> Vec<String> {
326        std::iter::from_fn(|| self.0.try_recv().ok()).collect()

330/// The only way the player's Lich acts on a session.
331#[derive(Clone, Debug)]
332pub struct LichDoor {
333    handle: SessionHandle,
334}
335
336impl SessionHandle {
337    /// The door the player's Lich acts on this session through.
338    #[must_use]
339    pub fn lich_door(&self) -> LichDoor {
340        LichDoor {
341            handle: self.clone(),
342        }
343    }
344
345    /// Whether the player's Lich is attached to this session.
346    #[must_use]
347    pub fn lich_running(&self) -> bool {
348        lock(&self.lich).attached()
349    }
350
351    /// Hand `line` to the player's Lich, as if typed for it: whether one
352    /// runs and took it.
353    #[must_use]
354    pub fn to_lich(&self, line: &str) -> bool {
355        lock(&self.lich).hand(line) == Some(true)
356    }
357
358    /// Hand `line` to the player's Lich, telling the player when it could
359    /// not be: [`crate::Outcome::Lich`] when it was.
360    pub(crate) fn hand_to_lich(&self, line: &str) -> crate::Outcome {
361        let handed = lock(&self.lich).hand(line);
362        let why = match handed {
363            Some(true) => return crate::Outcome::Lich,
364            Some(false) => format!(
365                "Lich is not reading what is typed for it ({TYPED_LINES} lines wait): \
366                 not handed: {line}"
367            ),
368            None => format!("Lich is not running for this character: not sent: {line}"),
369        };
370        self.say(Notice::line(crate::NoticeKind::Warn, why).answering());
371        crate::Outcome::Claimed
372    }
373}

375impl LichDoor {
376    /// Attach a Lich from here on: [claimed](Self::claim), and
377    /// [begun](Wire::begin) at once.
378    #[must_use]
379    pub fn attach(&self) -> Option<Attached> {
380        let attached = self.claim()?;
381        attached.wire.begin();
382        Some(attached)
383    }
384
385    /// Claim the character's Lich as it starts: what is typed for it from
386    /// here on waits for it, and none other attaches. Once it has connected
387    /// ([`Wire::begin`]), before the next chunk of the game's bytes it is
388    /// handed a login built from what the session knows then: nothing,
389    /// before the game has named the character, when the login itself is
390    /// still to come. Then that chunk and those after it. `None` while
391    /// another is attached: one per character. It stays attached until what
392    /// this returns is dropped.
393    #[must_use]
394    pub fn claim(&self) -> Option<Attached> {
395        let (bytes, wire) = mpsc::channel(WIRE_CHUNKS);
396        let (typing, typed) = mpsc::channel(TYPED_LINES);
397        let behind = Arc::new(AtomicBool::new(false));
398        let begun = Arc::new(AtomicBool::new(false));
399        let events = self.handle.events.clone();
400        let tap = Tap {
401            bytes,
402            typing,
403            behind: Arc::clone(&behind),
404            begun: Arc::clone(&begun),
405        };
406        lock(&self.handle.lich).attach(tap).then_some(Attached {
407            wire: Wire {
408                bytes: wire,
409                behind,
410                begun,
411                events,
412            },
413            typing: Typing(typed),
414        })
415    }
416
417    /// Show what Lich wrote to its standard output: each frame, marked with
418    /// whose line it was, to the windows.
419    pub fn show(&self, chunk: &[u8]) {
420        let frames = lock(&self.handle.lich).text.read(chunk);
421        // A script's own dialogs and timers are for the frontend, as the
422        // game's are: its quick bar, its windows, its countdowns. The
423        // game's, passed on, are already in.
424        let dialogs: Vec<Frame> = frames
425            .iter()
426            .filter(|(frame, mark)| *mark == Mark::Lich && for_the_frontend(frame))
427            .map(|(frame, _)| frame.clone())
428            .collect();
429        for (frame, mark) in frames {
430            let _ = self.handle.events.send(Event::LichShown {
431                frame: Box::new(frame),
432                mark,
433            });
434        }
435        // A session too busy to take them misses them; a script sends its
436        // bar again as it changes.
437        let _ = self.handle.fold_in(dialogs);
438    }
439
440    /// Whether the session has ended, so no Lich attaches to it.
441    #[must_use]
442    pub fn session_over(&self) -> bool {
443        lock(&self.handle.lich).over
444    }
445
446    /// What marks a line as Hydra's.
447    #[must_use]
448    pub fn symbol(&self) -> char {
449        self.handle.symbol().unwrap_or(DEFAULT_SYMBOL)
450    }
451
452    /// What marks a line as Lich's.
453    #[must_use]
454    pub fn lich_symbol(&self) -> char {
455        self.handle.lich_symbol()
456    }
457
458    /// Send `line`, which Lich wrote to its game: Hydra's own command when it
459    /// starts with the command symbol; otherwise to the game at once, with
460    /// no queue, as Lich writes straight to its socket.
461    ///
462    /// **Hydra's command line hears every line Lich writes as
463    /// [`Origin::Lich`]**, even one Lich says the player typed: what the
464    /// player types with Hydra's symbol is Hydra's before Lich is handed
465    /// anything, so a Hydra command coming back from Lich was made by Lich
466    /// (an alias, a hook, or a script writing without `<c>`), and the
467    /// commands only the player may give refuse it.
468    pub async fn send(&self, line: &str, from: LineFrom) -> Sending {
469        match self.handle.claim(line, Origin::Lich) {
470            Some(Claimed::Unknown) => return Sending::Unknown,
471            Some(Claimed::Done) => return Sending::Ran,
472            None => {}
473        }
474        let origin = match from {
475            LineFrom::Lich => Origin::Lich,
476            LineFrom::Player => Origin::Player,
477        };
478        match self.handle.write_now(line, origin).await {
479            Written::Yes => Sending::Sent,
480            Written::No => Sending::Lost,
481        }
482    }
483
484    /// Tell the player something.
485    pub fn say(&self, notice: Notice) {
486        self.handle.say(notice);
487    }
488}

490/// Whether `frame` is one a script sends its frontend for the state: a
491/// dialog's, for its own windows and quick bar, or a timer.
492fn for_the_frontend(frame: &Frame) -> bool {
493    match frame {
494        Frame::Timer { .. }
495        | Frame::DialogOpen { .. }
496        | Frame::DialogPanelOpen { .. }
497        | Frame::ClearDialogData { .. }
498        | Frame::CloseDialog { .. }
499        | Frame::DialogWidgets(_)
500        | Frame::QuickbarSwitch { .. } => true,
501        Frame::Label { dialog, .. } => dialog.is_some(),
502        Frame::ProgressBar(bar) => bar.dialog.is_some(),
503        _ => false,
504    }
505}
