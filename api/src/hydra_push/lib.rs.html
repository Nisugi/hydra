1//! The push relay: what lets a trigger on the desktop Hydra put a banner on
2//! a phone running HydraFE.
3//!
4//! Apple takes pushes for an app only from whoever signs it, with that
5//! team's key. The key cannot go inside Hydra, where anyone could take it,
6//! so it lives on a server of the author's, and this relay hands each
7//! desktop's alerts on:
8//!
9//! ```text
10//! desktop Hydra --HTTPS, sealed--> nginx --> hydra-push --HTTP/2, JWT--> Apple --> phone
11//! ```
12//!
13//! - `POST /register` gives a desktop its own token ([`desktops`]), asked for
14//!   once, as the phone is paired.
15//! - `POST /push`, with that token, takes a phone's device token and the
16//!   alert, sealed by the desktop with a key only it and the phone hold. The
17//!   relay never reads it: Apple is handed "Hydra" and the sealed bytes, and
18//!   the app opens them on the phone ([`apns`]).
19//! - `DELETE /register`, with the token, forgets it.
20//!
21//! Each desktop token and each phone is held to a rate ([`limit`]). Nothing
22//! but the hashes of the desktop tokens is kept.
