1//! Highlights: words or a pattern in what the game says, and what Hydra does
2//! when they come -- colour them or their whole line, hide the line, play a
3//! sound, raise a banner, show a notification.
4//!
5//! Display and attention alone: conditions, sends, substitutions, redirects
6//! and flags are automation, and automation is Lich's job.
7//!
8//! # The file
9//!
10//! One file in the data folder, `highlights.toml`: a `[highlight."name"]`
11//! table for each, and `[categories]` switching a category off whole.
12//!
13//! ```toml
14//! [categories]
15//! "Wrayth ignores" = false
16//!
17//! [highlight."Nisugi"]
18//! category = "Friends"
19//! text = "Nisugi"
20//! color = "#ecc013"
21//! background = "#311c1c"
22//! case_sensitive = true
23//! whole_word = true
24//! line = false          # the whole line, not only the words
25//! sound = "ding.wav"    # a file name in the data folder's sounds folder
26//! alert = true          # a banner of the line; or alert = "words to show"
27//! notify = "Nisugi!"    # a notification from the computer; or true
28//! squelch = false       # hide the line (an alert still comes)
29//! characters = ["GS3:Ashryn"]   # whose; none, everyone's
30//! ```
31//!
32//! # Where it is applied
33//!
34//! Once, as each line of the game's is finished in a character's story
35//! ([`crate::Story`]), before any window draws it: the story's lines and
36//! every stream's. The player log keeps what the game said.
