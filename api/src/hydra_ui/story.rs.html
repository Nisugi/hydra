1//! One character's story as its window shows it: the game's lines, its
2//! prompts and what was sent; each stream's own lines, for a widget of that
3//! stream; and what Hydra says of the connection, for Hydra's own pane.
4//!
5//! Hydra's own news is never among the game's lines: its pane is an info
6//! window into what Hydra is doing, and its errors.
7//!
8//! # Lines are assembled here, from the session's frames
9//!
10//! The parser gives one text frame per markup boundary and marks the last of
11//! each wire line with `ends_line`; the frames are gathered per stream until
12//! one ends the line, as the model gathers them (`hydra-model`'s `lines.rs`).
13//!
14//! # Where a stream's line goes
15//!
16//! Every line not on the main stream is kept on its own stream
17//! ([`Streams`]), for a widget of it: that widget is the stream's window,
18//! open. The story takes it too when the game sends it to the main window
19//! while that window is closed, as the game declared with
20//! `<streamWindow ifClosed= styleIfClosed=>`
21//! ([`Windows::route`](hydra_model::state::stream_windows::Windows::route)):
22//! into the story (`logons`, `death`), into the story in a style
23//! (`thoughts`, `familiar`), or nowhere (`room`, `inv`, `speech`: panels, or
24//! copies of what main already says). A story line of another stream is kept
25//! as [`Shown::From`], so a play window with that stream's widget open leaves
26//! it out of the story. The declarations are read off the frames as they
27//! come, so a line is routed by what was declared before it.
28//!
29//! # Highlights
30//!
31//! Each line the game finishes, the story's and every stream's, is looked at
32//! once by the character's highlights ([`Story::highlight_with`]) before
33//! anything else takes it: painted, hidden, or calling for attention. A
34//! banner is kept here for the window to show ([`Story::alerts_at`]); a
35//! sound or a notification waits for whoever plays them
36//! ([`Story::calls`]). Each highlight calls at most once in its cooldown.
37//!
38//! # A creature's own lines
39//!
40//! A line that is a creature's death, its spell coming, a special about to
41//! land or its recovery, as the bestiary records them, takes that kind's
42//! preset before the highlights see it ([`crate::creature_line`]), so the
43//! theme colours it as it colours speech.
44//!
45//! # The combat reader's word
46//!
47//! When the game's prompt closes a chunk, the session says which of its
48//! lines the combat reader found to be a flare, a status landing on the
49//! character or a killing blow ([`Event::Marked`]); the story finds each
50//! among the main lines it showed in that chunk, by its text, and gives it
51//! the preset ([`crate::combat_line`]). The reader matched them once; the
52//! story matches nothing again. In Lich's view the marks come before Lich's
53//! copy of the chunk does, and each waits for its line.
54//!
55//! # The player's Lich
56//!
57//! While the player's Lich runs, the story shows one of two texts
58//! ([`View`]), switched between as a toggle:
59//!
60//! - **Lich's** ([`View::Lich`], the default): what Lich shows a frontend,
61//!   so its squelches hold and its scripts' words show. The game's own lines
62//!   are still looked at, for the highlights' sounds, banners and
63//!   notifications alone, so those answer the game whatever Lich hid.
64//! - **The game's** ([`View::Game`]): the game's own text, and Lich's own
65//!   lines beside it. A Lich that marks what it forwards (`--sentinel`) says
66//!   which are its own; one that does not is guessed at: a line the game
67//!   itself said lately is the game's, and is not shown twice.
68//!
69//! A Lich started late shows again the login it was handed; that is left
70//! out, up to its prompt. Lich echoes its scripts' commands itself
71//! (`[go2]>north`), so the story does not.
72//!
73//! # Prompts
74//!
75//! The game sends a prompt with every chunk, one of effects alone among them.
76//! A prompt is shown after the story has had a line with something to read,
77//! or when it changed (`R>` to `>`), never twice in a row for nothing. A
78//! blank line the game sent is its formatting and is shown; a line left
79//! blank by a highlight hiding its words is not. The
80//! live prompt drops its `R` once roundtime has
81//! run out ([`Story::settle`]): the game sends no prompt when it ends.

290/// One line the game said while Lich's text was shown.
291#[derive(Debug, Clone)]
292struct Heard {
293    text: String,
294    at: Instant,
295    stream: String,
296    line: Vec<StyledRun>,
297    /// Shown as it came, the game's view being on: not shown again.
298    shown: bool,
299}
300
301impl LichShowing {
302    /// The game said `line` on `stream`, its bytes arriving `at`; `shown`
303    /// when the story showed it then.
304    fn heard(&mut self, stream: &str, line: &[StyledRun], at: Instant, shown: bool) {
305        self.recent.push_back(Heard {
306            text: plain(line),
307            at,
308            stream: stream.to_owned(),
309            line: line.to_vec(),
310            shown,
311        });
312        while self.recent.len() > RECENT {
313            self.recent.pop_front();
314        }
315    }
316
317    /// Whether Lich's line `text` is a copy of one the game said, and when
318    /// that arrived: once each.
319    ///
320    /// Lich passes the game's lines on in the order they came, so those
321    /// older than the one matched, still unmatched, are lines it hid or
322    /// changed: let go, so a later copy of one is not timed from it (the
323    /// author's Lich read 620 ms until restarted, and 14 ms after).
324    fn forwarded(&mut self, text: &str) -> Option<Instant> {
325        let at = self.recent.iter().position(|heard| heard.text == text)?;
326        self.recent.drain(..=at).next_back().map(|heard| heard.at)
327    }
328}

385    /// [`Self::see`] at `now`.
386    pub fn see_at(&mut self, snapshot: Arc<hydra_session::Snapshot>, now: Instant) {
387        self.seen = Some(snapshot);
388        let Some(highlights) = self.highlights.clone() else {
389            return;
390        };
391        let rising = {
392            let Some(world) = self.world() else {
393                return;
394            };
395            highlights
396                .conditions(&world)
397                .map(|(name, holds, rearm)| (name.to_owned(), holds, rearm))
398                .collect::<Vec<_>>()
399        };
400        let rising: Vec<String> = rising
401            .into_iter()
402            .filter(|(name, holds, rearm)| {
403                self.edges
404                    .entry(name.clone())
405                    .or_default()
406                    .observe(*holds, now, *rearm)
407            })
408            .map(|(name, ..)| name)
409            .collect();
410        let fired = rising
411            .iter()
412            .filter_map(|name| highlights.fired_alone(name))
413            .collect();
414        self.attend(fired);
415        self.place_pictures();
416    }

469    /// The game commands the triggers sent since last taken.
470    pub fn sends(&mut self) -> Vec<String> {

472    }

474    /// `commands` a trigger sends at `now`: none while the character is not
475    /// yet ready to play, as when the game is still logging it in; none past
476    /// [`SENDS`] in [`SEND_WINDOW`], and that said once a window.
477    fn send(&mut self, commands: Vec<String>, now: Instant) {
478        if commands.is_empty() {
479            return;
480        }
481        let ready = self
482            .seen
483            .as_ref()
484            .is_some_and(|seen| seen.lifecycle == State::Ready);
485        if !ready {
486            return;
487        }
488        while self
489            .triggered_at
490            .front()
491            .is_some_and(|at| now.saturating_duration_since(*at) >= SEND_WINDOW)
492        {
493            self.triggered_at.pop_front();
494        }
495        for command in commands {
496            if self.triggered_at.len() >= SENDS {
497                let warned = self
498                    .warned_at
499                    .is_some_and(|at| now.saturating_duration_since(at) < SEND_WINDOW);
500                if !warned {
501                    self.warned_at = Some(now);
502                    self.tell(&format!(
503                        "A trigger's `{command}` was not sent: triggers send at most {SENDS} commands each {} seconds, and one may be answering its own line.",
504                        SEND_WINDOW.as_secs()
505                    ));
506                }
507                return;
508            }
509            self.triggered_at.push_back(now);
510            self.sends.push(command);
511        }
512    }

524    /// What highlights that found something call for, each once in its
525    /// cooldown.
526    fn attend(&mut self, fired: Vec<crate::highlight::Fired>) {
527        let now = Instant::now();
528        let clock = self
529            .seen
530            .as_ref()
531            .and_then(|seen| seen.state.game_time_now());
532        for fired in fired {
533            // A flag or a status is set at every find, its cooldown aside.
534            for (mark, kept) in [
535                (&fired.flag, &mut self.flags),
536                (&fired.status, &mut self.statuses),
537            ] {
538                let Some(mark) = mark else {
539                    continue;
540                };
541                if mark.clears() {
542                    kept.clear(mark.name());
543                } else {
544                    let until = mark
545                        .seconds()
546                        .and_then(|seconds| clock.map(|clock| clock.saturating_add(seconds)));
547                    kept.set(mark.name(), until);
548                }
549            }
550            let waiting = self
551                .called
552                .get(&fired.name)
553                .is_some_and(|at| now.saturating_duration_since(*at) < fired.cooldown);
554            if waiting {
555                continue;
556            }
557            self.called.insert(fired.name.clone(), now);
558            // A send shares its highlight's cooldown with what it calls for.
559            self.send(fired.send.clone(), now);
560            if let Some(alert) = fired.alert {
561                self.alert_at(now, alert);
562            }
563            if let Some(timing) = fired.timer {
564                self.timers.push(timing);
565            }
566            if let Some(picture) = fired.picture {
567                self.pictures_due.push((fired.name.clone(), picture));
568            }
569            if fired.sound.is_some()
570                || fired.notify.is_some()
571                || fired.speak.is_some()
572                || fired.rumble.is_some()
573            {
574                self.calls.push(Call {
575                    name: fired.name,
576                    sound: fired.sound,
577                    volume: fired.volume,
578                    notify: fired.notify,
579                    speak: fired.speak,
580                    rumble: fired.rumble,
581                });
582            }
583        }
584    }

614        for (arrived, shown, reply) in self.unpainted.drain(..) {
615            let took = now.saturating_duration_since(arrived);
616            if reply {
617                self.perf.screen.push(took);
618            } else {
619                self.perf.line.push(took);
620                self.perf
621                    .feed
622                    .push(shown.saturating_duration_since(arrived));
623                self.perf.wait.push(began.saturating_duration_since(shown));
624            }
625        }
626    }

628    /// A line is shown whose bytes arrived `arrived`: timed once painted.
629    fn paint_later(&mut self, arrived: Option<Instant>) {
630        if self.unpainted.len() >= UNPAINTED {
631            return;
632        }
633        let now = Instant::now();
634        // The reply's own line, or a later one: in Lich's view, Lich's copy
635        // of it, never of a line older than the reply.

637            && arrived.is_some_and(|arrived| arrived >= reply)
638        {

641        }
642        if let Some(arrived) = arrived {
643            self.unpainted.push((arrived, now, false));
644        }

647    /// Take in one event the session published.
648    pub fn hear(&mut self, event: &Event) {
649        match event {
650            Event::Clock(at) => self.clock = Some(*at),
651            Event::Frame(frame) => {
652                self.listed.hear(frame);
653                if let (Some(sent), Some(at)) = (self.sent_at, self.clock)
654                    && at > sent
655                {
656                    self.sent_at = None;
657                    self.perf.reply.push(at - sent);
658                    self.reply_at = Some(at);
659                }
660                let role = if self.lichs_view() {
661                    Role::Calls
662                } else {
663                    Role::Shown
664                };
665                self.take(frame, role);
666            }
667            Event::Prompt(text) => {
668                self.closed_lines = std::mem::take(&mut self.chunk_lines);
669                if !self.lichs_view() {
670                    self.prompted(text);
671                }
672            }
673            Event::Marked(marks) => self.marked(marks),
674            Event::LichShown { frame, mark } => self.lich_shown(frame, *mark),
675            Event::LichBegun { login } => {
676                self.lich = Some(LichShowing {
677                    skip: *login,
678                    ..LichShowing::default()
679                });
680                self.lich_ended = false;
681                self.switched();
682            }
683            Event::LichEnded => {
684                let unseen = self.lich.take().map(|lich| lich.recent);
685                self.lich_ended = true;
686                self.switched();
687                // What the game said that Lich never passed on -- all of
688                // it, when Lich failed part-way -- and that was not shown as
689                // it came, in whichever view, is shown now.
690                for heard in unseen.into_iter().flatten().filter(|heard| !heard.shown) {
691                    self.show_unseen(&heard.stream, heard.line);
692                }
693            }
694            Event::LichView(view) => {
695                if *view != self.view {
696                    self.view = *view;
697                    self.switched();
698                }
699            }
700            // Lich echoes its scripts' commands itself: `[go2]>north`.
701            Event::Sent {
702                origin: Origin::Lich,
703                ..
704            } => {}
705            // The client's own protocol commands (`_menu`, `_drag`) are not
706            // the player's words, and Wrayth does not echo them.
707            Event::Sent { line, .. } if !line.starts_with('_') => {
708                if let Some(typed) = self.typed.pop_front() {
709                    let at = self.clock.unwrap_or_else(Instant::now);
710                    self.perf.sent.push(at.saturating_duration_since(typed));
711                    self.sent_at = Some(at);
712                }
713                self.sent(line);
714            }
715            Event::Claimed(line) => {
716                // Typed, and never written: not timed.
717                self.typed.pop_front();
718                self.sent(line);
719            }
720            Event::Notice(notice) => self.said(notice),
721            Event::Sent { .. } | Event::StateChanged(_) => {
722                if let Event::StateChanged(state) = event {
723                    self.changed(*state);
724                }
725            }
726            Event::ConnectFailed {
727                attempt,
728                delay,
729                detail,
730            } => self.tell(&format!(
731                "{detail}; try {} in {:.1}s.",
732                attempt + 1,
733                delay.as_secs_f64()
734            )),
735        }
736    }

809        if state.in_roundtime() != Some(false) {

813            return;

817        }
818        *text = text.replacen('R', "", 1);
819        self.prompt = Some(text.clone());

849    fn take(&mut self, frame: &Frame, role: Role) {
850        match frame {
851            Frame::Text(text) => {
852                let lines = if role.shown() {
853                    &mut self.unfinished
854                } else {
855                    &mut self.beside
856                };
857                let line = lines.entry(text.stream.clone()).or_default();
858                line.push(text.as_run());
859                if text.ends_line {
860                    let runs = std::mem::take(line);
861                    self.finished(&text.stream, &runs, role);
862                }
863            }
864            // Declared whatever text is shown: the windows must be known
865            // when the other text is shown again.
866            Frame::StreamWindow { id, attrs, .. } => {
867                self.windows.declare(id, attrs);
868            }
869            Frame::ClearStream { id, .. } => {
870                if role.shown() {
871                    self.unfinished.remove(id);
872                } else {
873                    self.beside.remove(id);
874                }
875            }
876            // The game's copy is left out while Lich's text is shown: Lich's
877            // own shows it.
878            Frame::InlineImage(picture) if role != Role::Calls => self.pictured(picture, role),
879            // The answer to Hydra's own request, which only the game gives.
880            Frame::MenuResponse(menu) if role.games() => {
881                let count = self.menu.as_ref().map_or(0, |(count, _)| count + 1);
882                self.menu = Some((count, menu.clone()));
883            }
884            _ => {}
885        }
886    }

888    /// A whole line on `stream`: kept on its stream, and into the story as
889    /// its stream declared, one story line for each line of its text; or,
890    /// as `role` says, only called for, or left out.
891    fn finished(&mut self, stream: &str, runs: &[Run], role: Role) {
892        let mut styled = styled(runs);
893        // A `:shortcode:` typed by a player is shown as its emoji.
894        for run in &mut styled {
895            if let Some(expanded) = crate::emoji::expanded(&run.text) {
896                run.text = expanded;
897            }
898        }
899        let mut lines = split_lines(styled);
900        // When the bytes of what is shown arrived: the game's own, or, for
901        // Lich's copy of a game line, the game's that it copies.
902        let mut arrived = role.games().then_some(self.clock).flatten();
903        if let Some(lich) = self.lich.as_mut() {
904            match role {
905                Role::Shown | Role::Calls => {
906                    let at = self.clock.unwrap_or_else(Instant::now);
907                    for line in &lines {
908                        lich.heard(stream, line, at, role == Role::Shown);
909                    }
910                }
911                Role::Guess => lines.retain(|line| lich.forwarded(&plain(line)).is_none()),
912                Role::Look => {
913                    if let Some(line) = lines.first()
914                        && let Some(at) = lich.forwarded(&plain(line))
915                    {
916                        self.perf.lich.push(at.elapsed());
917                        arrived = Some(at);
918                    }
919                }
920                Role::Own => {}
921            }
922        }
923        let heard = lines.len() as u64;
924        if role.games() {
925            self.perf.game_lines += heard;
926        } else {
927            self.perf.lich_lines += heard;
928        }
929        if role == Role::Calls {
930            if let Some(highlights) = self.highlights.clone() {
931                for line in &lines {
932                    let fired = self.respond(&highlights, line).fired;
933                    self.attend(fired);
934                }
935            }
936            self.place_pictures();
937            return;
938        }
939        if matches!(role, Role::Own | Role::Guess) {
940            lines.retain(|line| visible(line));
941        }
942        // A creature's own lines -- its death, a spell coming -- take their
943        // preset before the highlights paint over them.
944        for line in &mut lines {
945            crate::creature_line::mark(line);
946        }
947        let mut redirected = Vec::new();
948        if let Some(highlights) = self.highlights.clone() {
949            let mut kept = Vec::with_capacity(lines.len());
950            for line in lines {
951                let had_words = visible(&line);
952                let response = self.respond(&highlights, &line);
953                if role == Role::Shown {
954                    self.attend(response.fired);
955                }
956                // Squelched, or left blank by what a highlight hid: a blank
957                // the game sent is formatting and stays, one Hydra made is
958                // not.
959                if response.squelched || (had_words && !visible(&response.runs)) {
960                    continue;
961                }
962                match response.redirect {
963                    Some((to, copy)) if !to.eq_ignore_ascii_case(stream) => {
964                        if copy {
965                            kept.push(response.runs.clone());
966                        }
967                        redirected.push((to, response.runs));
968                    }
969                    _ => kept.push(response.runs),
970                }
971            }
972            lines = kept;
973        }
974        // A container look shown sorted, once the highlights have seen it
975        // as the game sent it.
976        if let Some(sorted) = self.sorting
977            && is_main(stream)
978        {
979            lines = lines
980                .into_iter()
981                .flat_map(|line| {
982                    crate::sorter::sort(
983                        &line,
984                        sorted.layout.width(),
985                        sorted.long_names.then_some(&self.listed),
986                    )
987                    .unwrap_or_else(|| vec![line])
988                })
989                .collect();
990        }
991        self.place(stream, lines, arrived);
992        self.place_pictures();
993        // A line redirected goes to its stream's windows alone.
994        for (to, runs) in redirected {
995            self.merging.push((to.clone(), runs.clone()));
996            self.streams.hear(&to, std::iter::once(runs));
997        }
998    }

1049    /// Lines of `stream`, as the highlights left them, put where the stream
1050    /// goes: on its stream, and into the story as its window declared.
1051    fn place(&mut self, stream: &str, lines: Vec<Vec<StyledRun>>, arrived: Option<Instant>) {
1052        let main = is_main(stream);
1053        if !main {
1054            self.merging
1055                .extend(lines.iter().map(|line| (stream.to_owned(), line.clone())));
1056            self.streams.hear(stream, lines.iter().cloned());
1057        }
1058        let style = match self.windows.route(stream, &|_| false) {
1059            Destination::Dropped => return,
1060            Destination::MainStyled(style) => Some(style),
1061            Destination::Main | Destination::Window(_) => None,
1062        };
1063        let mut shown = false;
1064        for mut runs in lines {
1065            let visible = visible(&runs);
1066            shown = true;
1067            self.since_prompt |= visible;
1068            if let Some(style) = &style {
1069                for run in runs.iter_mut().filter(|run| run.preset.is_none()) {
1070                    run.preset = Some(style.clone());
1071                }
1072            }
1073            if main {
1074                let text = plain(&runs);
1075                // A line a mark has taken is not looked for again: a flare's
1076                // line comes word for word chunk after chunk.
1077                if let Some(mark) = self.awaited_for(&text) {
1078                    crate::combat_line::mark(&mut runs, &mark.kind);
1079                } else {
1080                    let number = self.dropped + self.lines.len() as u64;
1081                    self.chunk_lines.push((text, number));
1082                }
1083            }
1084            self.push(if main {
1085                Shown::Game(runs)
1086            } else {
1087                Shown::From(stream.to_owned(), runs)
1088            });
1089            self.heard += 1;
1090        }
1091        if shown {
1092            self.paint_later(arrived);
1093        }
1094    }

1134    /// Each of `marks`, the combat reader's word on the chunk the last prompt
1135    /// closed, given to its line: found by its text among that chunk's
1136    /// lines, in order, and given the mark's preset on every run without one
1137    /// of its own. A line a highlight hid or rewrote is not found, and keeps
1138    /// what it has.
1139    ///
1140    /// In Lich's view a mark not found waits for its line ([`Self::awaited`]):
1141    /// Lich shows the chunk after the marks come.
1142    fn marked(&mut self, marks: &[hydra_model::state::combat::LineMark]) {
1143        let lichs = self.lichs_view();
1144        let mut from = 0;
1145        for mark in marks {
1146            let text = mark.text.trim();
1147            let Some(at) = self.closed_lines[from..]
1148                .iter()
1149                .position(|(seen, _)| seen.trim() == text)
1150            else {
1151                if lichs {
1152                    if self.awaited.len() == AWAITED {
1153                        self.awaited.pop_front();
1154                    }
1155                    self.awaited.push_back(mark.clone());
1156                }
1157                continue;
1158            };
1159            let number = self.closed_lines[from + at].1;
1160            from += at + 1;
1161            let Some(place) = number
1162                .checked_sub(self.dropped)
1163                .and_then(|place| usize::try_from(place).ok())
1164            else {
1165                continue;
1166            };
1167            if let Some((_, Shown::Game(runs))) = self.lines.get_mut(place) {
1168                crate::combat_line::mark(runs, &mark.kind);
1169            }
1170        }
1171    }

1173    /// The awaited mark whose line is `text`, if one waits: taken, and every
1174    /// mark before it let go, since Lich shows a chunk's lines in order and
1175    /// theirs did not come.
1176    fn awaited_for(&mut self, text: &str) -> Option<hydra_model::state::combat::LineMark> {
1177        if self.awaited.is_empty() {
1178            return None;
1179        }
1180        let text = text.trim();
1181        let at = self
1182            .awaited
1183            .iter()
1184            .position(|mark| mark.text.trim() == text)?;
1185        self.awaited.drain(..at);
1186        self.awaited.pop_front()
1187    }

1224/// several lines.
1225fn split_lines(runs: Vec<StyledRun>) -> Vec<Vec<StyledRun>> {
1226    let mut lines = vec![Vec::new()];

1228        for (index, piece) in run.text.split('\n').enumerate() {
1229            if index > 0 {

1231            }
1232            if !piece.is_empty()
1233                && let Some(line) = lines.last_mut()
1234            {
1235                line.push(StyledRun {
1236                    text: piece.to_owned(),
1237                    ..run.clone()
1238                });
1239            }
1240        }
