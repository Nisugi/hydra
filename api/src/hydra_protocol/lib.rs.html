1//! hydra-protocol
2//!
3//! The wire layer. Bytes arrive; [`frame::Frame`]s leave. This crate is the
4//! vocabulary boundary: nothing above it ever sees a raw byte or an unparsed
5//! string. The one deliberate exception is [`frame::Frame::UnknownTag`],
6//! which carries a tag nothing models so that it is never lost.
7//!
8//! Read [`frame`] for what the wire can say, [`parser`] for how a line becomes
9//! frames and why the parser is hand-rolled, and [`scrub`] for the redaction
10//! the committed fixtures pass through.
11
