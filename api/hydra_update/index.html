Crate hydra_update 

Source
Expand description

Hydra updating itself: a newer release looked for on the public releases page, fetched, its signature checked, and put in place of the running program, which is that release from its next start.

The release job signs each release’s checksums with the release key; Hydra holds the key’s public half. A file is put in place only when the signature holds under it, the signature’s signed comment names the release, and the file’s hash is the one the checksums give it.

  • release: the releases listed, and the newest above this Hydra.
  • signed: the checksums, their signature checked.
  • swap: the new program unpacked and put where the running one is.

Hydra updates itself on Windows alone for now: elsewhere Releases::look finds nothing.
