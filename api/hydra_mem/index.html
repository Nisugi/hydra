Where Hydra’s memory goes.

Built with the measure feature, every allocation is counted against the part of Hydra whose code made it, for as long as it is held: part marks a stretch of code as one part’s, and held says what each part holds now. Memory made outside every part is other. Built without it, part only runs its code and held says nothing, so no other build pays for the counting.

What is counted is what Rust allocates. Memory the graphics driver or the system holds for Hydra is not, so the parts add up to less than the process’s committed memory: the difference is theirs.

A part is marked on stretches of code that run on one thread without pausing, since what is being counted follows the thread, or on a task (task), counted each time it runs, or on a whole thread (thread), for what it makes outside every other part. A part inside another counts as its own: the combat matching inside the game text counts as combat.
