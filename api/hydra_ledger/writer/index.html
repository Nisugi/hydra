The one writer: a thread of its own, fed over a channel.

Recorders hold a Writer and hand it rows. The thread takes what has arrived, writes it all in one transaction, and waits for more. A recorder that must know its rows are on disk calls Writer::flush, which answers once everything sent before it is committed. The thread ends when the last handle is dropped.
