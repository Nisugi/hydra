1//! Resolving a noun to a thing.
2//!
3//! Kept apart from `state.rs` -- move code down, do not raise the cap.
4//!
5//! # What this is, and what it deliberately is not
6//!
7//! Every interactable carries a stable id, which is what makes "the doublet"
8//! resolvable to a thing. The **capture** of `exist=`/`noun=` happens
9//! elsewhere -- every `RoomItem` in the room and in every container carries
10//! both. This is the lookup, and that is all.
11//!
12//! It is **not a separate registry**. A second copy of every item, kept in sync
13//! with the room and the inventory, would be a cache with two writers and a
14//! staleness bug waiting: when a creature dies, `room objs` re-sends without it,
15//! and a registry that merely accumulated would keep offering it forever. Reading
16//! through to the live collections means a thing is resolvable exactly as long as
17//! the game still says it is there.
18//!
19//! # Why a noun can be ambiguous, and why that is reported rather than guessed
20//!
21//! MEASURED in recorded sessions: a single `room objs` body carried two
22//! creatures of one noun, and a capture shows a container holding several
23//! items whose nouns repeat across containers. `noun=` is what a
24//! command targets, and the game itself disambiguates with ordinals -- so a
25//! consumer that silently took the first match would send `attack artificer` at
26//! the wrong artificer.
27//!
28//! [`GameState::resolve_noun`] therefore returns **every** match, in a defined
29//! order, and lets the caller decide. A behavior that wants "the only one" checks
30//! the length; one that wants "the first in the room" takes `.first()` knowingly.
31
32use super::GameState;
33use super::room::RoomItem;
34
35/// Where a resolved thing was found.
36///
37/// Carried because *where* changes what a command can do: something in the room
38/// can be attacked or picked up, something in a container is already held.
39#[derive(Clone, Copy, Debug, PartialEq, Eq)]
40pub enum Where<'a> {
41    /// A bold entry of `room objs`.
42    Creature,
43    /// A non-bold entry of `room objs`.
44    RoomObject,
45    /// An entry of `room players`.
46    Player,
47    /// Inside the named container.
48    Container(&'a str),
49}
50
51/// One thing a noun resolved to.
52#[derive(Clone, Copy, Debug, PartialEq, Eq)]
53pub struct Found<'a> {
54    /// The item itself, borrowed from the live collection it lives in.
55    pub item: &'a RoomItem,
56    /// Where it was found.
57    pub found_in: Where<'a>,
58}
59
60impl GameState {
61    /// Every thing currently known by this noun.
62    ///
63    /// Searched in a **defined order** -- creatures, room objects, players, then
64    /// containers by id -- so the result is deterministic for a replay and so
65    /// `.first()` means something stable to a caller who uses it.
66    ///
67    /// Creatures come first deliberately: a noun that matches both a creature and
68    /// a floor item is overwhelmingly meant as the creature, because that is what
69    /// a player is usually acting on.
70    ///
71    /// **Returns every match rather than the best one.** The game disambiguates
72    /// with ordinals, so guessing here would send a command at the wrong target
73    /// and report success. See the module docs.
74    #[must_use]
75    pub fn resolve_noun(&self, noun: &str) -> Vec<Found<'_>> {
76        self.resolve_all().filter(|f| f.item.noun == noun).collect()
77    }
78
79    /// The thing with this `exist` id, wherever it is.
80    ///
81    /// The unambiguous lookup: ids are unique where nouns are not, so this
82    /// returns at most one. What a consumer uses once it has *chosen* among
83    /// [`Self::resolve_noun`]'s answers and wants to check the thing is still
84    /// there before acting.
85    #[must_use]
86    pub fn find_by_id(&self, id: &str) -> Option<Found<'_>> {
87        self.resolve_all().find(|f| f.item.id == id)
88    }
89
90    /// Every known thing, in the same defined order [`Self::resolve_noun`] uses.
91    fn resolve_all(&self) -> impl Iterator<Item = Found<'_>> {
92        let creatures = self.room.creatures.iter().map(|item| Found {
93            item,
94            found_in: Where::Creature,
95        });
96        let objects = self.room.objects.iter().map(|item| Found {
97            item,
98            found_in: Where::RoomObject,
99        });
100        let players = self.room.players.iter().map(|item| Found {
101            item,
102            found_in: Where::Player,
103        });
104        let carried = self.inventory.containers().flat_map(|(id, container)| {
105            container.items.iter().map(move |item| Found {
106                item,
107                found_in: Where::Container(id),
108            })
109        });
110        creatures.chain(objects).chain(players).chain(carried)
111    }
112}
