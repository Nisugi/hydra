1//! The `charprofile` stream: what `profile` shows, typed.
2//!
3//! # What the wire sends
4//!
5//! MEASURED against a live capture (`fixtures/character_profile.xml`, cut
6//! from a recorded session). A window declaration, `<output class="mono"/>`,
7//! then four **bold section headers**
8//! with plain lines under each:
9//!
10//! ```text
11//! PERSONAL INFORMATION
12//! Name: Nisugi
13//! Profession: Ranger   Level: 100
14//! Title: Hero
15//! Race: Half-Elf   Gender: Male
16//! Age: a tender age (36)
17//! Date of Birth: 8/28/5090
18//! He is taller than average.  He appears to be of a tender age.
19//! AFFILIATIONS
20//! Full citizen of Kraken's Fall
21//! Master of the Guardians of Sunfist
22//! ACHIEVEMENTS
23//! Strongest foe vanquished: a leopard ogre (level 140)
24//! HISTORY
25//! Formerly known as Ibbo.
26//! ```
27//!
28//! # What this type holds, and what it deliberately does not
29//!
30//! Most of `PERSONAL INFORMATION` and all of `AFFILIATIONS` are **already
31//! modelled**, and this reader must not become a second home for them:
32//!
33//! | Profile line | Already read by |
34//! |---|---|
35//! | `Race:`, `Profession:`, `Gender:` | [`Identity`](super::stats::Identity), from `info` |
36//! | `Master of the Guardians of Sunfist` | [`Standing::apply_society`](super::standing::Standing) |
37//! | `Full citizen of Kraken's Fall` | `Standing`'s citizenship |
38//!
39//! Those keep one home. What is here is what nothing else has --
40//! **`Title:`, the character's own description, the achievements and the
41//! history** -- plus the two identity fields the profile states better than
42//! `info` does (`Age:` carries a number in brackets; `Date of Birth:` appears
43//! nowhere else).
44//!
45//! # Nothing here is the level
46//!
47//! `Level: 100` is on this line and is NOT read, for the reason `blocks.rs`
48//! already gives about `info`: it is a snapshot of something that changes.
49//! The `expr` dialog is the level's home.
50//!
51//! # It arrives in the MAIN window, not in a stream
52//!
53//! A `charprofile` stream id is declared, but **the capture says the text is
54//! not pushed to it**: `profile` sends `streamWindow` + `clearStream` +
55//! `exposeStream` and then prints the text into the MAIN window. MEASURED
56//! over two profile runs: `exposeStream id="charprofile"` twice,
57//! `pushStream id="charprofile"` **zero times**.
58//!
59//! So this is an ordinary chunk reader, beside `blocks::InfoReport`; a
60//! stream-buffer reader would read an empty buffer and teach nothing.
61//!
62//! `exposeStream` is a **display** instruction: show that window. The
63//! `ifClosed=''` "Copy" behaviour is the same shape -- the server sends the
64//! line to main as well -- so a declared-and-exposed window is not evidence
65//! of a pushed stream.
66//!
67//! # A classifier over a chunk
68//!
69//! The section headers arrive bold, and the parser already records bold depth,
70//! so nothing here re-tokenizes markup. Read whole from one chunk because the
71//! sections are positional: `Formerly known as` means something different
72//! under `HISTORY` than it would anywhere else -- and because the prompt is
73//! the only boundary a command's output has.
74

77/// The window `profile` declares and exposes.
78///
79/// **Not a stream to read text from** -- see the module docs. Kept because a
80/// frontend showing the profile in its own panel needs the id, and because a
81/// reader looking for `charprofile` should land on that correction.
82pub const WINDOW: &str = "charprofile";
83
84/// A section of the profile, as its bold header names it.
85#[derive(Clone, Copy, Debug, PartialEq, Eq)]
86enum Section {
87    Personal,
88    Affiliations,
89    Achievements,
90    History,
91}
92
93impl Section {
94    fn of(line: &str) -> Option<Self> {
95        match line.trim() {
96            "PERSONAL INFORMATION" => Some(Self::Personal),
97            "AFFILIATIONS" => Some(Self::Affiliations),
98            "ACHIEVEMENTS" => Some(Self::Achievements),
99            "HISTORY" => Some(Self::History),
100            _ => None,
101        }
102    }
103}

105/// What `profile` says that nothing else does.
106///
107/// Every field is `Option` or empty-by-default: a profile nobody has run is
108/// not a character with no title.
109#[derive(Clone, Debug, Default, PartialEq, Eq)]
110pub struct Profile {
111    /// `Title: Hero` -- the title in use, which `info` does not state.
112    pub title: Option<String>,
113    /// `Age: a tender age (36)` -- the number in the brackets.
114    ///
115    /// Also reaches [`Identity::age`](super::stats::Identity::age), which is
116    /// where a caller should read it. Kept here too because this reader is
117    /// where the bracketed form is understood.
118    pub age: Option<u32>,
119    /// `Date of Birth: 8/28/5090`, verbatim. Elanthian, so not a date type.
120    pub birthday: Option<String>,
121    /// The `He is...` / `He has...` lines, in wire order: height, eyes, skin,
122    /// hair, scars, tattoos. Free prose, and the set varies per character, so
123    /// these are kept as lines rather than parsed into fields.
124    pub description: Vec<String>,
125    /// The `AFFILIATIONS` lines, in wire order.
126    ///
127    /// **Kept whole even though `Standing` reads most of them**, because the
128    /// section says things `Standing` has no field for: `Follower of Zelia`,
129    /// `Attuned to the Element of Earth`, `Member of House of Paupers`. A
130    /// caller wanting the society or citizenship reads `Standing`.
131    pub affiliations: Vec<String>,
132    /// `ACHIEVEMENTS`, as `(label, value)`: *Strongest foe vanquished*,
133    /// *Most difficult lock picked*, *Number of warcamps destroyed*. Labels
134    /// vary by profession, so this is a list rather than a struct.
135    pub achievements: Vec<(String, String)>,
136    /// `HISTORY` lines, e.g. `Formerly known as Ibbo.`
137    pub history: Vec<String>,
138    /// Whether a profile has been read at all.
139    stated: bool,
140}
141
142impl Profile {
143    /// Whether `profile` has been seen this session.
144    #[must_use]
145    pub const fn is_stated(&self) -> bool {
146        self.stated
147    }
148
149    /// Read one chunk's lines, as the profile of the character named `name`.
150    ///
151    /// Returns whether they were **this character's** profile. Recognised by
152    /// its `PERSONAL INFORMATION` header rather than assumed, because this
153    /// runs on every chunk -- the same rule `blocks::InfoReport::read` follows.
154    ///
155    /// # Only the character's own
156    ///
157    /// `profile Bob` prints Bob's profile in the same shape, and reading it
158    /// would give this character Bob's society, rank, citizenship and age.
159    /// So the `Name:` line under `PERSONAL INFORMATION` must name `name` as
160    /// one of its words. With no `Name:` line, or the character's own name
161    /// not yet known, nothing is read either: a profile nobody can prove is
162    /// ours teaches nothing. A refused profile leaves what was read
163    /// before untouched.
164    pub fn read_lines(&mut self, lines: &[String], name: Option<&str>) -> bool {
165        let Some(at) = lines
166            .iter()
167            .position(|l| Section::of(l) == Some(Section::Personal))
168        else {
169            return false;
170        };
171        let named = lines[at + 1..]
172            .iter()
173            .take_while(|l| Section::of(l).is_none())
174            .find_map(|l| l.trim().strip_prefix("Name:"));
175        let ours = named.zip(name).is_some_and(|(named, name)| {
176            named
177                .split_whitespace()
178                .any(|word| word.eq_ignore_ascii_case(name))
179        });
180        if !ours {
181            return false;
182        }
183        // Whole-list replacement, like the `Spells` stream: `profile` prints
184        // everything every time, so merging would keep an achievement that a
185        // later run no longer lists.
186        *self = Self {
187            stated: true,
188            ..Self::default()
189        };
190        let mut section = None;
191        for line in lines {
192            if let Some(next) = Section::of(line) {
193                section = Some(next);
194                continue;
195            }
196            let text = line.trim();
197            if text.is_empty() {
198                continue;
199            }
200            match section {
201                Some(Section::Personal) => self.read_personal(text),
202                Some(Section::Affiliations) => self.affiliations.push(text.to_owned()),
203                Some(Section::Achievements) => {
204                    if let Some((label, value)) = text.split_once(": ") {
205                        self.achievements
206                            .push((label.trim().to_owned(), value.trim().to_owned()));
207                    }
208                }
209                Some(Section::History) => self.history.push(text.to_owned()),
210                None => {}
211            }
212        }
213        true
214    }
215
216    fn read_personal(&mut self, text: &str) {
217        // `Name:`, `Profession:`, `Race:`, `Gender:` are deliberately skipped:
218        // `Character` and `Identity` own those (see the module docs).
219        if let Some(title) = text.strip_prefix("Title: ") {
220            self.title = Some(title.trim().to_owned());
221        } else if let Some(age) = text.strip_prefix("Age: ") {
222            // `a tender age (36)`: the brackets hold the number, and the words
223            // before them are flavour that changes with it.
224            self.age = age
225                .rsplit_once('(')
226                .and_then(|(_, n)| n.trim_end_matches(')').trim().parse().ok());
227        } else if let Some(birthday) = text.strip_prefix("Date of Birth: ") {
228            self.birthday = Some(birthday.trim().to_owned());
229        } else if text.contains(" is ") || text.contains(" has ") {
230            // The description lines. Recognised by their shape rather than by
231            // a pronoun, because the pronoun is the character's.
232            self.description.push(text.to_owned());
233        }
234    }
235
236    /// One achievement by label, e.g. `"Number of warcamps destroyed"`.
237    #[must_use]
238    pub fn achievement(&self, label: &str) -> Option<&str> {
239        self.achievements
240            .iter()
241            .find(|(l, _)| l == label)
242            .map(|(_, v)| v.as_str())
243    }
244
245    /// Forget it: a reconnect, after which `profile` must be run again.
246    pub fn clear(&mut self) {
247        *self = Self::default();
248    }
249}

251impl super::Character {
252    /// Send what the profile said to the fields that own it.
253    ///
254    /// **One home per fact.** `profile` states the age, the society
255    /// and the citizenship, and `Identity` and `Standing` already hold those
256    /// from `info` and from single lines. This routes them there instead of
257    /// letting `Profile` become a second, quietly disagreeing copy -- and it
258    /// reuses `standing`'s own line readers, so `Master of the Guardians of
259    /// Sunfist` yields rank 20 here exactly as it does from a chunk.
260    pub(crate) fn absorb_profile(&mut self) {
261        if let Some(age) = self.profile.age {
262            self.identity.age = Some(age);
263            self.taught.insert(snapshot::Group::Identity);
264        }
265        let mut standing_changed = false;
266        // `profile`'s own wording, which the report readers do not accept --
267        // see `standing::profile_affiliation`.
268        for line in self.profile.affiliations.clone() {
269            match standing::profile_affiliation(&line) {
270                // `Member of the Order of Voln` carries no rank, which is
271                // "not on this line", not "no rank": a rank the `society`
272                // report already gave for this same society is kept (erasing
273                // it would turn off wracking and the society way home).
274                Some(standing::Affiliation::Society(standing::SocietyEvent::Report {
275                    society: Some(society),
276                    rank: None,
277                    master: false,
278                })) if self.standing.society == Some(Some(society)) => {}
279                Some(standing::Affiliation::Society(event)) => {
280                    standing_changed |= self.standing.apply_society(event);
281                }
282                Some(standing::Affiliation::Citizenship(town)) => {
283                    let town = Some(Some(town));
284                    standing_changed |= self.standing.citizenship != town;
285                    self.standing.citizenship = town;
286                }
287                None => {}
288            }
289        }
290        if standing_changed {
291            self.taught.insert(snapshot::Group::Standing);
292        }
293    }
