pub fn parse_line(line: &str) -> Option<(&str, &str, &str)>
Expand description

Read a written line back into its three parts.

Both formats this project will ever write are accepted here, forever. Today there is one, which makes this look like speculation – it is not: a format changes eventually, and a format migration over years of archive is not a thing anyone wants to write. The place to add the second is here, and the test that both parse is what makes the promise real.

Returns (time, stream, text), or None for a line that is not ours; the text with its links after it, when it has any (super::links::read).
