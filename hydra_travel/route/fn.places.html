Expand description

The places to go (.go2 targets): town by town, the places the map names near each – which are targets already, with nothing saved. Under each town, one line for each of PLACES that has a room whose nearest town it is. Then the names the player chose (named).

“Nearest” is by what this walker would pay. A town tagged closed is not listed.
