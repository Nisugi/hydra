pub fn ways_out_of(map: &Map, room: RoomId) -> Vec<WayOut>
Expand description

The ways out of room on map that are not the compass’s, each once, in the map’s order: go gate shown gate; a crossing walked by more than one command shown by where it leads. None for a room the map does not have.
